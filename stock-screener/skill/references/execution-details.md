## 二、判断阈值（写死，用于 Step 2~4）

### 质量硬门槛（Step 2）— 全过才入候选
| 维 | 通过条件 |
|----|---------|
| 真实性 | 主营确属主线环节，非蹭概念 |
| 财务 | 营收增速>0 且 净利增速不为负向恶化 |
| 证据 | 有 S/A 级（涨价函/订单/中报）支撑 |
| 剔除 | 亏损无反转 / 增长停滞 / 纯叙事 |

### 题材阶段判断（Step 3 · 核心主轴，A股情绪驱动）
**估值是安全边际下限，不是选股主轴。强主线/强龙头在情绪发酵期允许溢价。** 先判阶段，阶段对则高PE/高换手不构成剔除理由：

| 阶段 | 特征（涨停梯队/资金/扩散） | 动作 |
|------|---------------------------|------|
| ①点火 / ②主升中段 | 连板梯队长、龙头不滞涨、资金持续流入、扩散龙头→补涨 | **可参与**，选题材纯度最高龙头 |
| ③主升末段(加速滞涨) | 龙头放量滞涨、连板断层无接力、炸板率升 | 减仓/不追 |
| ④退潮/⑤证伪/⑥过热 | 资金净流出、龙头破位、杂毛补涨 | 回避/冻结 |

> 判阶段指标：连板高度、首板家数、龙头是否滞涨、资金净流入是否衰减、题材内扩散层级。

### 估值坐标（Step 3 附属 · 只作安全边际参考，不作主删轴）
| 维 | 规则 |
|----|------|
| 历史分位 | 仅作"安全边际下限"参考：PE 分位过高+景气透支 且 阶段已到末段 → 降权；但 **阶段在①②主升期则允许溢价** |
| 优先 | 基本面好 + 估值合理或偏低；而非"一定选低PE" |

### 拥挤识别（Step 4 · 区分情绪溢价与接最后一棒）
| 情形 | 特征 | 动作 |
|------|------|------|
| 健康溢价(①②) | 高换手+量能配合+梯队完整+龙头未滞涨 | **不降权**，可参与 |
| 危险拥挤(③④) | 龙头放量滞涨、连板断层、炸板率升、资金净流出、龙头破位 | **冻结追高** |
| 近两周涨幅>30% | 需看阶段：若①②主升则属正常；若③末段则危险 | 结合阶段处置 |
| 换手率持续>15% | 同上：健康(①②)不降权 / 危险(③④)预警 | 结合阶段处置 |

### 仓位与止损（Step 5）— 按锁定风格条件
| 参数 | 锁定值 |
|------|--------|
| 持仓周期 | 1个月左右 |
| 硬止损 | 跌破买点-15%（或关键支撑）= 认错退出 |
| 单票集中 | 1~2只，轻仓（总仓位不大） |
| 卖点 | 按1个月目标位测算（支撑压力位+涨幅空间） |

## 三、输出纪律
1. 输出"选股单"而非"建议"，全自动直接交付最终候选。
2. 买卖点写"条件框架"（回调到X~Y买 / 到Z卖 / 跌破W退），不写死命令式。
3. 每只多空并列（多头依据 + 空头证据）。
4. 证据分级 S/A/B/C/D，缺失标 [MISSING]。
5. 落库 screener_ledger.md，供持仓分析回溯。
