关键字段定位（腾讯 v_sh 串）：现价/涨跌幅/今开/昨收/成交量/成交额/换手率/PE/总市值/流通市值/PB。实时权重将其作为准确锚点。

## 二、判断阈值（写死，用于 Step 2~4）

### 质量硬门槛（Step 2）— 全过才入候选
| 维 | 通过条件 |
|----|---------|
| 真实性 | 主营确属主线环节，非蹭概念 |
| 财务 | 营收增速>0 且 净利增速不为负向恶化 |
| 证据 | 有 S/A 级（涨价函/订单/中报）支撑 |
| 剔除 | 亏损无反转 / 增长停滞 / 纯叙事 |

### 估值坐标（Step 3）
| 维 | 规则 |
|----|------|
| 历史分位 | PE 分位 >80% 且景气透支 → 降权/剔除 |
| 优先 | 基本面好 + 估值未充分定价（A/B 类预期差） |

### 位置与拥挤（Step 4）— 防追高
| 指标 | 阈值 | 动作 |
|------|------|------|
| 近两周涨幅 | >30% | 列"追高危险"，避开现价买入 |
| 换手率 | 持续>15% | 拥挤降权 |
| 成交额 | 异常放大远离均量 | 拥挤预警 |
| 轮动位置 | 已兑现·主位高位 | 不追，等回调；优先启动/回调到位 |

### 仓位与止损（Step 5）— 按锁定风格条件
| 参数 | 锁定值 |
|------|--------|
| 持仓周期 | 1个月左右 |
| 硬止损 | 跌破买点-15%（或关键支撑）= 认错退出 |
| 单票集中 | 1~2只，轻仓（总仓位不大） |
| 卖点 | 按1个月目标位测算（支撑压力位+涨幅空间） |

## 三、输出纪律
1. 输出"选股单"而非"建议"，全自动直接交付最终候选。
2. 买卖点写"条件框架"（回调到X~Y买 / 到Z卖 / 跌破W退），不写死命令式。
3. 每只多空并列（多头依据 + 空头证据）。
4. 证据分级 S/A/B/C/D，缺失标 [MISSING]。
5. 落库 screener_ledger.md，供持仓分析回溯。
