### D8 · C路全市场强共振扫描（突破主线限制的进料来源）
> 作用：捕捉"资金正在聚集但未被主线挖掘写入台账"的票，反哺主线挖掘。与路径A/B取并集后统一按驱动轴评分。命中判定为"单日全市场异动 + 连续资金净流入 + 技术转强"三因子共振，而非简单涨幅榜。

```python
import akshare as ak
# 1) 全市场涨跌幅榜（东财，尽力而为；被墙则回退用行业板块涨幅+个股扩散）
try:
    df_spot = ak.stock_zh_a_spot_em()          # 全A实时，含涨跌幅/换手/量比/成交额 → 作为异动初筛源
    hot = df_spot[df_spot['涨跌幅']>5].sort_values('成交额', ascending=False)
    print(hot[['代码','名称','涨跌幅','换手率','量比','成交额']].head(40))
except Exception as e:
    print("spot_em ERR", str(e)[:80])          # 标 [MISSING]，回退行业板块榜
# 2) 近5日主力净流入 TOP（东财资金流，尽力而为）
try:
    ff = ak.stock_individual_fund_flow_rank(indicator="今日,5日")
    print(ff.head(30))
except Exception as e:
    print("fund_flow ERR", str(e)[:80])        # 标 [MISSING]，用腾讯实时串末尾资金流近似
# 3) 命中初筛后，逐票用 D1/D2 算技术多头(MA5>MA10>MA20)+量比>1+RSI(50~75健康区)，筛出真三因子共振
```
> **C路门槛（写死）**：必须同时满足——涨跌幅>5%（或换手>8%放量）、近5日主力净流入为正且日增、技术多头(现价>MA5>MA10>MA20)、量比≥1.2。只满足涨幅/换手其一者剔除（防情绪脉冲）。命中票进候选池并标注"[C-主线外]"供主线挖掘反向吸收。

## 二、判断阈值（驱动轴权重 70%：技术25+资金22.5+情绪22.5；背景板 25%：估值12.5+业绩12.5；主线5%）

### 基本面硬门槛（Step 2）— 辅助过滤，只排雷不强求优秀
| 维 | 通过条件 |
|----|---------|
| 真实性 | 主营确属主线环节，非蹭概念 |
| 最低门槛 | 非退市风险、无重大造假、非亏损且无任何反转逻辑 |
| 证据 | 有 S/A 级证据 → 加分（非剔除条件） |
| 剔除 | 退市风险 / 造假 / 濒死纯叙事 |

### 技术面（Step 3 · 权重最高 25%）— 定强弱与买卖时机
| 指标 | 强势信号 | 弱势信号 |
|------|---------|---------|
| 均线 | MA5>MA10>MA20 多头 | 均线空头/跌破关键均线 |
| MACD | 金叉/红柱放大 | 死叉/绿柱扩大 |
| 量价 | 放量突破/缩量回调 | 放量滞涨/缩量阴跌 |
| 位置 | 突破前高/回踩支撑不破/启动初期 | 加速末段/跌破平台 |
| 买卖时机 | 回调到支撑/突破时买 | 追高拉升尾段 |

### 资金面（Step 4 · 22.5%）
| 指标 | 强势 | 弱势 |
|------|------|------|
| 主力净流入 | 连续流入(>脉冲) | 持续净流出 |
| 量能 | 放量启动/突破 | 缩量反弹/放量出货 |
| 龙虎榜 | 机构净买>游资 | 机构净卖 |

### 情绪面（Step 4 · 22.5%）
| 阶段 | 特征（涨停梯队/资金/扩散） | 动作 |
|------|---------------------------|------|
| ①点火 / ②主升中段 | 连板梯队长、龙头不滞涨、资金持续流入、扩散龙头→补涨 | **可参与**，选题材纯度最高龙头 |
| ③主升末段(加速滞涨) | 龙头放量滞涨、连板断层无接力、炸板率升 | 减仓/不追 |
| ④退潮/⑤证伪/⑥过热 | 资金净流出、龙头破位、杂毛补涨 | 回避/冻结 |

### 拥挤识别（Step 4b · 防空回杀）
| 情形 | 特征 | 动作 |
|------|------|------|
| 健康溢价(①②) | 高换手+量能+梯队完整+龙头未滞涨 | **不降权**，可参与 |
| 危险拥挤(③④) | 龙头放量滞涨、连板断层、炸板率升、净流出、破位 | **冻结追高** |

### 估值/业绩（Step 4c · 辅助，各 12.5%）
| 维 | 规则 |
|----|------|
| 估值 | 仅安全边际参考，不因贵排斥主升龙头；主升期溢价合理 |
| 业绩 | 作虚实验证加分；纯讲故事但资金强可入围（非造假/濒死） |

> 判阶段指标：连板高度、首板家数、龙头是否滞涨、资金净流入是否衰减、题材内扩散层级。

### 估值坐标（Step 3 附属 · 只作安全边际参考，不作主删轴）
| 维 | 规则 |
|----|------|
| 历史分位 | 仅作"安全边际下限"参考：PE 分位过高+景气透支 且 阶段已到末段 → 降权；但 **阶段在①②主升期则允许溢价** |
| 优先 | 基本面好 + 估值合理或偏低；而非"一定选低PE" |

### 拥挤识别（Step 4 · 区分情绪溢价与接最后一棒）
| 情形 | 特征 | 动作 |
|------|------|------|
| 健康溢价(①②) | 高换手+量能配合+梯队完整+龙头未滞涨 | **不降权**，可参与 |
| 危险拥挤(③④) | 龙头放量滞涨、连板断层、炸板率升、资金净流出、龙头破位 | **冻结追高** |
| 近两周涨幅>30% | 需看阶段：若①②主升则属正常；若③末段则危险 | 结合阶段处置 |
| 换手率持续>15% | 同上：健康(①②)不降权 / 危险(③④)预警 | 结合阶段处置 |

### 仓位与止损（Step 5）— 按锁定风格条件
| 参数 | 锁定值 |
|------|--------|
| 持仓周期 | 1个月左右 |
| 硬止损 | 跌破买点-15%（或关键支撑）= 认错退出 |
| 单票集中 | 1~2只，轻仓（总仓位不大） |
| 卖点 | 按1个月目标位测算（支撑压力位+涨幅空间） |

## 三、输出纪律
1. 输出"选股单"而非"建议"，全自动直接交付最终候选。
2. 买卖点写"条件框架"（回调到X~Y买 / 到Z卖 / 跌破W退），不写死命令式。
3. 每只多空并列（多头依据 + 空头证据）。
4. 证据分级 S/A/B/C/D，缺失标 [MISSING]。
5. 落库 screener_ledger.md，供持仓分析回溯。

## 四、资金溢出自动接棒（三路进料的核心轮动触发规则，写死）

> 目的：全自动捕捉"主线外资金溢出的新方向"，根治"主线没死但资金已换场、票池跟不上"的灯下黑。v1.3.0 起强制执行。

### 4.1 · S0 主线迁移预判（写死触发）
**当同时出现以下信号，判定"资金正在从当前主线溢出"，自动把候选池重心切到溢出方向：**
| 触发信号 | 判定标准 |
|---------|---------|
| 当前主线龙头滞涨/破位 | 主线龙头（如沃尔核材/金安国纪等当前台账榜首）出现放量滞涨、或跌破关键均线/前高 |
| 主线内部资金净流出 | 主线链条内多股 D4 主力净流出，连板高度退坡、炸板率升 |
| C 路捞出主线外强共振票 | C 路命中 ≥3 只同一新方向（同板块/同题材）的三因子共振，且不是单日情绪脉冲 |
| 新方向量能持续放大 | 溢出方向连续≥2 日成交额放大、北向/龙虎榜机构进场 |

**触发后动作（自动，不需人工）**：
1. 把 C 路命中的新方向票升格为候选池**并列优先级**（不再是"A主线优先"）。
2. 对新方向票仍按驱动轴70%统一评分，趋势完整者允许溢价买入。
3. 用 `catalyst`/`evidence_lib` 佐证新方向真实性：有 S/A 级涨价函/订单/中报 → 反哺主线挖掘写入台账；无证据仅情绪 → 只作观察池候选，不重仓。
4. 旧主线若仅滞涨未破位 → 降权为 B 路观察（不立即删除）；若龙头破位+资金净流出持续 → 降级出候选池。
5. 把判定与结论落库 screener_ledger.md，标注"主线迁移 S0"。

> **反转开关（防误切）**：若溢出方向次日即炸（涨停断层、资金净流出、龙头破位），且原主线龙头重新放量收复均线 → 回到原主线候选，撤销迁移判定。切换以"连续2日确认"为准，不做单日冲动切换。
