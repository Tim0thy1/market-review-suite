# 中线选股器 · 全自动（Midline Stock Screener）

## 核心定位

**选股器是把"主线挖掘 skill"的自上而下结论，落成"具体买哪只、什么价买、买几成"的自下而上执行层。**

> **A 股认知总纲（必读）**：A 股不是由估值主导，**情绪、资金、题材阶段才是主驱动**，估值只是安全边际下限。强主线/强龙头在主升期会给情绪溢价（高 PE、高换手都可以），不应因"贵"而排除；真正要规避的是"情绪到了末段/退潮期去接最后一棒"。因此本 skill 以**题材阶段**为主轴（见 Step 3/4），估值仅作安全边际参考。

衔接关系（三 skill 闭环）：
- **主线挖掘 skill**（mainline-research）：自下而上分析 → 输出"哪些是真主线 + 主线标的池"（含子线/档位/买点情景）。
- **选股器（本 skill）**：承接标的池 → 按锁定风格条件做多因子筛选 → 输出"最终候选 1~2 只 + 买点/卖点/失效位 + 仓位"。
- **持仓分析 skill**（simulated-portfolio-review）：回溯验证选股结果 → 复盘优化。

**本 skill 输出 = 可直接执行的选股单（全自动，无需人工确认）。**

## 用户风格条件（已锁定，写死不得违规）

| 参数 | 锁定值 | 说明 |
|------|--------|------|
| 持仓周期 | **1 个月左右** | 中线，非日内短线 |
| 回撤容忍 | **-15%** | 硬止损线，跌破认错退出 |
| 集中度 | **1~2 只** | 单主线内选 1-2 只，不撒网 |
| 仓位 | **不大（轻仓）** | 单票仓位克制，控制总风险 |
| 执行模式 | **全自动** | 直接出最终单子，不做人工确认轮 |

> 这些条件来自用户明确设定，本 skill 生成的一切买卖建议都必须围绕"1个月 + -15%止损 + 1-2只 + 轻仓 + 全自动"展开。

## 触发条件

- 用户要求"选股、筛票、挑票、买哪只、静待花开、这个主线买哪只、自动选股"等。
- 需要从主线标的池里挑出具体可执行标的。
- 用户触发主线分析后，接着要"那该买哪只？"。

## 执行流程（全自动，固定 6 步）

### Step 1 · 进料三路并取（拓宽票池，突破单一主线限制）
> **范围认知**：过往版本只从"已确认主线"链条内选票，票池天然窄——真正的强势股若未被主线挖掘提前写入台账，就永远进不了票池。v1.3.0 起改为**三道进料取并集**，反哺主线挖掘。
- **路径 A · 自上而下（主线链条）**：读取 `mainline-research/ledgers/target_pool.md`（主线标的池）与 `mainline_ledger.md`（主线状态）。确认当前最强主线（以台账实际为准），在该主线链条内的真实子线中筛选。
- **路径 B · 横向近邻（同主线扩展）**：除领涨主位子线外，同时纳入同主线的**其他子线 + 近邻/间接受益环节**（沿用 target_pool"旁视同线其他子线"约定并扩大）：补涨接力位、上游扩散位、产业链二线卡位。这保证"主线没死、只是内部轮动"时票池不枯竭。
- **路径 C · 自下而上（全市场强共振扫描，新增）**：用 `finance-free-data` 后端做**全市场三因子强共振扫描**（技术多头 + 资金净流入 + 换手/情绪活跃），独立于主线台账，捕捉"资金正在聚集但还没被写成主线"的票，**反哺主线挖掘**。
- **取并集**：A∪B∪C 全部进入 v1.2.0/v1.3.0 驱动轴（技术25+资金22.5+情绪22.5=70%）统一评分；**主线真实性 5% 仍作兜底**：真主线/真核心加分，纯蹭概念虽可进观察池但驱动轴同分时降权。三道进料的执行命令见 `references/execution-details.md`。
- **资金溢出自动接棒**：当 C 路在主线外命中同一新方向多只强共振、叠加主线龙头滞涨/资金净流出时，触发**主线迁移 S0 预判**，自动把候选池重心切到溢出方向——完整触发信号与反转开关见 `references/execution-details.md`（第 4.1 节），全自动执行不需人工。

### Step 2 · 基本面硬门槛（辅助过滤，权重低）
对标的池内每只票做最低门槛过滤（**只剔除造假/濒死，不强求优秀**）：
- **真实性**：主营确属主线环节，非蹭概念（沿用拆分规则）。
- **最低门槛**：非退市风险、无重大造假、非亏损且无任何反转逻辑的纯叙事票。
- **证据等级**：有 S/A 级证据（涨价函/订单/中报）**加分**，但非剔除条件。
> **重要性降级**：业绩合格只是"入场资格"，不决定"选哪只"——选股主要看 Step 3-4 的技术面/资金面/情绪，业绩只是排除雷票的背景板。

### Step 3 · 技术面主导（权重最高，25%）
**对最终候选用技术面定强弱与买卖时机**：
- **趋势**：均线多头（MA5>MA10>MA20）、站稳关键均线、MACD 金叉/红柱放大。
- **量价**：放量突破/缩量回调（健康）、量比>1 温和放量、价涨量增。
- **位置**：突破前高/平台颈线、回踩不破支撑、启动初期而非加速末段。
- **买卖时机**：在"回调到支撑/突破前高/回踩踩实"时买，而非追拉升。
> 技术面决定"何时买、止损放哪"——这是 A 股短线/中线盈利的核心。

### Step 4 · 资金面 + 情绪面（并列为次高权重，各 22.5%）
**资金面（22.5%）**：
- 主力资金净流入趋势（连续流入>单日脉冲）、北向/机构动向。
- 量能配合：放量启动、缩量回调、放量突破。
- 龙虎榜机构席位净买入>游资（机构主导更稳）。

**情绪面（22.5%）**：
- 题材阶段（①点火/②主升中段高强度/③末段减/④退潮回避）。
- 涨停梯队高度、连板数、龙头是否滞涨、炸板率。
- 板块/题材热度排名、赚钱效应对比炸亏效应。
- 情绪给溢价（高换手+梯队完整+龙头不滞涨=健康溢价，可参与）。

### Step 4b · 拥挤度识别（防空回杀）
不因高换手/高涨幅一律砍票，而是**识别拥挤所处的阶段**：
- **健康溢价**（①/②中段）：高换手+量能配合+梯队完整+龙头未滞涨 → 正常，**不降权**。
- **危险拥挤**（③末段/④退潮）：龙头放量滞涨、连板断层、炸板率升、资金净流出、龙头破位 → "最后一棒"信号，**冻结**。

### Step 4c · 估值/业绩总计（降为辅助，各 12.5%）
- **估值**：仅作安全边际参考，不因"贵"排斥主升龙头（主升期溢价合理）。
- **业绩**：作"虚实验证"——有真实业绩信号的加分，但股价主要看情绪资金；纯讲故事但资金强也可入围（只要不是造假/濒死）。
> **权重定论**：技术面 25% + 资金面 22.5% + 情绪面 22.5% = **驱动轴 70%**；估值 12.5% + 业绩 12.5% = **背景板 25%**；主线真实性 5% 兜底。选股排序完全按驱动轴。

### Step 5 · 买卖点 + 仓位计算（按风格条件）
对最终候选，用锁定参数自动生成条件框架（**写条件，不写指令**）：
- **买点**：回调到位区间（支持位/前平台/缺口），给出"回调至 X~Y 分批买"。
- **卖点**：1 个月周期目标位（用支撑压力位 + 涨幅空间测算），给出"到 Z 分批止盈"。
- **失效位（硬止损）**：**跌破买点 -15% 或跌破关键支撑 = 自动认错退出**（呼应回撤容忍-15%）。
- **仓位**：总仓位不大，按"1 只重仓/2 只各半"轻仓配置；单票不超过总资金某比例（轻仓定位）。

### Step 6 · 输出选股单（全自动最终交付）
输出固定结构，含：
1. **最终候选 1~2 只**（附主线归属 + 预期差类型 + 一句话理由）
2. 每只的 买点 / 卖点 / 失效位(-15%) / 建议仓位
3. 全自动风险提示（不构成投资建议）
4. 落库到 `ledgers/screener_ledger.md`（选股台账，供持仓分析 skill 回溯）

## 数据与证据纪律

- **自包含声明**：本 skill 的完整取数命令与全部条件阈值已封装在 `references/execution-details.md`，运行时按该文件执行，无需调用外部 skill。
- 数据走 `finance-free-data` 后端（腾讯/新浪实时 + akshare 财务 + 百度估值），**禁止凭空编数**。
- 缺失数据标 `[MISSING]`，不硬造；估算值注明"估算"。
- 分红清仓/坏消息：候选标的出现证据等级 S 的利空（如业绩暴雷、涨价函停发），自动剔除并说明。

## 台账落库

- 每次选股把"候选、买点/卖点/失效位、仓位、理由、证据等级"写入 `ledgers/screener_ledger.md`。
- 与持仓分析 skill 接口：持仓分析可读取本台账回溯"当时为何选它/买卖点是否兑现"，形成闭环。

## 与其他 Skill 分工

- 本 skill 依赖 `mainline-research` 的标的池与主线判断，**不重复做主线挖掘**。
- 本 skill 侧重"自动筛出具体票 + 买卖点"，**不做持仓复盘**（那是 simulated-portfolio-review 的活）。
