# 中线选股器 · 全自动（Midline Stock Screener）

## 核心定位

**选股器是把"主线挖掘 skill"的自上而下结论，落成"具体买哪只、什么价买、买几成"的自下而上执行层。**

衔接关系（三 skill 闭环）：
- **主线挖掘 skill**（mainline-research）：自下而上分析 → 输出"哪些是真主线 + 主线标的池"（含子线/档位/买点情景）。
- **选股器（本 skill）**：承接标的池 → 按锁定风格条件做多因子筛选 → 输出"最终候选 1~2 只 + 买点/卖点/失效位 + 仓位"。
- **持仓分析 skill**（simulated-portfolio-review）：回溯验证选股结果 → 复盘优化。

**本 skill 输出 = 可直接执行的选股单（全自动，无需人工确认）。**

## 用户风格条件（已锁定，写死不得违规）

| 参数 | 锁定值 | 说明 |
|------|--------|------|
| 持仓周期 | **1 个月左右** | 中线，非日内短线 |
| 回撤容忍 | **-15%** | 硬止损线，跌破认错退出 |
| 集中度 | **1~2 只** | 单主线内选 1-2 只，不撒网 |
| 仓位 | **不大（轻仓）** | 单票仓位克制，控制总风险 |
| 执行模式 | **全自动** | 直接出最终单子，不做人工确认轮 |

> 这些条件来自用户明确设定，本 skill 生成的一切买卖建议都必须围绕"1个月 + -15%止损 + 1-2只 + 轻仓 + 全自动"展开。

## 触发条件

- 用户要求"选股、筛票、挑票、买哪只、静待花开、这个主线买哪只、自动选股"等。
- 需要从主线标的池里挑出具体可执行标的。
- 用户触发主线分析后，接着要"那该买哪只？"。

## 执行流程（全自动，固定 6 步）

### Step 1 · 读取主线 skill 标的池
- 读取 `mainline-research/ledgers/target_pool.md`（主线标的池）与 `mainline_ledger.md`（主线状态）。
- 确认当前**最强主线**（当前默认 AI 载板材料链，但**每次以台账实际为准**）。
- 只在该主线链条内的真实子线中筛选，**过滤蹭概念/贴牌**（沿用 mainline-research 的拆分规则）。

### Step 2 · 质量硬门槛（自动化过滤）
对标的池内每只票，用真实数据做硬门槛，全部通过才进入候选：
- **真实性**：主营确属该主线环节，非蹭概念；业绩有 S/A 级证据支撑。
- **财务**：营收/净利增速为正且非负增长恶化；现金流可查。
- **证据等级**：优先选涨价函/订单/中报实锤（S/A 级）支撑的标的。
- **剔除**：亏损且无反转证据、增长停滞、纯叙事未兑现的票。

### Step 3 · 估值坐标（过滤太贵）
- 拉取每只票当前 PE(TTM)/PB 及**历史分位**（用 finance-free-data 的百度估值接口，算近 3-5 年百分位）。
- 结合主线景气：涨价周期中，估值高于历史高位分位(>80%)且已透支的，降权或剔除。
- 优先选"基本面好但估值未充分定价"的（对应主线 skill 的 A/B 类预期差）。

### Step 4 · 位置与拥挤过滤（核心防追高）
针对"1个月"持仓，位置过滤至关重要：
- **不看连续暴涨已透支的**：近 2 周涨幅>30%、换手率极高(>15% 持续)、成交额异常放大远离均量的，列为"追高危险"，避开现价买入。
- 优先选**回调到位或启动初期**的（回踩到买点区域、量能温和放大）。用主线 skill 中"轮动位置"标注辅助判断。
- **拥挤度量化**：换手率、成交额/流通市值比、龙虎榜净买入异常、涨跌停家数——拥挤度过高则降权。

### Step 5 · 买卖点 + 仓位计算（按风格条件）
对最终候选，用锁定参数自动生成条件框架（**写条件，不写指令**）：
- **买点**：回调到位区间（支持位/前平台/缺口），给出"回调至 X~Y 分批买"。
- **卖点**：1 个月周期目标位（用支撑压力位 + 涨幅空间测算），给出"到 Z 分批止盈"。
- **失效位（硬止损）**：**跌破买点 -15% 或跌破关键支撑 = 自动认错退出**（呼应回撤容忍-15%）。
- **仓位**：总仓位不大，按"1 只重仓/2 只各半"轻仓配置；单票不超过总资金某比例（轻仓定位）。

### Step 6 · 输出选股单（全自动最终交付）
输出固定结构，含：
1. **最终候选 1~2 只**（附主线归属 + 预期差类型 + 一句话理由）
2. 每只的 买点 / 卖点 / 失效位(-15%) / 建议仓位
3. 全自动风险提示（不构成投资建议）
4. 落库到 `ledgers/screener_ledger.md`（选股台账，供持仓分析 skill 回溯）

## 输出模板

```
=== 选股单 · 2026-XX-XX ·（主线：XXX）===
最终候选：1-2只
【1】XXX(代码) — 主线子线/预期差类型
  买点：回调至 X~Y 分批
  卖点：1个月目标 Z
  失效位：跌破 W(-15%) 认错退出
  建议仓位：轻仓，X成
【2】...（可选）
多空并列：多头依据 / 空头证据
风险提示：以上为全自动筛选的研究参考，不构成投资建议。
```

## 数据与证据纪律

- **自包含声明**：本 skill 的完整取数命令与全部条件阈值已封装在 `references/execution-details.md`，运行时按该文件执行，无需调用外部 skill。
- 数据走 `finance-free-data` 后端（腾讯/新浪实时 + akshare 财务 + 百度估值），**禁止凭空编数**。
- 缺失数据标 `[MISSING]`，不硬造；估算值注明"估算"。
- 分红清仓/坏消息：候选标的出现证据等级 S 的利空（如业绩暴雷、涨价函停发），自动剔除并说明。

## 台账落库

- 每次选股把"候选、买点/卖点/失效位、仓位、理由、证据等级"写入 `ledgers/screener_ledger.md`。
- 与持仓分析 skill 接口：持仓分析可读取本台账回溯"当时为何选它/买卖点是否兑现"，形成闭环。

## 与其他 Skill 分工

- 本 skill 依赖 `mainline-research` 的标的池与主线判断，**不重复做主线挖掘**。
- 本 skill 侧重"自动筛出具体票 + 买卖点"，**不做持仓复盘**（那是 simulated-portfolio-review 的活）。
