## 一、全球市场映射方法论

### 1.1 海外→A股传导四层分析法

```
① 改变什么预期 → ② 谁最受益、为什么 → ③ 资金是先手还是跟风 → ④ 逻辑能否持续
```

标注**传导链断裂点**，写明"哪一环必须验证"。

### 1.2 板块映射四层模型

| 层级 | 定义 | 映射等级 | 示例 |
|------|------|---------|------|
| L1 直接资产 | 产品/技术路线直接相关 | A | 国内同类管线/产品公司 |
| L2 同技术平台 | 同技术路线的beta | B | 平台型公司 |
| L3 产业链 | 服务该方向的CXO/设备/耗材 | C | 产业链服务方 |
| L4 情绪Beta | 无具体逻辑、只吃板块情绪 | D | 板块指数、ETF |

> 每个映射标的标注映射等级(A/B/C/D) + 上市地。港股映射单列。

### 1.3 消息泄露度分级（内部推理用，不写进报告）

| 消息类型 | 可泄露性 | 能否解释当日盘面 |
|---------|---------|----------------|
| 政策文件/会议纪要 | 高 | 可以，标注"存在提前交易迹象" |
| 产业订单/大客户/扩产 | 中高 | 可以，标注"存在抢跑可能" |
| 宏观数据 | 低 | 有限（只能解释"预期差"） |
| 美股隔夜收盘/美联储决议 | 极低 | 禁止倒推T-1盘中，只能用于T开盘预测 |
| 突发地缘/黑天鹅 | 极低 | 禁止倒推，只能事后归因 |

### 2.3 外媒小作文监测专区

收录范围：彭博/路透/FT/WSJ/CNBC关于中国资产的叙事性报道。每条展示六要素：标题+媒体+发布时间 / 核心摘要 / 类型标签 / 可信度评级+理由 / 涉及标的 / 证伪路径。

**事实层与叙事层分离**：可查证事实与媒体叙事框架须分开呈现。
**评级纪律**：外媒品牌不加分——"彭博发布"只证明传播力，不证明内容为真。

## 四、执行原则

1. 全部搜索不可跳过，关键类别执行2-3条
2. 中英文双语搜索，确保海外英文新闻不遗漏
3. 引用时标注来源（如"据彭博社报道"）
4. 海外事件必须有A股映射分析
5. 证据等级：高=有明确价格反应 / 中=有相关板块异动 / 低=仅为观点性表述
