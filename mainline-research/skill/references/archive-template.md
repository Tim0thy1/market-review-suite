# 10 字段主线档案模板 + 主线成因档案

每条主线保存一份独立档案（可存 `mainline-ledger/<主线索>/archive.md` 或台账内嵌）。字段随信息滚动更新，**每次更新须注明"证据等级 + 催化等级"**。

## 模板

```markdown
## 主线：XXX（某主线）

**① 市场环境**
- 指数环境：大盘趋势 __ / 风格环境 __
- 资金环境：成交额趋势 __ / 增量or存量 __
- 情绪阶段：__（冰点→修复→发酵→高潮→分歧→退潮）
- 环境结论：该主线当前给 __ 权重

**② 点火源**
- 主要点火：资金面切换 / 政策大厂 / 基本面传导
- 叠加引擎：已从 __ 换到 __（引擎切换记录）

**③ 主线真实性**
- 五维验证：A龙头__ B产业链__ C业绩__ D资金__ E时间__
- 标签：真主线 / 强题材 / 事件驱动 / 资金抱团 / 补涨线 / 跟风线

**④ 生命周期阶段**
- 起势 / 主升(初期·加速·末期) / 高位分歧 / 退潮 / 出局
- 上一次切换：__（日期·触发信号·证据等级）

**⑤ 产业链传导路径**
```text
环节A → 环节B → 环节C → 环节D   （价值传导方向）
```

**⑥ 当前传导进度**
- 环节A [已启动] 环节B [进行中] 环节C [进行中] 环节D [未启动]
- 传导验证依据（价格/订单/CAPEX，至少2项）

**⑦ 驱动变量**
- 基本面向：__
- 资金面：__
- 政策面：__
- 外生变量：美债/汇率/战争/关税等 __

**⑧ 预期差**
- 市场原有预期：__
- 最新信息实际：__
- 预期变化：超预期 / 符合 / 低于
- 股价反应：利好上涨 / 利好不涨 / 利好兑现 / 利空不跌
- 结论：高价值主线 or 预期已满

**⑨ 资金/情绪/拥挤度**
- 拥挤度风险分：-5 ~ 0
- 情绪阶段：__
- 增量资金：有 / 无（单日脉冲）

**⑩ 证伪与退出信号**
- 逻辑证伪（→出局）：__
- 阶段证伪（→降级）：__
- 交易证伪（→不追/等回调）：__

**⑪ 主线成因档案（v1.1 强制 · 中长线必做）**
> 为什么它成为主线？随日更/周更不断补厚，每次新增历史档位。

- 起源与点火：__（何时、因何事件/范式点火）
- 周期定位：__（当前处"叙事/业绩兑现/扩张/见顶"哪一段）
- 全球定价锚：__（A股映射的海外对标：龙头/指数/CAPEX）
- 为什么一直在传导：__（传导链每一环如何被相继点燃）
- 利润/估值结构变化：__（利润兑现到哪环、估值重估到哪段）
- 当前所处阶段/回调原因：__
- 历次里程碑（滚动补厚）：
  - YYYY-MM-DD：__（事件·影响环节·证据等级·对阶段影响）
```

## 示例：AI 科技长线（A股资本节奏版，非美股叙事）

> 校准口径：**不写"应用→芯片→设备"美股链**，以 A股真实资金/业绩验证的"载板及材料"链为骨架。

- ① 市场环境：大盘强势区、景气度风格主导 → 权重最高
- ② 点火源：基本面传导（中报集体兑现）+ 涨价周期
- ③ 真实性：A✓ B✓ C✓ D✓ E✓ → **真主线**
- ④ 生命周期：主升中段（"业绩+涨价+扩产"验证期）
- ⑤ 传导：电子布/铜箔/树脂 → 覆铜板(CCL) → PCB(高多层/HDI) ，旁支 MLCC、光模块/CPO
- ⑥ 进度：PCB[已兑现·最强] 覆铜板/电子布/铜箔[已兑现] MLCC/CPO[进行中] 半导体设备[未启动·候补]
- ⑦ 驱动：英伟达CAPEX、覆铜板/电子布/MLCC涨价、AI服务器PCB价值量放大、国产扩产
- ⑧ 预期差：中报集体超预期 → 高价值，但PCB主位预期已满，转向上游扩散/补涨
- ⑨ 拥挤度风险：-4（主位高位）；上游材料补涨位中等
- ⑩ 证伪：涨价见顶 / PCB龙头破位 / CAPEX转弱
- ⑪ 成因档案：源自2023大模型→算力军备竞赛；A股在"卖铲卖布"载板材料卡位；全球锚=英伟达CAPEX/费半；传导靠"价值量放大→中报兑现→涨价→扩产"逐环节点燃；第一期已立骨架，后续逐期补历史档位
