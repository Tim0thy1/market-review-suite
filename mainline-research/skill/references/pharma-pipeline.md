# 创新药管线追踪框架（打包自 innovative-drug-tracker）

> 主线挖掘涉及医药/创新药主线时，使用本文件追踪管线进展。

---

## 一、标准管线卡片

每个靶点/药物包含以下模块：

| 模块 | 要求 |
|------|------|
| 基本信息 | 靶点名称、适应症、作用机制(MoA)一句话 |
| 全球玩家 | 国际巨头 + 中国Biotech主要玩家 |
| 管线阶段表 | 按公司列：药物名称、企业、临床阶段、预计获批、最近更新 |
| 关键BD | License-out/out：交易对手、首付款、总里程碑、时间 |
| 最新进展 | 会议数据(ASCO/ESMO/EASD/AACR)、顶线结果、关键数据解读 |
| 业界评论 | 券商机构评论、估值判断、商业化预测 |
| 获批情况 | NMPA/FDA获批时间、适应症拓展 |
| 开发倾向 | 公司战略优先级、资源投入 |

---

## 二、数据要求

### 2.1 临床数据必须具体
写具体数字（ORR 28.1%、mPFS 6.8m、减重22.5%），禁止"数据良好"等模糊表述。

### 2.2 BD交易必须完整
首付款、里程碑总额、交易双方、交易时间、交易结构。

### 2.3 同类比较
同靶点不同管线横向对比：疗效数据、安全性、给药频率、目标人群、商业条款。

### 2.4 催化剂时间线
每条管线标注：下次数据读出时间、审批预期、关键里程碑。报告末尾汇总未来6-18个月催化剂时间线。

## 四、更新原则

- 普通管线/数据每3个月更新一次
- 重大突破（FIC获批、改变临床指南、亿级BD交易）立即更新
- 保留历史数据轨迹，每次更新标注变更内容

---

## 五、A股映射传导路径

```
海外临床突破/FDA批准
  → L1 直接资产：国内同类管线公司
  → L2 同技术平台：mRNA/LNP/ADC平台型公司
  → L3 产业链：CXO/CDMO/临床CRO/测序服务
  → L4 情绪Beta：创新药ETF、创业板、医药板块指数
```

> 每个映射标的标注映射等级(A/B/C/D) + 上市地。港股标的单列。

---

## 六、质量标准

1. 不遗漏关键管线，每个至少含临床阶段、最新数据、BD信息
2. 必须找到3个月内的最新数据
3. 同时记录成功和失败案例，不隐瞒阴性结果
4. 数据来源链接保留
