# 创新药管线追踪框架（打包自 innovative-drug-tracker）

> 主线挖掘涉及医药/创新药主线时，使用本文件追踪管线进展。
> 核心原则：临床数据必须具体（ORR 28.1%而非"数据良好"），BD交易必须完整。

---

## 一、标准管线卡片

每个靶点/药物必须包含以下模块：

| 模块 | 要求 |
|------|------|
| 基本信息 | 靶点名称、适应症、作用机制(MoA)一句话 |
| 全球玩家 | 国际巨头 + 中国Biotech主要玩家 |
| 管线阶段表 | 按公司列：药物名称、企业、临床阶段、预计获批、最近更新 |
| 关键BD | License-out/out：交易对手、首付款、总里程碑、时间 |
| 最新进展 | 会议数据(ASCO/ESMO/EASD/AACR)、顶线结果、关键数据解读 |
| 业界评论 | 券商机构对该管线的评论、估值判断、商业化预测 |
| 获批情况 | NMPA/FDA获批时间、适应症拓展 |
| 开发倾向 | 公司对该管线的战略优先级、资源投入 |

---

## 二、数据要求

### 2.1 临床数据必须具体

每个管线必须写入具体数字：
- ORR（客观缓解率）：如 28.1%
- mPFS（中位无进展生存期）：如 6.8个月
- 减重幅度：如 22.5%
- CDR-SB减缓：如 27%
- 安全性：AE/SAE发生率，特别是间质性肺炎ILD等关键信号

**禁止**使用"数据良好""疗效显著"等模糊表述。

### 2.2 BD交易必须完整

每笔BD交易必须包含：
- 首付款
- 里程碑总额
- 交易双方
- 交易时间
- 交易结构（首付+里程碑+销售分成）

### 2.3 同类比较

同靶点不同管线之间必须做横向对比：
- 疗效数据对比
- 安全性对比
- 给药频率对比
- 目标人群对比
- 商业条款对比

例如：Enhertu vs SHR-A1811 vs iza-bren 的HER2 ADC对比

### 2.4 催化剂时间线

每条管线标注：
- 下一次数据读出时间
- 下一阶段审批预期
- 关键里程碑

报告末尾汇总"催化剂时间线"（按时间排序），覆盖未来6-18个月。

## 三、分类组织

按治疗领域分类：

| 领域 | 主要靶点/方向 |
|------|-------------|
| 肿瘤 | ADC、KRAS、双抗、CAR-T、CLDN18.2、EGFR×HER3、B7-H3 |
| 慢病 | GLP-1减重、PCSK9/Lp(a)、糖尿病、高血压 |
| 眼科 | AMD、青光眼 |
| 阿尔兹海默 | Aβ、tau、疫苗 |
| 自身免疫 | IL-17、IL-23、JAK、BTK |

## 四、更新原则

- 普通管线/数据每3个月更新一次
- 重大突破（FIC药物获批、改变临床指南、亿级BD交易）立即更新
- 保留历史数据轨迹：每次更新标注变更内容

---

## 五、A股映射

创新药海外突破到A股的传导路径：

```
海外临床突破/FDA批准
  ↓
L1 直接资产：国内同类管线公司（如同类靶点/技术路线）
  ↓
L2 同技术平台：mRNA/LNP平台型、ADC平台型公司
  ↓
L3 产业链：CXO/CDMO/临床CRO/测序服务
  ↓
L4 情绪Beta：创新药ETF、创业板、医药板块指数
```

> 每个映射标的标注映射等级(A/B/C/D) + 上市地。
> 港股标的（如信达生物、石药）单列"港股映射"，不混入"A股受益标的"。

---

## 六、质量标准

1. **绝对详细**：不遗漏关键管线，每个管线至少包含临床阶段、最新数据、BD信息
2. **时效性**：必须找到3个月内的最新数据
3. **客观性**：同时记录成功和失败案例，不隐瞒阴性结果
4. **可追溯性**：数据来源链接保留
5. **增量维护**：支持持续更新，3个月内信息有效，过期更新
