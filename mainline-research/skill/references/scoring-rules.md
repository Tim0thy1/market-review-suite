# 主线强度评分规则

可复算的打分体系，替代"强/弱"模糊词。每维 0-5 分，需有数据判据锚定。

## 六维评分（满分 30）

| 维度 | 定义 | 4-5 分（强）判据 | 2-3 分（中）判据 | 0-1 分（弱）判据 |
|------|------|-----------------|-----------------|-----------------|
| ① 驱动强度 | 点火逻辑多硬 | 巨头CAPEX/政策文件/价格新高，S-A级证据 | 行业数据拐点，B级 | 仅有传闻/题材，C-D级 |
| ② 基本面兑现度 | 业绩是否落地 | 收入/利润/订单/CAPEX已兑现（S级），且加速 | 部分兑现、在爬坡 | 无业绩、纯预期 |
| ③ 产业链扩散度 | 是否多环节扩散 | 已从单一环节扩散上下游 ≥3 环节 | 扩散中 1-2 环节 | 单一环节未扩散 |
| ④ 资金认可度 | 增量资金持续性 | 主力/北向/ETF持续净流入，非单日 | 有流入但不稳定 | 单日脉冲或净流出 |
| ⑤ 龙头强度 | 龙头是否持续强 | 龙头持续强于指数、连板/趋势新高 | 龙头强势但波动大 | 龙头走弱、无领涨 |
| ⑥ 持续催化能力 | 催化能否续接 | 有财报季/政策窗/事件排期持续催化 | 偶有催化 | 无新增催化 |

## 拥挤度风险分（-5 ~ 0，单独一栏呈现）

| 状态 | 扣分 |
|------|------|
| 不拥挤 / 刚启动 | 0 |
| 有一定拥挤但早期 | -1 |
| 明显拥挤 | -2 |
| 拥挤但处上涨中段 | -3 |
| 高位拥挤 / 抱团极致 | -4 ~ -5 |

**关键**：强度分与拥挤风险分必须拆两栏。"强但拥挤(28/30, 风险-4)" 与 "强且刚启动(24/30, 风险-0)" 是完全不同交易机会——前者要等回调/控仓，后者可顺势。总单分不混。

## 示例

- AI（算力）长线：驱动5 / 兑现5 / 扩散4 / 资金5 / 龙头5 / 催化4 = 28/30，拥挤度高位 -4 → 净24但情绪结构为"强且拥挤"
- 券商中报（资金面点火）：驱动4 / 兑现5 / 扩散3 / 资金4 / 龙头4 / 催化3 = 23/30，拥挤度早期 -1 → 净22 "资金面启动、搭配兑现"
