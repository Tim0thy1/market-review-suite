# 催化剂等级 + 证据等级

信息不再一视同仁。两者结合决定"这条信息能否改主线档案"。

## 催化剂等级

| 级 | 含义 | 示例 |
|----|------|------|
| S | 改变产业盈利预期 | 巨头宣布几百亿 CAPEX |
| A | 改变订单/资本开支 | 大增单 / 扩产公告 |
| B | 改变市场预期 | 行业数据拐点 |
| C | 情绪催化 | 行业会议 / 协会支持发文 |
| D | 重复性消息 | 无新增量的旧闻 |

## 证据等级

| 级 | 来源 |
|----|------|
| S | 财报 / 公司公告 / 官方数据 |
| A | 监管 / 政策文件 / 龙头公告 |
| B | 高可信产业数据 / 权威媒体 |
| C | 券商研报 / 专业机构 |
| D | 媒体传闻 / 社交媒体 |

## 硬规则

1. 禁止仅凭 C/D 级信息直接修改主线档案。
2. C/D 级只能"新增观察信息"，不能"正式升级到主升阶段"。
3. 必须 价格 + 龙头 + 订单 + 产业数据 至少两项以上验证，才可改动档案阶段。
4. `信息 → 催化等级 → 影响哪个环节 → 改变哪个变量 → 主线阶段是否变化`。

## 示例

"某机构（C级）称 AI 存储可能涨价"：
- 催化剂等级=C，证据等级=C → 只记入"新增观察信息"。
- 不能据此把"存储"正式升级为主升。
- 待 价格(实价) + 龙头(公告/涨) + 订单(产业数据) 至少两项后，才可定"存储进入主升"。
