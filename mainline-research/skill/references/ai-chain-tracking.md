# AI/算力全产业链环节级跟踪框架（L0~L7 环节 · 话语层 · 利率锚）

> 定位：本文件回答"**AI/算力/科技这条链，每个环节分别怎么跟踪**"。原则沿用 `SKILL.md`：**K 线/资金是"结果与验证"，产业指标是"原因"**——每个环节都给独立于股价的跟踪口径。链上叠两个横向变量：**话语层**（投行研报/高管意见/KOL 网红发言，影响预期与节奏）与**利率锚**（美债/实际利率，影响估值与融资）。

## 一、链条分层总览（L0~L7）

```text
L0 算力资源/大宗层   电力·铜·玻纤·土地·能耗（实物约束，最上游）
L1 材料元件层       PCB/覆铜板/铜箔/电子布/MLCC/树脂/散热（→ ai-upstream-verification.md）
L2 芯片/算力硬件层   国产GPU·ASIC、HBM/存储、先进封装/载板、服务器整机
L3 网络互连层       光模块/光器件、交换机、AEC/DAC铜连接、光纤、CPO
L4 基建/IDC层       数据中心、液冷、电源/HVDC、柴发、变压器/电网接入
L5 算力云/租赁层     云厂商capex、算力租赁、租金、上架率（重资产高杠杆）
L6 模型/平台层      大模型、MaaS、API/token价格、开源生态
L7 应用层          Agent/办公/多模态/端侧AI（AI手机·眼镜·玩具）/爆款应用
横切① 话语层        投行研报 / 高管意见 / KOL网红（预期与节奏）
横切② 利率锚        美债/实际利率（估值分母 + 融资成本，见 §三）
```

**每层跟踪的统一骨架**：核心矛盾（这层行情由什么决定生死）→ 独立跟踪主指标（不看 K 线）→ 数据源/节奏 → 证伪信号 → A 股子线映射。映射仅示例，归属判定按 `mainline-split.md` "真核心产品"规则执行。

## 二、环节级跟踪指标

### L0 算力资源/大宗层（电力为最紧约束）

核心矛盾：算力扩张撞上实物约束（电/铜/土地）。跟踪见 `macro-darkline.md` 家族④。

| 指标 | 口径/数据源 | 节奏 |
|---|---|---|
| 电网投资与变压器/开关柜订单 | 国网/南网招标额、特高压中标（同比） | 月更 |
| 数据中心耗电量与电价 | 全社会用电量中数据中心占比、分区域电价、绿电交易 | 月更 |
| 铜/玻纤等大宗 | LME铜、电子纱价（成本端输入，接 `ai-upstream-verification.md`） | 日戳 |

证伪信号：电网投资增速回落 + 算力中心"限电/批文收紧"政策落地。

### L1 材料元件层（PCB/覆铜板/铜箔/电子布/MLCC）

**全部跟踪口径见 `ai-upstream-verification.md`**（涨价函密度、加工费、产能利用率、业绩兑现三张表）。此处仅提醒排序：电子布/玻纤是涨价传导**起点（先行）**，覆铜板是**中继**，下游 PCB 承接是**确认**。

### L2 芯片/算力硬件层（国产替代 × 海外供给）

核心矛盾：国产替代进度（流片→量产→批量装机）对冲出口管制；需求锚是国内智算中心建设。

| 指标 | 口径/数据源 | 节奏 |
|---|---|---|
| 国产芯片节点 | 流片/量产/装机节点、昇腾等发布会、大厂集采中标公告 | 事件更 |
| 海外供给变量 | 出口管制清单变化、英伟达对华特供版进展、台积电月度营收（全球需求温度） | 月更 |
| 存储/HBM | HBM 合约价、DRAM 现货价、长鑫链扩产进度 | 周更 |
| 先进封装/载板 | CoWoS 类产能与涨价、载板稼动率 | 月更 |
| 服务器 | 整机厂营收同比、智算服务器出货占比 | 季更（财报） |

证伪信号：大厂集采停滞 + 国产量产节点跳票 + 海外管制反而放宽（国产替代逻辑降速）。

### L3 网络互连层（离美元 capex 最近的环节）

核心矛盾：**海外云厂 capex → 订单量**；产品代际（800G→1.6T→CPO）决定份额与单价。

| 指标 | 口径/数据源 | 节奏 |
|---|---|---|
| 云厂 capex 指引 | 微软/Meta/谷歌/亚马逊财报电话会 capex 表述与上调幅度（话语层 A 级） | 季更 |
| 出货与订单 | 800G/1.6T 出货指引、龙头在手订单披露 | 季更 |
| 价格结构 | 光模块价格年降幅度（正常年降 10~15%；降幅骤扩=恶化，价格上涨=紧缺） | 季更 |
| 技术路线 | 硅光/CPO 产业化进度、AEC/DAC 渗透、液冷配套 | 事件更 |
| 需求先行 | 台积电 CoWoS 扩产、博通/Marvell 业绩（ASIC 侧需求） | 季更 |

证伪信号：云厂 capex 指引集体下修 + 1.6T 放量节奏低于预期 + 年降幅扩大至 20%+。

### L4 基建/IDC 层（供需看上架率与租金）

核心矛盾：供给（机柜/能耗批文）vs 需求（上架率/租金）；电价是成本锚。

| 指标 | 口径/数据源 | 节奏 |
|---|---|---|
| 上架率 | 智算中心上架率、新交付机柜去化速度（公司公告/调研） | 季更 |
| 租金 | A100/H100 等时租金/月租金趋势（算力价格指数、租赁平台报价） | 周更 |
| 订单/招标 | 智算中心 EPC/液冷/电源中标公告 | 事件更 |
| 液冷/电源渗透 | 液冷渗透率、HVDC/机架功率密度趋势 | 季更 |

证伪信号：租金连续下行（供给过剩）+ 上架率低于 60% 且无改善。

### L5 算力云/租赁层（利率敏感度最高的一环）

核心矛盾：供给过剩价格战 vs 真实上架；**重资产 + 高负债（负债率常 60%+），融资成本直接决定生死**。

| 指标 | 口径/数据源 | 节奏 |
|---|---|---|
| GPU 租金 | 主流卡型日/时租金趋势、与折旧回本线的距离 | 周更 |
| 上架率与合同 | 上架率、算力服务合同（公告口径，警惕框架协议≠收入） | 季更 |
| 资金链 | 负债率、发债/定增成本、利息保障倍数（**利率锚直接输入**） | 季更 |
| token 价格 | 推理 token 单价趋势（MaaS 侧，见 L6） | 月更 |

证伪信号：租金击穿回本线 + 定增/发债受阻 + "有卡无租"（上架率塌方）。

### L6 模型/平台层（能力迭代 + token 通缩）

核心矛盾：模型能力代际差与 token 价格下降速度；开源冲击闭源商业模式。

| 指标 | 口径/数据源 | 节奏 |
|---|---|---|
| 模型迭代 | 头部新模型发布、评测榜位次、多模态/Agent 能力节点 | 事件更 |
| token 价格 | 头部 MaaS API 价格调整（降价=应用繁荣前置信号） | 月更 |
| 生态数据 | 开源模型下载量/衍生模型数、开发者生态活跃度 | 月更 |
| 融资 | 头部大模型融资额与估值（一级温度计） | 事件更 |

证伪信号：token 价格战烧穿成本 + 头部融资断档（一级退潮）。

### L7 应用层（从题材到业绩的最后一跳）

核心矛盾：用户数 → 付费转化 → 收入兑现。多数"AI 应用"死在转化前。

| 指标 | 口径/数据源 | 节奏 |
|---|---|---|
| 用户与收入 | DAU/MAU、ARR、付费率、应用商店排名与榜单变动 | 月更 |
| 爆款出现 | 现象级 Agent/应用出现与留存（周留存>30% 才算真爆款） | 事件更 |
| 端侧渗透 | AI 手机/AI PC 出货渗透率、AI 眼镜销量（Meta 等出货锚） | 季更 |
| B 端落地 | 行业订单（法律/医疗/教育/广告），公告口径验证 | 季更 |

证伪信号：爆款留存崩塌 + 付费率<2% 长期无改善 + B 端续约率下滑。

## 三、利率锚 → AI 链传导（分层久期）

**信念**：利率对 AI 链不是一刀切，而是**按环节久期分层传导**——越靠下游（应用/模型）越像"长久期债券"，越靠上游（材料）越像"周期涨价资产"。

| 环节 | 利率敏感度 | 主导机制 |
|---|---|---|
| L7/L6 应用/模型 | 最高 | 现金流在后、纯估值定价，折现率↑直接杀估值 |
| L5 算力租赁 | 高 | 融资成本直接打利润与 capex（负债率 60%+） |
| L4 IDC | 中高 | 重资产杠杆，租金回报率 vs 资金成本的利差被压缩 |
| L3 光模块 | 中 | 有业绩支撑，但估值含成长溢价 |
| L2 芯片 | 中 | 国产替代叙事对利率钝化，但受风险偏好牵连 |
| L1 材料 | 较低 | 涨价与业绩对冲，主要由供需定价 |
| L0 大宗 | 反向 | 利率压制大宗价格，但 AI 需求增量对冲 |

**四条传导机制**：

1. **分母端贴现**：实际利率↑ → 折现率↑ → 长久期资产（L6/L7）估值压缩。
2. **融资成本**：AI 基建高度债务化（发债买 GPU、数据中心 REITs、租赁公司杠杆）→ 利率↑ → 扩张受抑。跟踪：AI 相关债券发行利率、租赁公司利息保障倍数。
3. **资金分流**：5%+ 无风险收益抬升高波动科技股的机会成本。
4. **capex 决策门槛**：云厂项目 IRR 门槛随利率上移 → capex 指引下修风险。

**2000 年教训（精炼）**：互联网链是真链（渗透率继续升），但思科/朗讯死于 ①电信 capex 债务化后砍单（盈利崩）②估值透支，**利率是触发器不是死因**。映射当下，盯两个健康度：云厂 capex 的资金来源（经营现金流 vs 发债）与 token 收入对算力成本的覆盖率。

**跟踪指标（日戳）**：10Y/30Y 美债、10Y TIPS、FedWatch 路径、国内 LPR 与利率债；**分层反应验证**——某轮利率上行中，若 L7 跌幅 > L5 > L3 > L1，传导即成立。与 `macro-darkline.md` §6.4 双受体（黄金 + AI 长久期）衔接。

## 四、话语层跟踪（投行研报 / 高管意见 / KOL 网红）

**信念**：话语**不改变事实，只改变预期与节奏**——但预期本身就是短中线的定价变量，且话语密度是情绪周期的温度计。三类源分级使用，不混同。

### 4.1 三源定级与三用法矩阵

| 话语源 | 证据等级 | 用法① 前瞻确认 | 用法② 预期差校准 | 用法③ 情绪温度计 |
|---|---|---|---|---|
| 投行研报（外资大行/A股卖方） | B/C | 上调出货/盈利预测 = 需求前瞻（B 级可入档） | 一致预期 = "市场预期"的代理变量 → 喂 `expectation-gap.md` | 集体翻多密度 = 拥挤；集体翻空 = 预期底 |
| 高管意见（财报会指引 A / 采访吹风 B） | A/B | 指引上调 = 订单前瞻（A 级可改档案） | 指引 vs 实际 = 预期差原料 | 高管频繁热搜"带货" = 过热 |
| KOL/网红/大V | D | 不采信 | 不采信 | 声量/搜索指数/涨停号密集度 = **反向**拥挤预警 |

采集对象（谁）：直接复用 `global-anchors.md` §二的 8 类必扫矩阵（科技领袖/投行/财经媒体/央行官员…），补充国内关键节点：字节（豆包推理量）、阿里/腾讯（云+AI capex 表述）、华为昇腾生态、DeepSeek（成本曲线）、头部卖方行业首席。

### 4.2 话语周期规律（五段，用于判断"话语走到哪了"）

```text
领袖前瞻言论（黄仁勋"需求疯狂"） → 投行研报跟进上调 → 财报/产业数据确认
  → 散户KOL扩散 → 网红带货式普及（末段信号）
```

话语密度见顶常领先或同步于情绪顶。**当"网红都在讲算力"出现时，配合 L1 材料普涨 + 蹭概念股满天飞 = 行情末段的组合证据**。

### 4.3 硬纪律

1. 话语与产业数据（S/A）背离时，以产业数据为准；话语只入"预期侧"。
2. D 级（KOL/网红）**永不改档**，只进情绪/拥挤度计量。
3. **高管行为 > 高管语言**：减持/增持/回购 > 财报会吹风；吹自家生态要折价处理。
4. 警惕利益动机并标注：高管有市值诉求、投行有持仓/承销、KOL 有带货——使用前先标动机再定权重。
5. 话语事件一律入 `evidence_lib.md`，标等级 + 用途标签（前瞻/预期校准/温度计）。

## 五、环节轮动与传导顺序（价值层 ≠ 股价层，分开记）

```text
价值层（需求信号，自上而下，慢变量）：
  云厂capex指引(话语层A) → 网络互连订单(L3) → 芯片/HBM(L2)
    → 上游材料涨价函(L1) → 应用繁荣(L7，token降价催生)

股价层（A股资金扩散，快变量，常见顺序）：
  国产替代叙事(L2) → 硬件业绩链(L3光模块/PCB) → 上游材料(L1)
    → 租赁/应用补涨(L5/L7) ；末段信号：L1普涨+蹭概念满天飞+KOL狂热
```

与 `SKILL.md`「主线内部轮动」六章呼应：传导进度记价值层，轮动阶段记股价层，**两层错位时（如价值层已到 L1 而 K 线还在 L3 龙头抱团）即是前瞻布局或减仓的决策点**。
