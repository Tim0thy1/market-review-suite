# 预期差模块

**市场炒的不是"好"，是"比市场预期好"。**

## 判定框架

```text
市场原有预期   市场认为会怎样？
最新信息       实际发生了什么？
预期变化       超预期 / 符合 / 低于
股价反应       利好上涨 / 利好不涨 / 利好兑现 / 利空不跌
```

| 预期变化 | 股价反应 | 解读 |
|---------|---------|------|
| 超预期 | 利好上涨 | 最强，主线确认 |
| 符合预期 | 利好不涨 / 兑现下跌 | 预期已定价，警惕兑现 |
| 低于预期 | 利好不涨 / 下跌 | 逻辑松动，降级 |
| 表面利空 | 利空不跌 | 利空已出尽，或逻辑强化 |

## 结论判据

- 基本面很好 + 预期已经很满 = **不一定是好交易**（利好兑现风险）
- 基本面改善 + 市场预期还低 = **高价值主线**（预期差向上）

## 使用规则

预期差应作为**主线评分的核心变量**之一（尤其影响"基本面兑现度 + 持续催化能力"两维）。
每次新增 S/A 级信息，重估预期差。

## 示例：AI 算力

- 市场原有预期：英伟达/巨头 CAPEX 高增但市场已较高price-in
- 最新实际：Q2 营收 +106%、数据中心 +117%、FY2028 指引 +70%（超预期）
- 预期变化：超预期
- 股价反应：盘后上涨（美股）
- 结论：核心硬件超预期 → 长线逻辑强化；但 A 股算力映射端拥挤度已升，属"强但需控拥挤"。
