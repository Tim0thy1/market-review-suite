# 台账格式（mainline-research 落库）

独立目录 `mainline-research/` 维护三类台账（升级原 `mainline_ledger.md`）。

## 目录结构

```
mainline-research/
├── ledgers/
│   ├── mainline_ledger.md     # 主线总台账（10字段核心表）
│   ├── catalyst_ledger.md     # 催化剂台账 A
│   ├── target_pool.md         # 标的池 B
│   └── evidence_lib.md        # 信息证据库 C
├── archives/                  # 每条主线的成因档案（可选，厚积累）
└── reports/                   # 周更 S0~S8 报告
    └── mainline-YYYYMMDD.html
```

## A. mainline_ledger.md（主线总台账核心字段）

```markdown
## YYYY-MM-DD

| 层级 | 主线 | 点火源 | 真实性标签 | 生命周期 | 传导到环节 | 强度/30 | 拥挤风险 | 预期差 | 证伪/退出 | 今日增量 |
|------|------|--------|-----------|---------|-----------|--------|---------|--------|----------|---------|
```

分层：长(年级)/中(季级)/短(周级)。每次更新注明证据等级。

## B. catalyst_ledger.md（催化剂台账）

```markdown
| 日期 | 信息 | 催化等级 | 证据等级 | 影响环节 | 改变变量 | 主线阶段变化 |
|------|------|---------|---------|---------|---------|-------------|
```

## C. target_pool.md（标的池）

```markdown
| 主线 | 标的 | 类别(龙头/卡位/弹性/验证) | 轮动位置(1-6) | 传导环节 | 证伪信号 | 状态 |
|------|------|--------------------------|---------------|---------|---------|------|
```

## D. evidence_lib.md（信息证据库）

```markdown
| 日期 | 原始信息 | 来源 | 证据等级 | 可信度 | 是否改动档案(原因) |
|------|---------|------|---------|--------|-------------------|
```

## E. archives/（主线成因档案 · v1.1 中长线厚积累）

每条中长线主线的成因档案（"为什么成为主线"）存放在独立文件：
`archives/<主线索>-archive.md`，按 archive-template.md 的 ⑪ 成因档案字段组织。
**每次日更/周更把新的历史档位（事件/订单/业绩/CAPEX/估值中枢）追加进去**，让论证越来越厚。

## 规则

- 日更增量更新，不重写全档；周更全量重构 + 排序 + 成因档案补厚。
- 证据等级 < B 的信息只入 evidence_lib，不改档案（催化剂台账里的阶段变化列留空或"仅观察"）。
