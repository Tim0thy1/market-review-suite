# 市场环境层判定（三级结构的顶层 · 双尺结构）

任何主线都必须先挂到市场环境层判断，脱离环境谈主线强弱的结论无效。

**关键原则（v1.3 新增 · 长度匹配）**：**环境层的尺度必须匹配主线的周期**。
- 研究 **短线（日/周级）主线** → 用「日线战术环境」（当日大盘/资金/情绪）。
- 研究 **中线/长线（季/年级）主线** → 必须用「全球战略环境」（全球流动性、地缘、中美产业投入），**禁止只用当天大盘**当成主线成立与否的依据。长线主线的权重由全球流动性 + 地缘成局 + 中美投入决定，而非当日涨跌。

---

## A. 日线战术环境层（短线·日/周级，原版保留）

### 指数环境
| 指数 | 观察 | 判定 |
|------|------|------|
| 上证 / 沪深300 | 趋势线 + 均线 + 量能 | 趋势上行 / 震荡 / 趋势下行 |
| 中证1000 / 创业板 | 小盘成长强度 | 偏好成长 or 偏好价值 |
| 科创50 | 科技权重映射 | 同步/领先/落后 |

判定口径：`20日/60日趋势 + 量能是否放大`。

### 风格环境
观测大类风格相对强度：大盘价值 / 小盘成长 / 科技 / 周期 / 医药 / 高股息。用风格指数或板块涨跌分化判定当前市场偏好哪一种，决定主线适配度。

### 资金环境
| 指标 | 意义 |
|------|------|
| 成交额趋势 | 放量/缩量 → 增量 or 存量博弈 |
| 北向/外资（可用替代指标） | 外部增量 |
| ETF 资金 | 被动增量 |
| 融资余额 | 杠杆资金方向 |
| 涨跌家数 / 涨停家数 / 连板高度 | 赚钱效应与情绪温度 |

### 情绪环境（六段）
`冰点 → 修复 → 发酵 → 高潮 → 分歧 → 退潮`
> 用途：决定同一条主线在当前环境给多少**当日追踪**权重。短线主线的节奏由这一层主导。

## B. 全球战略环境层（中长线·季/年级）

> **什么时候用**：任何**中线（季级）或长线（年级）主线**建档/周更时，必须先过这一层；它决定主线能走多远、该给多大权重，是"温和正确的战略背景"。
>
> **核心硬规则（v1.3 修订 · 关键）**：B 层是**开放扫描框架，不是固定模板**。上面的"流动性/地缘/中美/政策"等只是示例思路，**绝不是每次都要填的四项**。分析时你必须：
> 1. **先定义这条主线的专属环境透镜**——主动回答"跨季度/跨年驱动这条主线的最关键外部力量是什么"；
> 2. 从下方"宏观力量家族"中**挑选当下最相关的 2-4 个**，并**主动补充现有家族里没有的维度**（汇率/电价/库存/竞争格局变化/资本开支政策…不受此清单限制）；
> 3. **禁止**机械套用固定四项、照抄上一期结论。**环境维度本身是分析成果**，不是填空。

### 第一性命题

**一条中长线主线能否持续，取决于它是否踩在一组"跨季度/跨年仍在加大"的宏观力量上。** 环境层的任务 = 扫描这组力量的强弱与边际方向（是放大还是衰减/翻转）。

### 宏观力量家族（思考起点，可扩展，非封闭列表）

| 家族 | 观察点 | 典型"对主线"含义 |
|------|--------|---------|
| **F1 货币与信用周期** | 央行利率/点阵图、QE/QT 与资产负债表、信用脉冲（社融/M1）、收益率曲线 | 流动性宽松 → 成长/高估值主线扩张空间 ↑；紧缩 → 收缩 |
| **F2 实体经济与盈利周期** | GDP/PMI 趋势、库存周期（补库/去库）、产能利用率、盈利周期位置 | 顺周期主线看景气向上；逆周期主线看政策托底 |
| **F3 资金流与市场结构** | 全球/北向/南向资金、风险偏好(VIX)、机构持仓、ETF 发行、解禁/新股供给、风险溢价压缩 | 增量资金 → 主线持续性；存量 → 内部轮动 |
| **F4 政策与政治周期** | 大选/换届、产业政策、监管态度（鼓励 vs 收紧）、财政/债务空间 | 政策鼓励的方向获估值溢价；收紧的方向承压 |
| **F5 地缘与供应链** | 能源咽喉（霍尔木兹/红海）、出口管制、制裁/联盟、物流绕行成本 | 冲击高能源/高贸易依赖环节；塑造供应链再布局受益者 |
| **F6 技术范式/大国科技博弈** | 驱动主线的技术处于 S 曲线哪一段、双边技术上围堵、标准与生态锁定、双方资本开支 | 技术加速 + 双方同时加码 → 战略确定性最高 |
| **F7 气候与能源转型** | 碳约束、新能源政策、绿色资本开支、电价/碳价 | 决定能源/减排主线的长逻辑与成本结构 |

> 以上只是**提问起点**。分析每条主线时必须问：还有哪些这个家族表没覆盖、但对这条主线是决定性的力量？（例：对"过氧化氢/化工"看原料电价；对"存储"可能看云厂商资本开支而非央行利率；对"铜"可能看矿端供给与绿电资本开支，而非单纯地缘。）**表中无、但主线需要，就加上。**

### 维度生成启发式（用于"自己发明新维度"，非填空）

对任何候选维度用这 8 个钩子自检它是否成立：景气（向上/向下）、政策（鼓励/收紧）、资金（流入/流出）、技术范式（加速/证伪）、成本端（顺风/逆风：油价/汇率/利率/电价）、对手方资本开支（扩张/收缩）、估值与拥挤（极值/中位）、替代与颠覆（是否有新供给冲击）。**若某维度能被这些钩子解释、且对主线边际影响显著，就可作为下一个 B 层维度。**

### 判定与输出

- 每个采纳的维度记**方向（放大/衰减/翻转）**，不看单点高低。
- B 层结论 = 「哪些环境力量在放大 → 主线可持续；哪些在衰减/翻转 → 主线窗口收窄」。
- 每次输出必须标注"**本条主线采用的维度集 + 为什么选这几个**"，证明是推导而非套模板。

## 双尺联动（如何用）

```
判断每条主线周期 → 匹配对应环境层：
  短线主线   → A 日线战术层（决定当日进出/仓位）
  中线/长线  → B 全球战略层（决定能走多远/给多高权重）
              + A 日线战术层（决定何时上车/下车）
```

- **给权重**来自 B 层（每次为这条主线**主动推导的维度集**），**给节奏**来自 A 层（当日大盘/资金/情绪）。
- 默认评级模板需同时输出：`长线战略环境结论`（B层，含所选用维度）+ `日线战术环境结论`（A层），禁止只写当天大盘，禁止只写固定四项。
