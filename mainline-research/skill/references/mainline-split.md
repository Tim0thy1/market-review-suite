# 主线拆分（Mainline Split · 把泛概念主线拆成真实子线）

> **目的**：A股里很多概念很泛（如"光通信""医药""AI"），板块领涨 ≠ 里面所有公司是一条命。**拆分**就是把一条泛主线按"公司真核心产品/竞争力"拆成若干真实子线，再落到子线内的可操作标的与买卖位置。**不按券商概念标签归类，标签只当线索、不当结论。**

## 拆分不设固定层数，但**必须拆到"真实子线 + 可操作标的"**才算完成

```
Level 0  泛概念主线（概念板块，如"光通信"）
   ↓ 拆分① 真实子线     按公司核心产品/竞争力归线（光模块 / 光器件 / 光纤光缆 …）
   ↓ 拆分② 标的分档       龙头 / 卡位 / 弹性 / 补涨 / 候补，标各自轮动阶段
   ↓ 拆分③ 买点位置       合适位置买：回调位 / 支撑 / 赔率 / 催化时点 / 是否追高
   ↓ 拆分④ 卖点 / 离场    合适位置卖：目标位 / 主线阶段 / 失效位 / 交易证伪
```

> 拆到哪一层看问题需要，但**任何主流主线的分析都至少拆到"真实子线 + 标的分档 + 买卖位置框架"**；只看概念标题、不落到可操作标的和位置的输出，视为任务未完成。

---

## 拆分①：拆出真实子线 —— 归类看"真核心"，不靠标签

**核心规则：一个公司的归属 = 它真正赚钱/真正有竞争力的那个环节，不是它被贴的概念板块。** 泛概念下往往是几路子线 + 一批贴牌蹭概念的。

- 判据：公司主营产品、客户结构、产能/份额、研发卡点、真实业绩占比，确认"它到底靠什么活着"。
- 案例（光通信）：
  - **高速光模块（算力最相关）**：中际旭创（400G/800G/1.6T 数通光模块）、新易盛（高干线率，核心客户偏海外云厂商）
  - **光器件/平台**：天孚通信（光引擎、器件、连接器，偏器件平台）、太辰光（无源：MPO/MTP 高密度连接）、光迅科技（光芯片+器件+模块，偏国产自主光芯片）
  - **光纤光缆 + 更宽**：长飞光纤（光纤/光缆/特纤/数据中心）、亨通光电（通信+海洋+光器件+电力能源，超宽综合）
- **主动过滤蹭概念**：只沾边、没有核心产品与竞争力、纯贴标的一律剔除；虚头巴老的不算子线、不算标的分档。宁缺毋滥。
- **校准优先**：子线归属/板块真实领涨，用 A股板块涨幅 + 龙头行为 + 公司核心业务三重校准，不用某券商概念市值清单当结论。

## 多空交织（每个环节/标的都要"利好多空并列"）

只列多头逻辑必掉坑——"逻辑对"不等于"会一直涨"。**任何拆分的环节、标的、买卖判断，都必须两栏并列：**

| 多头（上涨依据） | 空头（反转/证伪/压制因素） |
|------|------|
| 景气/订单/涨价/业绩兑现 | 拥挤度过高/估值贵/连板加速 |
| 政策/资本开支/催化前 | 利好兑现见光 / 龙头破位 / 资金退潮 |
| 传导扩散到下一环 | 传导停滞 / 证伪信号（逻辑/阶段/交易三级） |
| 全球流动性友好 | 海外加息/美元走强/地缘升级 |

- 空头不是"唱反调"，而是**反转预案**：每条空头因素对应一个"什么情况下它主导行情"的开关，翻转向我要么降级、要么切到同线他子线。
- 买点判断必须在列全多空后做：多空并行但赔率好 + 位置不拥挤 → 可介入情景；空头短期占优 → 等回调/等反转信号。
- 输出里"风险/利空"不能是一句套话，必须具体到 该环节/该标的 的可观察信号。

## 拆分②：标的分档 —— 每只票在子线里的角色

对拆出的真实子线，把标的按真实核心环节分成几档：

| 档位 | 角色 | 特征 | 介入性质 |
|------|------|------|---------|
| 龙头 | 子线旗帜 | 强于指数、机构共振、最先启动 | 定方向，可能已高 |
| 卡位 | 强绑定环节 | 订单/业绩直接催化、确定性高 | 子线核心持仓带 |
| 弹性 | 高 β 补涨 | 市值小、题材纯度高、爆发强 | 回报空间大、波动大 |
| 补涨 | 落后待起 | 同子线但还没动 | 低吸、等轮动到位 |
| 候补/潜伏 | 下一棒 | 传导未到、位置低 | 埋伏、需等启动信号 |

> 每只票必须标注**当前轮动阶段**（龙头启动/核心扩散/中军跟随/补涨/末端高位），
> 与"传导进度（价值层）"分开记，防止把"还没轮到它涨"误当"逻辑坏了"。归属列不进去（无真实核心）的，直接剔除。

## 拆分③：买点 —— 合适位置买（介入情景，非指令）

**逻辑对 ≠ 现在就该买。** 买点看"位置 + 赔率 + 时机"三件事：

- **位置**：相对主升启动点的涨幅、距重要均线/筹码密集带的回撤深度、是否在高位拥挤区。
- **赔率**：向上空间（目标位-现价）与向下空间（止损位-现价）之比，<1.5:1 不划算。
- **时机/催化**：介入是否处于新一轮催化前（订单/CAPEX/业绩/涨价兑现日）。
- **追高纪律**：高位连板加速、龙头巨量滞涨 → 属"交易证伪"（见退出机制③），倾向等回调，不追。
- **分档各有介入节奏**：龙头看回调确认、卡位看业绩兑现、弹性看题材发酵、补涨看轮动到位、候补看启动信号。

## 拆分④：卖点 / 离场 —— 合适位置卖

- **目标/预期差兑现位**：子线走完预期的空间即兑现（预期差模块）。
- **主线阶段位**：主升→高位分歧（龙头破位/资金退潮/高潮缩量）→ 降级。
- **失效位**：逻辑/阶段/交易三级证伪（见 exit-mechanism.md），分别对应出局/降级/不追。
- **分批**：可 目标分批离场 + 逻辑失效全出，避免"落袋早了没吃到主升"或"死拿回吐"。

---

## 交割闭环

`看准主线 → 拆出真实子线 → 过滤蹭概念 → 分档选票 → 定买点 → 定卖点 → 循资本节奏分批介入/离场 → 兑现收益`

工具（建档/评分/传导/预期差）都只是帮这一步更准的辅助；**最终交付物是"合适位置买卖合适标的"的可操作框架，不是研究报告本身。**

## 合规（本 skill 统一口径）

- 不出现"建议买入/卖出"措辞；买卖一律写成**情景取向 + 条件框架**（"若回踩 XX 支撑且催化未兑现，则属可介入情景"）。
- 数据不可得标注"待补充"，不编造业绩/目标价/公司核心业务占比。
