# 《主线深度研究》报告模板（周更 S0~S8）

**视觉风格强制对齐 A股 复盘报告**（`A股复盘-YYYYMMDD/全景复盘_YYYYMMDD.html`），同一 UI 语言，用户一眼可辨识。

## CSS 基础（复用复盘报告 token）

```css
:root{--bg:#f7f8fa;--card:#ffffff;--ink:#1f2937;--muted:#6b7280;--line:#e8eaf0;
--primary:#1e40af;--up:#dc2626;--down:#16a34a;--amber:#d97706;--soft:#eef2ff;--softred:#fee2e2;--softamber:#fef3c7;}
```

- body：`#f7f8fa`，字体 PingFang SC / Microsoft YaHei / Noto Sans CJK SC，行高 1.7，底 60px
- `.wrap` max-width 1100px 居中
- header 顶部渐变色块 + `h1` 主色 + `.badge` 胶囊
- `.hero`（一句话）+ `.kpis/.kpe`（关键数字卡）
- `section` 卡片（白底 + 蓝边圆角）+ `h2 .no` 主色编号块
- `table` 斑马隔行 + `th` 浅灰底
- `.pill` 分级胶囊、`.warn/.good/.quote/.verdict` 侧边色块
- 折线/柱状用 ECharts（cdn.jsdelivr.net/npm/echarts），A股红涨绿跌

> 主色保持复盘一致：上涨红 `#dc2626`、下跌绿 `#16a34a`（A股习惯），不改成港股/美股配色。

## S0~S8 章节结构（每章一个 section，h2+`.no` 编号）

| no | 章节 | 内容要点 |
|----|------|---------|
| 0 | 市场环境 | 指数/风格/资金/情绪四维 + 环境给主线定权重 |
| 1 | 主线地图 | 长中短全览表：点火源/真实性标签/评分/层级 |
| 2 | 长线主线 | **主线成因档案(为什么成为主线)** + 范式/资本开支/传导全景 |
| 3 | 中线主线 | **主线成因档案(为什么成为主线)** + 景气/政策/订单/资金切换验证 |
| 4 | 短线主线 | 催化/情绪/资金接力 + 扩散可能性 |
| 5 | 预期差 | 各主线"牌面差"表格 + 高价值主线判定 |
| 6 | 标的池 | 龙头/卡位/弹性/验证 + 轮动位置 |
| 7 | 跟踪清单 | 每条主线的证伪信号 + 追踪节奏 |
| 8 | 台账落库 | 催化剂台账/证据库/升级降级记录/成因档案补厚 |

## S2/S3 中长线"为什么成为主线"强制论证（v1.1 新增）

**中长线跨度大，成主线理由必须横跨多个时间点/环节/催化来论证，禁止只写"当日热点 + 一句话逻辑"。** 至少覆盖以下维度（第一期允许立骨架 + 写明"后续如何积累"，但语义必须完整）：

1. **起源与点火**：这条主线最初因何事件/范式点火？始于何时？
2. **周期定位**：当前处于"叙事 / 业绩兑现 / 扩张 / 见顶"哪一段？用 1-2 个硬数据锚定。
3. **全球定价锚**：A 股映射对应的海外对标（龙头、指数、CAPEX）是什么？为何必须同步跟踪美股。
4. **为什么一直在传导**：传导链的每一环为何被相继点燃，而非一次性涨完。
5. **利润/估值结构变化**：利润兑现到哪个环节、估值重估到哪一段。
6. **当前所处阶段**：若回调，讲清触发（利好兑现/拥挤/情绪/海外）——区分"阶段证伪"与"逻辑证伪"。
7. **积累视角**：写明本段是第一期的哪部分骨架、后续日更/周更将如何补厚（新增历史档位）。

> 信息必须真实可溯（附证据等级）。数据不可得时写"待补充"，不编造。

## Header 区

- `h1`: `主线深度研究 · YYYY-MM-DD（周更）`
- `.sub`: 一句话结论（如"资金面切换点火·医药CRO中线接力 / AI长线基本面底盘持稳"）
- `.badge` 若干：当前主线数、最高分主线、市场情绪段等

## 内容规范

- 每条主线按 10 字段档案组织（市场环境/点火源/真实性/生命周期/传导/驱动/预期差/资金情绪/证伪）
- 中长线（S2/S3）额外展开"主线成因档案"论证块（见上节）
- 强度分与拥挤度风险分拆两栏展示
- 标的池标注轮动位置（①龙头~⑥尾部）
- 报告结尾固定风险提示 + 免责
- 生成后 `node --check` 校验内联 JS 通过再交付
