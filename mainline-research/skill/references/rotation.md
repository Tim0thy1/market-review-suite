# 主线内部轮动（股价层，与传导互补）

**传导进度（价值层）≠ 股价轮动进度（股价层）。** 两者分开记录，可错开。

## 六阶段轮动（股价层）

```
第一阶段  龙头启动       龙头先于板块走强，量价齐升
第二阶段  核心环节扩散   主线核心受益环节放量接力
第三阶段  中军跟随       板块中军（次龙头/权重）跟随
第四阶段  细分补涨       细分赛道、边缘环节补涨
第五阶段  低位轮动       低位滞涨股轮动补涨
第六阶段  末端补涨/高位抱团  一切非核心股轮涨，龙头滞涨 = 行情末端信号
```

## 每只标的标注（六类位置）

| 位置 | 含义 |
|------|------|
| ① 龙头 | 已启动 |
| ② 核心环节 | 主升 |
| ③ 中军 | 扩散 |
| ④ 弹性股 | 刚启动 |
| ⑤ 补涨股 | 未启动 |
| ⑥ 尾部股 | 过热 |

## 与传导进度错开的用法（判断力来源）

- 传导进度（价值层）告诉你"价值兑现到哪个环节"；
- 轮动进度（股价层）告诉你"股价炒到哪一段"。
- 一只"补涨股"可能价值传导刚启动但股价已过热；这才是真判断点，而非单看某一路。

## 仓位情景取向（非指令）

- 轮动早期（1-3阶）：主线确认中，低试错。
- 轮动中段（3-4阶）：延续逻辑，条件性持有。
- 轮动末段（5-6阶）：末端补涨+龙头滞涨 → 降敞口、防高位分歧。
