# 市场状态分析框架（打包自 market-trend-assessment）

> 本文件整合了大盘走势研判的三套分析路径，供主线挖掘时判断市场环境层使用。
> 三条路径互补：日频定节奏，周线定大方向，群体心理做拐点校验。

---

## 路径A：日频情绪与涨停梯队

按「量能→催化→结构→风控」四段式展开：

### A1. 量能判断 — 市场强度

依据 `changedist` + `market-overview --type updown,trade` 判定：

| 强度 | 特征 |
|------|------|
| 强势 | 涨停>80、连板高、跌停<10、成交放量 |
| 震荡 | 涨停40-80、涨跌各半 |
| 弱势 | 涨停<40、跌停>20、成交缩量 |
| 退潮 | 连板断崖、跌停潮、龙头大跌 |

### A2. 催化识别 — 主线挖掘

依据 `sector ranking` + `limitup_days` + `lhb` 判定：
- **真主线**：龙头持续强于指数 + 产业链扩散 + 资金持续增量
- **次级主线**：板块涨幅居前但扩散有限
- **脉冲**：单日涨停潮但无持续催化

### A3. 结构分层 — 涨停梯队

依据 `limitup_days` + `sector constituent` 分层：
- **龙头**（绝对高位）：连板最高、辨识度最强
- **中军**（核心环节）：跟风但量能充沛
- **补涨**（低位首板）：刚启动或跟风
- **后排**（中位股）：三进四/四进五，风险最高区

### A4. 风控定位 — 情绪周期 + 次日关注

### 情绪周期阶段速查

| 阶段 | 盘面特征 | 策略取向 |
|------|---------|---------|
| 冰点 | 涨停偏少、连板矮、跌停多 | 观望，等右侧确认 |
| 修复 | 龙头反包、炸板率降、首板增 | 低仓试错 |
| 主升 | 连板加速、板块扩散、放量 | 顺势持有确认主线 |
| 高位震荡 | 龙头分歧、后排掉队 | 降风险敞口、评估补涨质量 |
| 退潮 | 龙头大跌、跌停潮 | 防守，等冰点后再评估 |

> 写入报告时用「条件→观察→风险」表述，避免「必须满仓/清仓」口吻。

## 路径B：周线阶段模型（七阶段）

分析流程：读取阶段论 → 拉取指数/涨跌停/板块/资金数据 → 自下而上对照七阶段特征 → 输出当前阶段 + 证据链 + 分叉路径 → 仓位取向与应急预案。

### 七阶段速查

| 阶段 | 名称 | 仓位取向 |
|------|------|---------|
| 一 | 下跌到企稳 | 轻仓观察 |
| 二 | 超跌反弹 | 偏低仓、快进快出 |
| 三 | 真空期 | 中低仓、等方向 |
| 四 | 主线初期 | 逐步提高敞口（主线确认后） |
| 五 | 主线中期 | 高仓持有主升 |
| 六 | 主线末期 | 降低敞口、转防御 |
| 七 | 进入下跌 | 极低仓、等阶段一 |

### 预警信号

- 主线成交拥挤（板块成交额占全市场比例过高）
- 跌速榜持续放大
- 龙头回撤约 28%–33%
- 连板高度骤降 + 炸板率飙升

## 路径C：群体心理分析

### C1. 情绪周期六阶段定位

`绝望 → 怀疑 → 乐观 → 狂热 → 焦虑 → 自满`

### C2. 十种认知偏差群体检测

重点检测：
1. **确认偏误**：只看支持自己观点的信息
2. **锚定效应**：被近期高点/低点锚定
3. **羊群效应**：追涨杀跌的群体行为
4. **过度自信**：连续盈利后放大仓位
5. **损失厌恶**：亏损后不愿止损
6. **可得性偏差**：近期事件权重过高
7. **代表性偏差**：用类比代替分析
8. **处置效应**：卖赢持亏
9. **框架效应**：受表述方式影响
10. **从众效应**：盲目跟随 majority

### C3. 五大指标读数

| 指标 | 含义 | 极端信号 |
|------|------|---------|
| 拥挤度 | 主线成交额占比 | >15% 为拥挤 |
| 融资余额 | 杠杆资金 | 连续快增=高潮信号 |
| 换手率 | 交投活跃度 | 龙头换手>30%=过热 |
| 新高新低 | 市场宽度 | 新低>新高=趋势转弱 |
| 媒体情绪 | 舆论温度 | 全民看好=顶部信号 |

### C4. 聪明钱 vs 散户资金分化

- 聪明钱（北向/机构/龙虎榜席位）：提前布局/提前撤退
- 散户资金（融资余额/小单净流入）：滞后追涨/滞后杀跌
- **分化信号**：聪明钱持续流出但散户持续流入 → 顶部预警

> 极端信号须与价格结构、估值、资金流向交叉验证，不可单独作为交易依据。

---

## 使用原则

1. 三条路径可互补：日频定节奏，周线定大方向，群体心理做拐点校验
2. 多信号冲突时优先重视下行风险
3. 数据存在滞后（融资、部分资金流 T+1）；媒体情绪需甄别噪声
4. A股散户占比高、政策冲击大，情绪波动幅度通常大于美股
