# 三级退出机制

防止常见错误"主线逻辑还在，所以一直死拿"。**逻辑正确 ≠ 股价一直涨。**

## 三级退出

| 层级 | 触发 | 动作 |
|------|------|------|
| ① 逻辑证伪 | 产业逻辑本身坏掉：CAPEX下调 / 订单消失 / 政策取消 | **出局** |
| ② 阶段证伪 | 逻辑在但这一轮行情结束：龙头破位 / 资金退潮 / 高潮后持续缩量 | **降级** |
| ③ 交易证伪 | 主线没问题但当前买点错误：高位拥挤 / 赔率差 / 短线连续加速 | **不追 / 等回调** |

## 细分信号

### 逻辑证伪（→出局）
- 巨头/CAPEX 指引转向
- 核心订单消失、产品价格见顶回落
- 政策取消 / 监管收紧
- 传导停止扩散且出现反向

### 阶段证伪（→降级）
- 龙头跌破关键均线/前高，破位
- 资金持续退潮、高潮后连续缩量
- 板块内龙头滞涨、补涨后无接续

### 交易证伪（→不追/等回调）
- 高位拥挤度过高（评分风险 -4~-5）
- 赔率差（盈亏比不合适）
- 短线连续加速、情绪过热

## 台账记录

每次触发三级退出，必须：记录日期 + 触发层级 + 证据等级 + 原档案字段变化 + 新状态（出局/降级/观察）。
