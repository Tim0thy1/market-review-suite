# A 股主线深度研究（Mainline Deep Research）

## 核心定位

**主线 = 一条会被"点火、沿产业链传导、再被证伪"的动态链条，不是静态板块。**

本 skill 是"跨行业地把主线做成可运行闭环系统"的研究工具：判断 → 建档 → 信息冲刷 → 筛股跟踪 → 升级/降级/证伪/出局。要精读单个行业或公司时，下沉调用 `industry-chain-research` / `company-deep-research`。

**一句话**：从"今天有哪些热点"升级为"市场在炒什么 → 为什么炒 → 炒到哪了 → 哪些已兑现 → 哪些还没启动 → 哪些股值得跟 → 何时逻辑变坏 → 何时切下一条"。

## 触发条件（何时调用本 skill）

- 用户要求主线判断、主线挖掘、主线深度研究、长线/中短线跟踪
- 用户问"某条主线值不值得跟、现在到哪一步了"
- 需要构建/更新主线档案或主线台账（`mainline_ledger.md`）
- 需要生成《主线深度研究》报告（周更重构）
- 日常复盘已含"主线"章节，但用户要的是针对单条主线的跨时效深度，而非当日盘面

## 双节奏运行模式（强制先判节奏）

| 模式 | 频率 | 核心任务 | 产出 |
|------|------|---------|------|
| **日更** | 每个交易日收盘后 | 信息冲刷 + 主线状态变化 + 重大事件复核 | 增量更新 `mainline_ledger.md`（不重写全档） |
| **周更** | 每周末 | 全市场主线重构 | 新主线发现/旧主线淘汰/排序 + 完整 S0~S8 深度报告 + 三台账刷新 |

> 日更=轻量冲刷（增量更新存档），周更=全量重构（出整份报告 + 补厚积累）。两者任务不同，不得混用。

## 总控层：Mainline Decision Engine（决策流水线）

任何一条主线从发现到出局都走固定流水线，不靠"感觉"：

```
市场环境层      大盘/风格/资金/情绪 放背景里
   ↓
主线发现        三源点火：资金切换 / 政策大厂 / 基本面传导
   ↓
点火源识别      认清"靠什么点着的"（决定节奏）
   ↓
真实性验证      真主线 vs 题材（五维验证 + 打标签）
   ↓
生命周期判断    起势→主升→高位分歧→退潮→出局
   ↓
产业链传导      传导到哪一环 + 内部轮动到哪一段（两者分开记）
   ↓
预期差          市场预期 vs 实际 → 是"高价值主线"还是"预期已满"
   ↓
资金/情绪验证   是否持续增量，而非单日脉冲
   ↓
主线评分        6 维 0-5 分 + 拥挤度风险分（分开呈现）
   ↓
标的映射        龙头/卡位/弹性/验证 + 各自轮动阶段
   ↓
跟踪            五源信息冲刷，证据分级过滤（防被 C/D 级带跑）
   ↓
阶段变化        升级 / 降级 / 证伪 / 出局（三级退出）
   ↓
移交下一条主线
```

## 三级结构（所有分析必须挂在环境上）

```
市场环境层（大盘背景）     决定主线能走多远、给多少权重
   ↓
主线环境层（主线自身）     档案 + 评分 + 真实性 + 传导 + 轮动
   ↓
个股环境层（标的内跟踪）   龙头/弹性/补涨 + 买点与退出
```

**环境层分双尺（v1.3 强制 · 长度匹配）**，详见 `references/market-environment.md`：

```
A. 日线战术层（短线·日/周级）  当日大盘/资金/情绪  → 决定"何时上车/下车"（给节奏）
B. 全球战略层（中长线·季/年级） 一组"跨季度/跨年仍在加大"的宏观力量 → 决定"能走多远/给多高权重"
```

- **给权重看 B 层（开放扫描，非固定模板）**：研究中线/长线主线时，市场环境**禁止只用当天大盘**，也**禁止机械套用固定几项**（如流动性/地缘/中美/政策只是思考起点）。必须按"驱动这条主线的最关键外部力量"**主动挑选 + 发明维度**，可参考宏观力量家族（货币信用/实体盈利/资金结构/政策政治/地缘供应链/技术范式/气候能源等，见 `references/market-environment.md`），并主动补充表中没有的（汇率/电价/库存/资本开支政策…）。
- **给节奏看 A 层**：短线主线用日线战术层；中长线在 B 层给权重后，再用 A 层决定出入场点。
- 评级产出默认同时给「长线战略环境结论」（B，含所选用维度及理由）+「日线战术环境结论」（A）两行。

## 十字段主线档案（每条主线存一份，是判断的锚）

```text
① 市场环境         当前大盘/风格/资金/情绪背景（环境决定权重）
② 点火源           资金切换 / 政策大厂 / 基本面传导（可叠加，可换引擎）
③ 主线真实性       五维验证 + 真实标签（见 references/authenticity.md）
④ 生命周期阶段     起势→主升→高位分歧→退潮→出局
⑤ 产业链传导路径   价值传导链：先涨谁→后涨谁→扩散到谁
⑥ 当前传导进度     已启动 / 进行中 / 未启动（价值层，≠股价轮动）
⑦ 驱动变量         三引擎关键变量 + 外生变量（美债/战争/汇率等）
⑧ 预期差           市场预期 vs 实际 → 超预期/符合/低于（评分核心变量）
⑨ 资金/情绪/拥挤度  拥挤度风险分、情绪阶段、增量资金
⑩ 证伪与退出信号   逻辑证伪 / 阶段证伪 / 交易证伪（三级）
```

> **积累厚度要求（v1.1 新增，针对中长线的必做项）**：中长线主线跨度大，档案除上述 10 字段外，必须额外维护"**主线成因档案**"——即"为什么它成为主线"的多维度论证，随日更/周更不断补厚。详见 references/archive-template.md 的"主线成因档案"章节。**每次更新必须补入新的历史档位（事件/订单/业绩/CAPEX/估值中枢变动），让论证越来越厚，而不是每期重写一份薄报告。**

## 主线强度评分（可复算公式，不是"强/弱"模糊词）

```text
主线总分（满分 30）＝
① 驱动强度         0-5
② 基本面兑现度     0-5
③ 产业链扩散度     0-5
④ 资金认可度       0-5
⑤ 龙头强度         0-5
⑥ 持续催化能力     0-5
小计              /30

额外 + 拥挤度风险分（-5 ~ 0，单独呈现，不混入总分）
  拥挤但早期    -0~-1
  拥挤但高位    -3~-5
```

**必须"强度分"与"拥挤风险分"两栏拆开呈现**。"强但拥挤" vs "强且刚启动"是完全不同的交易机会。判据明细见 `references/scoring-rules.md`。

## 主线真实性五维验证（防止把题材当主线）

```text
A. 龙头验证    龙头是否持续强于指数？
B. 产业链验证  是否从单一环节扩散到上下游？
C. 业绩验证    收入/利润/订单/CAPEX 是否兑现？
D. 资金验证    是否持续增量，而非单日脉冲？
E. 时间验证    催化过去后，主线是否还能自己运行？

最终打标签：真主线 / 强题材 / 事件驱动 / 资金抱团 / 补涨线 / 跟风线
```

**反例**：机器人突然 10 只涨停 ≠ 已成为主线，可能只是消息刺激的短线题材。未过 C/D/E 验证最多标"强题材"。详见 `references/authenticity.md`。

## 主线内部轮动（股价层，与传导互补）

**传导进度（价值层）≠ 股价轮动进度（股价层），两个进度分开记录。**

```text
主线内部轮动（股价层）：
  第一阶段  龙头启动
  第二阶段  核心环节扩散
  第三阶段  中军跟随
  第四阶段  细分补涨
  第五阶段  低位轮动
  第六阶段  末端补涨 / 高位抱团

每条主线对每只标的标注：
  ① 龙头 已启动  ② 核心环节 主升  ③ 中军 扩散
  ④ 弹性股 刚启动  ⑤ 补涨股 未启动  ⑥ 尾部股 过热
```

详见 `references/rotation.md`。

## 催化剂等级 + 证据等级（信息不再一视同仁）

### 催化剂等级

```text
S级  改变产业盈利预期        巨头宣布几百亿 CAPEX
A级  改变订单/资本开支        大增单/扩产公告
B级  改变市场预期            行业数据拐点
C级  情绪催化                行业会议/协同发文
D级  重复性消息              无新增量的旧闻
```

### 证据等级（自动运行时防被带跑的关键）

```text
S级  财报 / 公司公告 / 官方数据
A级  监管 / 政策文件 / 龙头公告
B级  高可信产业数据 / 权威媒体
C级  券商研报 / 专业机构
D级  媒体传闻 / 社交媒体
```

**硬规则**：
- 禁止仅凭 C/D 级信息直接改主线档案。
- C/D 级只能"新增观察信息"，不能"正式升级到主升阶段"。
- 必须 价格 + 龙头 + 订单 + 产业数据 至少两项以上验证才可改动档案。

**自动处理链路**：`信息 → 催化等级 → 影响哪个环节 → 改变哪个变量 → 主线阶段是否变化`。详见 `references/catalyst-grading.md`。

## 预期差模块（评分核心变量）

市场炒的不是"好"，而是"比市场预期好"。

```text
市场原有预期   市场认为会怎样？
最新信息       实际发生了什么？
预期变化       超预期 / 符合 / 低于
股价反应       利好上涨 / 利好不涨 / 利好兑现 / 利空不跌

结论：
  基本面很好 + 预期已经很满 = 不一定是好交易
  基本面改善 + 市场预期还低 = 高价值主线
```

详见 `references/expectation-gap.md`。

## 三级退出机制（防止"逻辑对就一直死拿"）

```text
① 逻辑证伪   产业逻辑本身坏掉：CAPEX下调/订单消失/政策取消   → 出局
② 阶段证伪   逻辑在但这一轮行情结束：龙头破位/资金退潮/高潮后缩量 → 降级
③ 交易证伪   主线没问题但当前买点错：高位拥挤/赔率差/短线连续加速 → 不追/等回调

核心：逻辑正确 ≠ 股价一直涨。
```

详见 `references/exit-mechanism.md`。

## 三大点火源判别（决定追踪节奏的根因）

建任何一条主线前，先回答"它靠什么点着的"：

| 点火源 | 典型 | 节奏 | 证伪信号 |
|--------|------|------|---------|
| 资金面切换 | 创新药/CRO | 中线，先点火后验证 | 估值洼地填平 + 拥挤度再升，跟风盘证伪 |
| 政策/大厂驱动 | 商业航天/机器人 | 短线题材波 | 政策兑现 + 大厂动作停滞 → 预期断档回落 |
| 基本面传导 | AI/有色 | 长线主导 | 业绩/资本开支不及预期，传导不再扩散 |

**三时域分层与节奏**（呼应"长中短时间内重点不同"）：

| 层级 | 底盘 | 复盘 | 追踪 | 重点 |
|------|------|------|------|------|
| 长线(年级) | 基本面传导 | 月 | 年 | 资本开支/范式/传导扩散/成因档案演进 |
| 中线(季级) | 资金面切换最多 | 周 | 季 | 拥挤度/估值分位/流向拐点/成因档案演进 |
| 短线(周级) | 政策/大厂点火为主 | 日 | 周 | 催化/情绪/资金接力 |

建档后不断用五类信息冲刷，任一命中即复核"阶段 + 传导 + 证伪点"：

```text
⑤ 研报/外资  预期拐点信号 → 聪明钱方向
```

## 报告结构（周更 · S0~S8 · 单独深度报告）

| 章节 | 内容 |
|------|------|
| S0 市场环境 | 指数/风格/资金/情绪四维，给主线挂背景 |
| S1 主线地图 | 长中短主线全览 + 点火源 + 真实性标签 + 评分 |
| S2 长线主线 | **主线成因档案(为什么成为主线)** + 范式/资本开支/传导全景 |
| S3 中线主线 | **主线成因档案(为什么成为主线)** + 景气/政策/订单/资金切换验证 |
| S4 短线主线 | 催化/情绪/资金接力 |
| S5 预期差 | 各主线"牌面差"，谁是高价值主线 |
| S6 标的池 | 龙头/卡位/弹性/验证 + 轮动阶段 |
| S7 跟踪清单 | 证伪信号 + 追踪节奏 + 预期差跟踪 |
| S8 台账落库 | 催化剂台账 / 证据库 / 升级降级记录 / 成因档案补厚 |

> **S2/S3 强制项**：长线、中线的"为什么成为主线"必须有厚度论证——至少覆盖：起源与点火、周期定位（当前处哪段）、全球定价锚、为什么一直在传导、利润/估值结构变化、当前所处阶段与回调原因。第一期允许"立骨架"，但必须写明"后续将如何积累补厚"。HTML 视觉风格与 A股 复盘报告一致（见 references/report-template.md）。

## 落地为 Agent 的三条规则（自动维护台账的前提）

1. **打分规则**：6 维每档 0-5 需有明确判据（数据锚定，见 scoring-rules.md）。
2. **升级/降级规则**：文档写明触发阈值 + 证据强度要求。
3. **信息触发规则**：按催化剂等级 + 证据等级决定"观察 or 修改档案"。

## 输出约定

- 日更：增量更新 `mainline_ledger.md` + 聊天摘要。
- 周更：完整 `S0~S8` HTML 深度报告（风格对齐复盘）+ 台账刷新 + 成因档案补厚 + 聊天摘要 + 文件链接。
- 发布前 `node --check` 校验内联 JS；含图表才校验，纯文字可省略。
- 文末固定风险提示：「以上分析基于公开数据，不构成投资建议。仓位与操作须自行决策并自担风险。」

## 独立验证原则（强制 · v1.1 新增）

**用户或外部提供的传导范式、因果链、主线归属，一律视为"待验证假设"，不是权威前提。** 在引用进主线档案/报告前，必须先做逻辑与事实校验：

1. **校验维度**：主体是否一致（A 的业绩能否传导到 B 的收入）、计量是否匹配（交易/融资金额 ≠ 外包服务订单）、量级是否对得上、是否存在第三方催化才是真正驱动。
2. **校验手段**：用 S/A 级证据（财报、订单、官方数据、龙头行为）交叉验证；数据不可得或逻辑不闭环时，标为"存疑/待验证"，不写进结论。
3. **反例教材（医药/CRO）**：`创新药BD授权量（License-out对价）→ CRO业绩` 是量级错配——BD是授权方的变现对价，主体与计量和 CRO 的服务收入不同，不能直接传导。CRO 的基本面底座应以"全球创新药研发回暖（利率下行→biotech融资→研发投入）→ CXO订单 + 地缘订单转移"为准。
4. **校准优先（A股资本节奏）**：传导链必须以 **A股实际资金/股价验证的环节**为骨架，而不是照搬美股产业叙事。例如 AI 线在 A股最强的资金主线是 **PCB / 覆铜板(CCL) / 电子布 / MLCC / 铜箔 / 电子树脂**（"AI载板及材料"链），不是美股那套"应用→芯片→设备"。任何传导链在写入前，须用 A股 板块涨幅 + 龙头行为校准，标注"已兑现环节"与"待启动环节"。
5. **边界**：即便用户断言某条因果，Agent 未独立校验通过也不得作为主线核心逻辑；最多作为"候选假设 + 待验证"呈现。

## 合规

- 不使用"建议买入/卖出"措辞；仓位表述为**情景取向**、写成条件框架。
- 不编写造数据；数据不可得时标注"待补充"。
