# A 股每日收盘全维复盘

## 能力概览

本 skill 提供 A 股收盘后的完整复盘能力，覆盖三条模式（盘前预测 / 盘中概览 / 收盘复盘）与多条深度分析路径。
数据统一经 4 个可信 skill 获取，不依赖外部 API 或 WebSearch。

**输出格式由客户端类型自动决定**：电脑客户端（内置浏览器可浏览 HTML）→ 生成自包含 HTML 报告；手机 App（暂不支持 html）→ 直接输出文字版（Markdown 纯文本）。见「输出格式自动判断」章节。

> **输出约定**：交付后聊天中只给摘要 + 文件路径；含图表的报告须 `node --check` 通过后再交付。
> 遵守 wb-finance 硬约束；复盘章节结构见 `references/html_report_style.md`（可按分析路径微调配色）；
> 热点速览为橙红脉冲风格，见 `references/hotspot_report_template.html`。
>
> **加载顺序**：金融场景先加载 `wb-finance-skill` 读红线与时区口径，再调 westock / neodata 取数。

## 输出格式自动判断（强制 · 先于一切分析）

> **⛔ 硬性规则**：Agent 在开始任何数据采集、模式判定、分析写作之前，**第一步必须先判断本次复盘指令来自哪个客户端**。判断错误会导致输出格式不符（把 HTML 发给不能浏览的手机，或把文字版发给想看图表的电脑），因此本规则强制优先执行。

### 判断依据（从用户指令本身识别）

| 判断信号 | 判定为电脑客户端 | 判定为手机 App |
|---------|-----------------|---------------|
| **指令明示** | 用户说"生成网页/HTML报告/图表/浏览器看" | 用户说"文字版/不要HTML/手机上看/纯文本" |
| **指令载体特征** | 在聊天中输入长结构化指令、引用文件路径、要求"可视化/图表/报告" → 倾向电脑 | 用户提到"手机上/App/打开不方便/看不到网页" → 倾向手机 |
| **历史行为** | 用户过往对 HTML 报告有正向反馈、要求生成报告文件 | 用户过往要求"直接输出文字/太长了/手机看" |
| **上下文痕迹** | 会话中涉及 `computer://` 链接、报告文件目录、浏览器预览 | 会话要求"精简/压缩/手机友好" |

**核心判断原则**：
1. **用户指令明确时，以用户明示为准**（用户说"文字版"就输出文字，说"HTML"就输出HTML）
2. **用户未明示时**：若无任何手机线索，默认按**电脑客户端**处理（输出 HTML 报告，附带 `computer://` 文件链接）；若指令中出现手机相关线索（"手机""App""打开不方便""看不到网页"），则按手机处理，**直接输出文字版 Markdown，不生成 HTML 文件**
3. 当从对话上下文中能判断出用户设备时，跟随上下文的稳定推断

### 两种输出模式的分工

| 模式 | 适用客户端 | 交付物 | 特点 |
|------|-----------|--------|------|
| **HTML 模式** | 电脑客户端（内置浏览器） | 自包含 `.html` 文件（ECharts 图表） | 可视化、图表丰富，交付 `computer://` 链接 + 聊天摘要 |
| **文字版模式** | 手机 App（暂不支持 HTML） | 纯文本 Markdown（直接展示在聊天中） | 信息密度高、可一键复制，图表用文字/表格代替 |

### 文字版模式的写作要求

当判定为手机 App（文字版）时，**必须完整保留 16 章分析框架的全部维度**，只是以纯 Markdown 文字方式呈现而非 HTML：

- **16 章为"最大模板"，按动态折叠机制执行**：核心骨架章节（零/一/三/十五/8.7/十六）永远存在，条件模块按当日信息量自动启用/折叠（见「动态折叠机制」）。文字版与 HTML 版的区别仅在呈现形式，不在分析深度
- **图表转表格**：HTML 中的 ECharts 折线图/柱状图/雷达图，在文字版中改为 Markdown 表格呈现（指数数据用表格、涨跌幅排序用表格、多空辩论用结构化文字）
- **HTML 卡片转 Markdown 段落**：HTML 中的数据卡片、结论卡片，在文字版中改为 `###` 标题 + 加粗关键数据 + 连续自然段
- **核心分析章节（章零、一、二、三、五、七、十五）使用连续自然段**：一个完整逻辑链写成一个段落，避免一句话一个段落的碎片化
- **每个事实/结论只讲一次**：不同章节之间不重复同一数据点，章一讲过的数据章五引用时一句话带过
- **因果传导链保留**：每条关键新闻的归因仍须讲清四层（改变什么预期→谁受益为何→资金先手还是跟风→逻辑能否持续），用连贯自然段呈现
- **盘前预测模式同样适用**：10 段结构（S0~S9）完整保留，每段内容不缩减，只是以 Markdown 文字呈现（S9 预测台账用 Markdown 表格）

## 交易日检查

开始任何数据采集前，先判断目标日期是否为 A 股交易日。周末或中国法定节假日（A 股休市）时，告知用户「今日休市，无交易数据」，停止后续流程。

## 数据采集流程（所有分析路径共用）

以下为基础数据采集步骤，按需取用。

### 指数行情与市场广度

```bash
# 核心指数批量行情（上证/深证/创业板/科创50/上证50/沪深300/中证1000/中证500/中证红利/北证50）
westock-data quote sh000001,sz399001,sz399006,sh000688,sh000016,sh000300,sh000852,sh000905,sh000922,bj899050 --raw

# 市场总览（含成交额、风格轮动、估值画像）
westock-data market-overview --type trade,rotation,valuation --raw

# 涨跌分布（涨停/跌停计数首选来源）
westock-data changedist --raw

# 两融余额多周期变动
westock-data market-overview --type margin
```

### 板块排行

```bash
# 行业涨幅 + 概念涨幅 + 资金流入 + 北向热门板块
westock-data sector ranking --raw

# 板块热度排名（搜索/讨论度）
westock-data hot board
```

### 涨停板与连板梯队

```bash
# 连板天梯
westock-tool ranking limitup_days --limit 50

# 涨停封单量排行
westock-tool ranking limitup_seal_volume --limit 30

# 跌停排行（连续跌停天数 + 封单量）
westock-tool ranking limitdn_days --limit 20
westock-tool ranking limitdn_seal_amount --limit 20
```

### 龙虎榜与资金流向

```bash
# 机构榜 + 游资榜
westock-data lhb --type institution,hotmoney --raw

# 近期龙虎榜股票池
westock-tool event longhu_statis_past_15

# 北向资金（个股维度）
westock-data fund flow <代码>
```


### 国家队护盘信号监控（宽基ETF + 券商银行）

> 国家队（汇金/证金等）护盘通常通过宽基ETF大额申购和拉升券商/银行板块实现。以下命令采集关键信号数据。

```bash
# 宽基ETF实时行情（规模最大的6只宽基ETF）
westock-data quote sh510300,sh510330,sh510050,sh510500,sh512100,sh588000,sh159915 --raw

# 宽基ETF资金流向（主力净流入/流出）
westock-data fund flow sh510300,sh510050,sh510500,sh512100,sh588000,sz159915

# 券商ETF + 银行ETF行情与资金流向
westock-data quote sh512000,sh512800 --raw
westock-data fund flow sh512000,sh512800

# 券商板块 + 银行板块行情（申万行业）
westock-data search 券商 --type sector
westock-data search 银行 --type sector
# 拿到板块代码后：
# westock-data sector info <券商板块代码>
# westock-data sector info <银行板块代码>
# westock-data fund flow <券商板块代码>
# westock-data fund flow <银行板块代码>

# 宽基ETF近期K线（判断是否有持续放量申购痕迹）
westock-data kline sh510300 --period day --limit 10
westock-data kline sh510050 --period day --limit 10
```

**国家队护盘识别逻辑**：

| 信号 | 判定条件 | 强度 |
|------|---------|------|
| 宽基ETF异常放量 | 单只宽基ETF成交额 > 近5日均值2倍 | 中 |
| 宽基ETF持续净流入 | 连续3日主力净流入且日均 > 1亿 | 中 |
| 多只宽基ETF同步流入 | >=3只宽基ETF同日主力净流入 | 强 |
| 沪深300ETF + 上证50ETF双流入 | 510300和510050同日净流入 | 强（汇金经典操作） |
| 券商板块异动拉升 | 券商板块涨幅 > 1%且资金净流入 | 中 |
| 银行板块逆势走强 | 大盘下跌但银行板块上涨 | 中 |
| 券商+银行双拉升 | 两板块同日涨幅 > 0.5%且资金净流入 | 强 |
| 尾盘集中放量（盘中模式） | 14:30后宽基ETF成交额突然放大 | 强（尾盘护盘信号） |

> 当 >=2个「强」信号或 >=3个「中」信号同时出现时，可判定为「国家队护盘信号明显」，在报告中单列提示。

## 盘前预测模式（核心新增 · 时间因果与消息泄露度）

> **⛔ 本模式是全新升级，核心是「时间因果」+「消息泄露度」双判断。** 旧版把「盘后才发布的新闻 / 隔夜美股」一律排除在当日归因之外，这过于绝对——实际上**部分消息在发布前就可能被"聪明钱"抢跑**（提前泄露），资金确实会提前埋伏。正确做法不是一刀切禁用，而是**分级判断每条消息的可泄露性**，再决定能否用它解释当日盘面。

### 时间因果铁律（基线）

| 你要回答的问题 | 只能使用哪个时间窗的信息 | 说明 |
|--------------|------------------------|---------|
| 昨日（T-1）为何上涨/下跌 | T-2 盘后 → T-1 开盘前已公开的信息 | 这是当日资金决策的确定依据 |
| 今日（T）开盘预测 | T-1 收盘后 → T 开盘前（隔夜美股、盘后政策、早间消息） | 今日预测的确定Trigger |
| 今日（T）全天推演 | T-1 状态(State) + 隔夜触发(Trigger) → 推演 T 资金响应(Flow) | 预测主线 |

### 消息泄露度分级（在本铁律之上·智能豁免）

**核心逻辑**：若某条"盘后才正式发布"的消息，其**核心内容在盘前已可被提前获知**（存在泄露渠道），则它**可以**用来解释当日盘中的提前反应；反之，若消息真正无法提前预知，则禁止用它倒推当日盘面。

| 消息类型 | 可泄露性 | 能否解释当日盘面 | 判断依据 |
|---------|---------|----------------|---------|
| **政策文件/会议纪要**（如央行货币政策报告、国常会通稿） | 高（起草/审阅/吹风阶段易泄露，卖方会提前路演） | **可以**，需标注"存在提前泄露可能" | 观察盘前是否有资金提前潜伏相关板块、板块是否在消息发布前已异动 |
| **产业订单/大客户/扩产**（如SK海力士扩产、阿里云超节点） | 中高（产业链公司/调研纪要/卖方覆盖会提前知情） | **可以**，需标注"存在抢跑可能" | 看相关个股是否在消息前已有资金布局、是否逆势走强 |
| **宏观数据**（CPI/PMI，官方定时发布） | 低（有严格保密，但市场有预测共识） | 有限（只能解释"预期差"导致的波动） | 看实际值 vs 市场一致预期的偏离 |
| **美股隔夜收盘/美联储决议** | 极低（A股无法提前知道，只能盘前反应） | **禁止**用于解释T-1盘中，只能用于T开盘预测 | 时间上T-1盘中时美股尚未收盘 |
| **突发地缘/黑天鹅**（如突发冲突、单交易日爆雷） | 极低（无法预知） | **禁止**倒推，只能做事后归因 | 无法提前埋伏 |

**操作原则**：
1. 基线是"昨日走势看昨晨已公开信息、今日预测看隔夜信息"
2. **内部评估、外部呈现**："可泄露性""抢跑"是分析者在**内部推理**时评估资金有无可能提前知情用的，**不要把"可泄露性""泄露度""有抢跑可能"等词写进报告**。报告只呈现判断结果和证据
3. **呈现方式**：当判断资金在某消息发布前已先手买入时，直接写"资金在消息公开前已提前潜伏/布局，从某板块某时点逆势走强可见"，并给出证据；不用解释评估过程
4. **不豁免**：美股隔夜收盘、突发黑天鹅等真正无法提前预知的，归入"今日预测Trigger"，不倒推昨日盘中
5. 判断标准是**消息发布前资金有无可能提前知情**，而非消息发布时间本身

### 报告结构（盘前预测，10 段骨架 + 4 个增强小节）

> **设计哲学**：报告不只是"解释今天可能怎么走"，而是一个**会被市场打脸、也因打脸而变强的预测系统**。每一段都要为"明天的验证"服务——预测值可对答案、概率可校准、判断可归因。

> **三个增强小节（机构晨报方法论移植，硬性必写）**：S1.5 盘前观点（叙事层：四段式连贯观点，对应机构"早评"）、S2.5 行业快讯板（广度层：全行业信息覆盖，对应"新闻速递"）、S4.5 热点深追（产业层：产业链拆解+拐点诊断，对应"热点追踪"）。三者与 S0~S9 骨架互补：骨架管结构化预测与验证，增强小节管叙事连贯性、信息广度与产业深度。另增 **S2.6 外媒小作文监测**（外媒叙事层：彭博/路透级大机构中国资产报道的可信度分级专区，硬性必写）。

1. **S0 · 执行摘要（Executive Summary）**：5 行以内。
   - 市场状态一句话（如"恐慌后首日修复窗口"）
   - 今日核心判断（偏多 / 震荡 / 偏空）
   - 最大变量（如"医药能否承接隔夜催化"）
   - 最大风险（如"昨日板块已+9%，高开兑现"）
   - 最重要的 3 个观察信号

2. **S1 · 市场状态（Market Regime）**：市场处于什么阶段，六维状态标签，每个标签必须由数据支撑：
   - **趋势**：下降 / 震荡 / 上升（20日线方向 + 指数相对20日线位置）
   - **波动**：低 / 中 / 高（近3日振幅均值 vs 20日均值）
   - **情绪**：冰点 / 修复 / 发酵 / 高潮（涨跌家数、涨停跌停比、连板高度、炸板率）
   - **风险偏好**：risk-on / neutral / risk-off（成长vs价值相对强弱、小盘vs大盘）
   - **风格**：大盘/小盘 × 成长/价值（风格指数相对表现）
   - **资金**：增量 / 存量博弈（成交额趋势 + ETF净申赎 + 融资余额变动）
   - 附**昨日收盘速览**（指数、量能、涨跌停、主线），只陈述事实，归因简略
   - **估值分位必须是决策变量**：写了"PE 95%分位"就必须回答它对今明两天方向意味着什么（如"估值约束中期弹性，但历史上极端超跌反弹阶段估值分位对3日方向解释力弱"）。落不到决策上的漂亮数字直接删掉

2a. **S1.5 · 盘前观点（Morning View · 机构早评式叙事）**：报告唯一的**连贯叙事章节**，供"愿意读3分钟"的用户建立今日观盘框架。固定四段式，每段80~150字，总篇幅≤600字，使用连续自然段：
   - **第1段 · 海外锚点**：隔夜海外发生了什么 → 宏观环境定性（风险偏好方向）→ 对今日A股的传导方向。不是罗列美股涨跌，而是把海外事件翻译成"对A股风险偏好的方向性影响"（如"美股调整但属预期内，传导偏中性"）
   - **第2段 · 盘面定性**：量价+技术位双重锚定。必须使用「量价定性词典」给出定性（缩量上涨/放量滞涨/高位缩量整理等），必须落到具体技术位（5日线/10日线/20日线点位、平台区间、年线），禁止"市场可能震荡"式无锚表述
   - **第3段 · 结构行为**：资金在板块间的行为模式——高低切换、跷跷板（谁在吸金谁在失血）、补涨/补跌、主线与权重的对冲关系。回答"钱在怎么轮动"
   - **第4段 · 今日取向**：风格取向判断（重指数还是重个股 / 进攻还是防守 / 垃圾时间）+ **至少一个条件分支句**（"若今日放量收复X点则回到进攻态势；若缩量跌破Y则整固延长"）
   - **写作纪律**：①每段以判断句开头（敢下结论，"垃圾时间多看少动"也是合法结论）；②不罗列数据（数据在S0/S1已有，这里是解读）；③不给仓位建议（硬约束），只给风格取向；④与S0不重复——S0是要点清单，本节是连贯叙事

   **量价定性词典（S1/S1.5 共用语言规范，必须使用）**：

   | 量价组合 | 定性 | 含义 |
   |---------|------|------|
   | 缩量上涨 | 存量博弈 | 反弹高度受制于量能，非增量行情，追高性价比低 |
   | 放量上涨 | 增量进场 | 有新增资金，行情持续性概率上升 |
   | 放量滞涨 | 顶部特征候选 | 高位分歧加剧，筹码开始松动 |
   | 高位缩量整理 | 良性调整 | 筹码锁定好、抛压衰竭，整固后方向待定 |
   | 放量破位 | 风险确认 | 资金出逃，防守优先 |
   | 缩量回踩均线不破 | 强势整理 | 趋势未破坏，观察能否重新放量 |
   | 尾盘集中放量 | 抢筹/护盘待区分 | 宽基ETF同步放量多为护盘，单一题材放量多为抢筹 |

   **均线锚定规范**：强势=指数>5日线>10日线>20日线（多头排列）；整固=指数在5日线与20日线之间；转弱=跌破20日线。每次表述必须落到具体点位（如"5日线位于3980，昨日收盘3975已跌破"），禁止只写均线名称不写点位

3. **S2 · 隔夜冲击（Overnight Shock）**：不是新闻列表，按**事件 → Surprise → 资产反应 → 传导链 → A股映射**呈现：
   - **事实层**：发生了什么、来源、时点（与"市场解读"严格分开标注。如"财政部提高回购上限"是事实，"'迷你QE'"是市场解读，禁止混写）
   - **Surprise 评分**：新闻重要性 X/10 + 市场预期（高/中/低）+ 实际偏离方向 → Surprise 分值。市场交易的是"结果超没超预期"，不是"事件好不好"——高利好+已被充分预期 = 兑现风险
   - **资产反应**：哪些资产已定价（美股对应板块、商品、汇率、利率）
   - **传导链**：四层因果链（改变什么预期 → 谁受益为何 → 资金先手还是跟风 → 逻辑能否持续），并**标注传导链断裂点**——A→B→C→D 的链条现实中常常只走到 B。写明"哪一环必须验证（如：医药高开后必须看到新增资金承接，否则题材交易终止）"

3a. **S2.5 · 行业快讯板（News Board · 机构新闻速递式广度覆盖）**：S2管深度（重大事件四层拆解），本节管广度（全行业覆盖）。按固定行业块组织：**宏观政策 / AI算力 / 半导体 / 医药生物 / 机器人 / 航天军工 / 新能源 / 金融地产 / 消费 / 其他**（当日无新闻的行业块直接省略）。
   - 每块结构：2~4条快讯 + 末尾一行"→ 映射：{受益/受损板块或宽基}"
   - 每条快讯1~2句，必须含**信息增量**（数字/事件/时间/订单/政策文号），纯观点不收（"某券商看好XX"不收，"某券商给出XX亿元订单预测"收）
   - **信源纪律（硬性）**：①传闻必须以"传："前缀标注，与已确认事实严格区分；②每条标注来源类型【官方】【卖方】【外媒】【产业】【公告】
   - **排重纪律**：已进S2深挖的重大事件不在本节重复出现；本节只收"不够重大但有交易价值"的信息
   - **排序纪律**：行业块按当日信息密度从高到低排列，信息最多的行业排最前
   - **时间窗纪律**：只收T日08:00前已公开的信息
   - 本节是信息板不是分析板——不做四层传导链展开（那是S2的职责），但每条快讯的方向性（利多/利空哪个板块）必须在"映射"行体现

3b. **S2.6 · 外媒小作文监测（Market Narrative Watch · 硬性必写）**：A股资金对"彭博/路透级别大机构的中国资产叙事报道"定价效率极高（信源迷信），这类报道介于"已证实新闻"与"纯传闻"之间，必须单列专区、逐条分级展示。**禁止与S2已证实事件混排**。
   - **收录范围**：①外媒（彭博/路透/FT/WSJ/CNBC等）关于中国资产/A股/港股的叙事性报道；②引用数据商（S3 Partners/EPFR等）或单一机构/匿名信源的市场影响型文章；③无明确信源但广泛传播的市场传闻（标注"纯传闻"）
   - **分流规则**：内容已被官方/数据证实且够重大事件标准 → 进S2（标注"外媒首发"）；未证实但具市场影响力 → 进本节；行业级小传闻（如"传长鑫HBM良率80%"）→ 进S2.5，不进本节。同一报道不重复进多节
   - **每条展示格式（六要素）**：标题+媒体+发布时间（精确到小时）｜核心摘要（≤3句）｜**类型标签**（数据型/知情人士型/机构观点型/卖方研报型/纯传闻型）｜**可信度评级**（高/中/低 + 一句话理由，如"S3 Partners数据可查证=较高；'涨势过头'判断属媒体叙事=主观"）｜涉及标的/板块（标注上市地）｜**证伪/证实路径**（什么可观测信号能验证或推翻）
   - **事实层与叙事层分离（硬性）**：每条必须拆出"可查证事实"（如做空比例23.4%、A/H溢价8%）与"媒体叙事框架"（如"涨势引发质疑"）——前者可采信，后者需独立判断，禁止混写
   - **评级纪律**：数据型（第三方数据商背书）起点=中高；知情人士型=中（标注"待证实"）；单一机构观点型=中低（观点非事实，注意机构利益立场）；纯传闻型=低。**外媒品牌不加分**——"彭博发布"只证明传播力，不证明内容为真
   - 当日无符合条件条目时写明"今日无重大外媒小作文"，不硬凑

4. **S3 · 定价与拥挤度（Positioning / Price-in）**：回答"市场昨天有没有提前交易"：
   - **Price-in Score**：昨日板块涨幅 + 3/5日累计涨幅 + 近5日量能 vs 均值 + ETF净流入 + 龙头股涨幅 + 板块涨停数 → 输出"利好强度 X/10 vs 价格透支 X/10 → 盈亏比（优/一般/差）"
   - 提前上涨**只能表述为"存在提前交易迹象"**，禁止推断"消息泄露"——板块提前走强还可能来自政策预期、行业轮动、机构调仓、ETF资金、海外映射等，无法排除
   - 若昨日相关板块已大涨（如+9%），必须在本段给出"高开兑现"风险量化

5. **S4 · 主线竞争（Sector Competition）**：**禁止输出单一"今日绝对主线"**，改为概率竞争：
   - 第一主线（候选板块A，成为最强主线概率 X%）+ 驱动事件 + 承接逻辑
   - 第二主线（候选B，Y%）、第三主线（候选C，Z%），概率合计≈100%
   - 真实A股经常是两个方向争夺资金，主线竞争的表达方式能显著降低过拟合
   - **板块映射四层模型（所有重大事件强制使用）**：

   | 层级 | 定义 | 映射等级 | 示例（以mRNA疫苗成功为例） |
   |------|------|---------|--------------------------|
   | L1 直接资产 | 产品/临床项目/技术路线直接相关 | A | 国内同类个性化mRNA肿瘤疫苗管线公司 |
   | L2 同技术平台 | 同技术路线的beta（平台、递送、抗原设计） | B | mRNA/LNP平台型公司 |
   | L3 产业链 | 服务该方向的CXO/CDMO/测序/耗材 | C | CXO、临床CRO、测序服务 |
   | L4 情绪Beta | 无具体逻辑、只吃板块情绪 | D | 板块指数、创业板、创新药ETF |

   - **每个映射标的必须标注：映射等级（A/B/C/D）+ 上市地（A股/港股/ADR/海外）**。A股盘前报告严禁把港股标的（如信达生物、石药）混入"A股受益标的"——港股映射单列小节。混装市场会摧毁报告可信度

5a. **S4.5 · 热点深追（Theme Deep-Track · 产业链深挖+拐点诊断）**：S4回答"今天谁最可能赢"（概率竞争），本节回答"赢家的产业链逻辑是什么、板块处于什么位置"。
   - **触发条件**（至少满足一条；不满足则本章简写为"今日无产业级拐点候选，主线竞争见S4"，不硬凑）：①隔夜有产业级重大催化（海外临床突破/大客户订单/政策文件/涨价潮）；②某板块处于拐点候选区（调整充分+新催化出现）
   - **选题**：选1个主题，最多2个。优先选S4第一主线或隔夜最大产业催化
   - **固定五层结构**：
     1. **事件锚点**：什么事件、来源、为什么重要（1段，讲清"为什么是产业级"而非噪音）
     2. **产业链拆解**：上游/中游/下游分环节呈现（表格），标注哪个环节最受益、受益弹性排序、为什么
     3. **受益分层**：按S4四层模型落标的（L1直接供应链/L2平台beta/L3产业链/L4情绪beta），每个标的标注映射等级+上市地
     4. **板块位置诊断（拐点四要素）**：①本轮调整时长；②机构持仓位置（有数据则写，无数据如实标注"数据源未覆盖"）；③筹码出清程度（从量价行为推断，使用量价定性词典）；④利空是否出尽（财报/解禁/监管风险是否已释放）
     5. **拐点验证信号**：什么信号确认主升启动（可观测、当日可验证，如"板块成交额>200亿且龙头涨停≥2家"）+ 什么信号证伪（如"高开>3%但10:30前无涨停则证伪，降级为兑现行情"）
   - **与S4的排他分工**：S4的概率判断在本节一句话引用即可，本节全部篇幅给产业链；概率数字不重复论证
   - **可选历史类比**：若有可比历史案例（如"2023H2美债利率5%时上证跌破3000点"式复盘），简要类比并标注本次差异点；无合适类则不强行套用

6. **S5 · 今日预测（Market Forecast）**：
   - **开盘预测**：高开/低开/平开 + 幅度区间 + 依据
   - **时间节点预测**（每个可独立打分，替代故事化分时推演）：
     - 09:45 前：核心板块相对大盘超额收益 X%
     - 10:30：板块涨停数达到 X~Y 家
     - 11:30：创业板 vs 上证超额收益
     - 14:00：成交额达到全天预测值的 X%
     - 14:30：主线板块相对强弱是否衰减
   - **量能预测统计化**：不得凭感觉。输入昨日成交额、5日/20日均值、昨日振幅、涨跌停比、可比历史情形（如"近3次极端放量恐慌日后成交额变动-8%/-12%/-15%"）→ 输出**中位数 + 80%区间**
   - **涨停家数区间**：给出区间 + 判断依据
   - **历史基准率规范（⛔ 硬性）**：所有"历史上X情形后反弹概率70%"类表述，必须写全四要素——**样本条件 → 样本数（N=几）→ 基准概率 → 条件概率**（样本时间范围、"反弹"的精确定义、口径是哪个指数、几天窗口）。给不出样本的，禁止写概率数字，只能写定性判断
7. **S6 · 情景推演（Scenario Tree）**：乐观/中性/悲观三情景，各给概率 + 关键触发条件。**情景概率会被台账校准**——若台账显示乐观情景实际频率持续低于标注概率，必须下修
8. **S7 · 失效条件（Kill Conditions）**：不是泛泛风险提示，而是"**出现什么信号，我承认判断错了**"：
   - 每条核心预测附失效阈值（如"若开盘医药板块高开>4%但10:30前涨停<3家，主线判断失效，降级为兑现行情"）
   - 今日真实风险日历（关键数据、政策窗口、海外事件）+ 反身性风险（昨日已涨板块的高开兑现）
9. **S8 · 观察清单（Watchlist）**：不是荐股，是**验证逻辑的观察对象**，按 S4 四层模型分 L1/L2/L3 列示（每个标的注明映射等级+上市地），并写明"看它验证什么逻辑"
10. **S9 · 预测台账（Forecast Ledger）**：**本系统长期变强的核心**：
    - 开头列出**上一期盘前报告的全部预测 → 昨日实际值 → 对错**（表格：预测项/预测值/置信度/实际值/结果✅❌）
    - 将本期全部可验证预测（S5/S6 的每一条）**追加写入台账文件** `A股/predictions_ledger.md`（不存在则创建，按日期分节）
    - 台账累计≥10个交易日后，在 S9 输出滚动评分：方向命中率、区间命中率、主线命中率、时间节点命中率、情景概率校准（标注概率 vs 实际频率）
    - 评分偏差要归因（如"开盘方向78%但午后方向52% → 隔夜信息传导判断强，盘中资金行为判断弱"），归因结论反馈修正后续报告的置信度标注

### 写作要求（升级版）

- **预测必须具体可验证**：不要"可能反弹"，要"若高开0.5%+首小时量能≥昨日同期，则有望冲上X点；反之回踩Y支撑"。给出点位、量能阈值、时间点
- **统计纪律**：无样本的概率禁写；区间预测给中位数+区间；时间节点预测可逐项打分；量能预测给推导输入而非结论
- **叙事纪律**：每条传导链标注断裂点；**会拒绝解释**——当数据不支持强结论时直接写"不确定"，不硬编故事；"什么行情都能解释"的模糊表述（如"先冲高后分化震荡"）必须替换为可证伪的时间节点预测
- **表述纪律**：事件事实与市场解读分开标注；"提前交易"≠"消息泄露"；每条信息标注来源；单一重大新闻不得劫持全篇主线判断（见S4概率竞争）
- **资金结构优先于成交量**：成交量只说明"交易了多少"，不说明"谁在交易、为什么、谁承接"。资金判断优先看：宽基ETF净申赎、融资余额变动、龙虎榜席位结构、大小盘分化、期指基差、机构重仓股表现；外资数据按实际可得口径标注（"北向相关资金指标"，不把单一口径当永恒指标）
- **证据等级**：每个预测标注证据等级（高/中/低），说明依据
- **不凑字数**：信息密度优先，一件事只讲一次，篇幅优先给 S1.5/S3/S4/S4.5/S5/S9

## 盘中概览模式（盘中分析报告）

> 当用户使用「盘中概览 / 盘中分析 / 盘中复盘 / 实时盘面 / 盘中速览 / 盘中报告」等词触发时进入本模式。
> 与本技能「收盘复盘」的差别：数据取**当前实时快照**，分析聚焦「现在发生了什么、谁在领涨、本时段看什么」，不做次日推演。
> 底层数据源（westock-data / westock-tool / neodata）本就返回实时快照，无需改动取数命令，只需把查询口径从「收盘+日期」改为「当前/实时」。

### 交易时段判定（先于任何采集 · 强制执行）

> **⛔ 硬性规则**：Agent 在进入任何数据采集或模式判定之前，**必须**通过系统命令（如 `Get-Date` / `date`）获取当前北京时间，**不得凭经验或上下文猜测时间**。A 股收盘时间为 15:00，当前时间 < 15:00 且为交易日时，一律视为**盘中模式**；当前时间 >= 15:00 时方可进入**收盘复盘模式**。违反此规则会导致使用错误的数据口径和分析框架。

A 股交易时段（北京时间 GMT+8，遵循 wb-finance-skill 时区口径）：

- 盘前：09:00–09:30（集合竞价 09:15–09:25）
- 早盘：09:30–11:30
- 午间休市：11:30–13:00
- 午盘：13:00–14:30
- 尾盘：14:30–15:00（尾盘竞价 14:57–15:00）
- 盘后：15:00–16:00（龙虎榜、盘后公告陆续披露）
- 其他时段（含周末 / 法定节假日）= 非交易时段

**执行步骤**（严格遵守）：

1. 调用系统命令获取当前北京时间（如 PowerShell `Get-Date -Format "yyyy-MM-dd HH:mm:ss zzz"`）
2. 判定是否为交易日（周末/法定节假日休市 -> 非交易时段）
3. 若为交易日，根据当前时间匹配上表时段
4. **当前时间 < 15:00 -> 盘中模式**（即使仅差几分钟收盘，也按盘中处理，数据取实时快照）
5. **当前时间 >= 15:00 -> 收盘复盘模式**（可叠加龙虎榜、盘后公告）
6. 在报告中标注「**数据时点 + 所属时段**」，再决定采集与解读口径：盘前看昨收与竞价信号、盘中看实时快照、盘后叠加龙虎榜与公告、非交易时段退化为「最近一个交易日快照」并明确标注，不编造实时数据

### 数据采集（复用基础命令，口径改为「当前 / 实时」）

westock 类命令返回实时快照，直接调用；neodata 查询去掉具体日期，改用「今日 / 当前 / 盘中」：

```bash

# 实时领涨 / 领跌板块

## 核心分析框架（所有路径强制适用）

> 以下分析框架应用于所有分析路径（路径一～五），是复盘报告的方法论基础。**禁止将行情简单归因于当天的新闻**，必须先判断市场原有的仓位状态和信念底色。

### 市场 = 状态（State） + 触发器（Trigger） + 资金响应（Flow）

A 股市场同样适用 State-Trigger-Flow 框架，且在涨跌停制度和 T+1 交易规则下，状态判断比美股更为关键——因为一旦方向判断错误，T+1 无法当日纠错，代价远高于美股。

| 维度 | 定义 | A 股特有含义 |
|------|------|-------------|
| **状态（State）** | 市场进入今天的"底色"——仓位结构、信念共识、情绪温度 | 涨停连板高度、炸板率、量能趋势、主线板块的拥挤度（是否已经过于一致） |
| **触发器（Trigger）** | 打破状态平衡的事件——宏观数据、政策、产业催化、突发新闻 | 政策文件、产业规划、涨价函、龙虎榜席位变化、北向资金异动 |
| **资金响应（Flow）** | 触发器引发资金如何流动——板块轮动方向、资金攻击方向、撤退方向 | 涨停封单量、主力净流入/流出、北向资金净买入、ETF资金流向、连板梯队封板强度 |

**禁止行为**：先看收盘K线再找理由。必须还原"今天开盘时市场是什么状态 → 过程中发生了什么 → 资金如何响应 → 最终K线怎么走出来"的时间顺序。

### 分析方法论（强制四步法）

每个核心判断必须经过以下四步，缺一不可：

1. **观察事实** — 盘面发生了什么，数据是什么（先写盘面事实，再写推导，再写结论）
2. **排除其他解释** — 为什么不是其他常见解释（排除法，避免"拿着结果找原因"）
3. **给出最可能解释** — 基于排除后的剩余选项，给出最合理的因果链，明确标注"证据等级"（高/中/低）
4. **附反证条件** — "如果这个判断是错的，盘面应该出现什么信号"（让读者可以自行验证判断的有效性）

### 叙事竞争分析框架

每次分析必须区分两个层面：

- **局部定价权** — 某条叙事在板块层面赢了（如"数据要素"叙事推动计算机板块领涨，但大盘指数下跌）
- **全局定价权** — 某条叙事在指数层面赢了（如"稳增长政策"叙事推动上证指数收涨，但AI板块反而下跌）

必须回答：哪条叙事赢得了局部定价权？哪条赢得了全局定价权？为什么？

### 多时间维度分析原则（强制）

所有分析结论必须注明是哪个时间窗口的判断，禁止用单日数据下中期结论：

| 时间窗口 | 关注重点 | 解决的问题 |
|---------|---------|-----------|
| **当日（1D）** | 涨跌幅、成交量、资金流向、新闻驱动 | 今天发生了什么 |
| **近5日（5D）** | 趋势方向、板块轮动持续性、量能变化趋势 | 当前的短期趋势是什么 |
| **近20日（20D）** | 中期趋势、均线系统、支撑/阻力位、累计资金流向 | 中期方向如何，是否值得参与 |

### 路径二：情绪周期分析

**匹配场景**：用户关注市场情绪、短线氛围、赚钱效应与亏钱效应。

**分析维度**：五维情绪评估。

**分析清单**：

| 维度 | 核心问题 | 结论输出 |
|------|---------|---------|
| 量温度 | 涨停数、跌停数、连板数、炸板率、红盘占比 | 温度决定仓位上限 |

| **十** | 前瞻观察与风险 | 未来1-3个交易日关键观察变量。包含：主线延续情景（需要什么条件）、主线反转情景（从哪里开始失真）、做空/防御触发条件（Short Triggers）、宏观事件日历（即将发布的CPI/PMI/政策会议等） |

#### 外媒小作文监测专栏（章八必含子模块 · 与盘前S2.6同规范）

章八末尾必须包含「外媒小作文专区」，对当日（含隔夜）外媒发布的中国资产叙事报道逐条分级展示：六要素格式（标题+媒体+发布时间 / 核心摘要≤3句 / 类型标签 / 可信度评级+理由 / 涉及标的含上市地 / 证伪证实路径）、五类标签（数据型 / 知情人士型 / 机构观点型 / 卖方研报型 / 纯传闻型）、事实层与叙事层分离、"外媒品牌不加分"评级纪律，均与盘前预测模式 S2.6 完全一致。与章八主体的分工：章八主体是"已发生信息的四维评估"，小作文专区是"未证实叙事的可信度分级"，两者必须分区展示、禁止混排。复盘视角额外回答：**该小作文当日是否已被盘面定价**（如外媒做空报道发布后，对应板块当日是否已回调）——已定价的标注"情绪已释放"，未定价的标注"潜在发酵风险"，并给出次交易日观察信号。当日无符合条件条目时写明"今日无重大外媒小作文"，不硬凑。

#### 章8.5~8.7 子模块规范（条件模块 · 有增量才展开）

**8.5 重磅深度（条件模块）：** 只深度解读**1个**最重磅事件 + 未来1-2周推演。当日无重磅事件则折叠。

**8.6 价格波动链追踪（Price Fluctuation Chain · 条件模块）：**
- **不限于涨价**：跌价同样影响股价（如碳酸锂跌价、光伏组件跌价、猪价下跌、面板跌价），必须**双向追踪**——涨价链与跌价链
- **上下游传导方向相反**（核心纪律）：
  - **涨价链**：上游原料涨价 → 利好上游资源股（量价齐升）→ 利空中游成本端（毛利率承压）→ 下游可转嫁则影响小、不可转嫁则利空
  - **跌价链**：上游跌价 → 利空上游（量价齐跌）→ 利好中游成本端（毛利率修复）→ 利好下游需求端（成本下降刺激需求）
- 每条价格波动链给出六要素：**价格数据（涨/跌幅度+周期） + 方向（涨/跌） + 驱动逻辑 + 上下游传导 + 映射标的（区分受益/受损） + 持续性判断**
- 例：MDI/TDI涨价 → 利好万华化学（涨价受益）→ 利空下游聚氨酯制品商（成本端）；碳酸锂跌价 → 利空锂矿（天齐/赣锋）→ 利好电池厂（宁德时代成本端）→ 利好新能源车终端（降价刺激需求）
- 与章8.7持续性故事线的关系：价格波动链是"当日有价格数据增量才展开"的条件模块；若某条价格链跨日持续，升级为持续性故事线（只更新增量）

**8.7 持续性故事线追踪（核心骨架 · 永远存在）：** 跨日持续影响市场的事件，每日只更新增量（≤2句），无新增标注「无新增」，不重复全量。见「时间维度分层纪律·持续性故事线纪律」。

**输出格式**：自包含 HTML（默认；勿再默认写 Markdown）。章节顺序即上述16章；样式遵循 `references/html_report_style.md`。保存建议：`./daily-review/全景复盘_YYYYMMDD.html`。

**写作基调**：每个章节控制在200-500字，核心分析章节（章零、一、二、三、十五）使用**连续自然段**写作，完整逻辑链写成一个段落，避免一句话一个段落。辅助数据可用卡片/表格，但核心分析不能碎片化。

### 去重纪律（Anti-Redundancy Discipline · 硬性必守）

> 复盘报告最易犯的毛病是**同一盘面现象在多章反复展开**（如"黄金新高→贵金属爆发"在章零/章三/章五/章六/章8.5各讲一遍），读者观感啰嗦。本纪律强制每章只回答一个问题，数据首次出现原则，后续章节只引用不复述。

**核心原则：One Chapter One Job + 数据首次出现原则 + 引用而非复述。**

**各章唯一职责与禁止越界：**

| 章节 | 唯一职责（只回答这一个问题） | 禁止（越界即重复） |
|------|------------------------------|-------------------|
| 零 | 市场底色：默认信念/拥挤度/资金驱动力 + 反证条件 | 不展开具体板块涨幅、不列数据 |
| 一 | 全景数据（指数/量能/宽度）+ 状态定性（进攻/修复/分歧/退潮） | 不解释成因（留给章五）、不判主线（留给章三） |
| 二 | 宏观锚点变化 + 汇率/利率/大宗背离共振 | 不展开A股板块映射（留给章三/章六） |
| 三 | 主线判定 + 资金流向 + 做空动能 + 叙事竞争 | 不展开因果链（留给章五）、不复述章一数据 |
| 四 | 市场**没注意**的信号（暗线/伏击点） | 不复述章三已讲的做空动能，只讲增量信息 |
| 五 | 盘面成因：State→Trigger→Flow 因果链 | 不复述数据（引用章一）、不复述主线（引用章三） |
| 六 | 叙事→不同资产定价映射 + 反事实推演 | 不复述叙事本身（引用章五），只讲映射差异 |
| 七 | 多空辩论 + 胜率 + 可验证条件 | 引用前面结论，不复述盘面 |
| 八 | 信息四维评估 + 外媒小作文专区 | 不重复分析（引用对应章） |
| 8.5 | **只深度解读1个**最重磅事件 + 未来1-2周推演 | 不复述当日盘面，聚焦"未来会怎样" |
| 8.6 | 价格波动链（涨价/跌价双向 + 上下游传导） | 不复述当日盘面，只讲价格数据与传导 |

| 九 | 旧叙事钝化 vs 新定价锚确立 | 一句话引用，不展开 |
| 十 | 前瞻观察（未来1-3日） | 不回顾当日 |
| 十一 | 标的层级表格 | 不重复逻辑（引用章三主线） |
| 十二 | 反弹性质判断（超跌/政策/趋势/事件） | 引用章五成因，不重述 |

| 十六 | 预测台账与回归 | 只记录预测与回归结果，不重复盘面 |

**数据首次出现原则（硬性）：**
- 每个数据点（指数涨跌、成交额、板块涨幅、资金流向、涨停/跌停数）**只在首次出现的章节完整呈现一次**
- 后续章节引用时用"如章X所述"或一句话带过，**禁止重复完整数据**
- 例：成交额1.88万亿只在章一完整出现；章五/章十五引用时写"缩量（见章一）"即可

- "章三已判定贵金属/有色为主线，此处不展开……"
- "结合章五的成因分析……"

- [ ] 后续章节是否用"见章X"引用而非复述？

### 时间维度分层纪律（Time-Dimension Discipline · 硬性必守）

> **复盘重复的根因**：16章都是"当日空间维度"，单日信息量有限，同一件事（如黄金原油涨）必然在多章反复出现。解法是**按时间维度分层**，每层只讲自己的时间尺度，用时间纵深替代空间堆砌。

| 时间维度 | 讲什么 | 禁止 |
|---------|--------|------|
| **T0 当日** | 当日新增事件、当日盘面数据（首次出现） | 不回顾持续性事件全量 |
| **T-3~T-5 周度** | 本周主线变化、风格切换、量能趋势、板块轮动节奏 | 不重复当日数据（引用章一） |
| **T-20~T-60 中期** | 趋势性变化（黄金牛市/存储周期/风格主线） | 不重复当日事件 |
| **持续性故事线** | AI投入/霍尔木兹海峡/涨价链等跨日事件 | **每天只更新增量，不重复全量** |

**持续性故事线纪律（Ongoing Storylines）：**
- 收录正在进行、持续影响市场的故事线（AI算力投入、美伊以地缘/霍尔木兹、存储涨价、黄金牛市、实验猴涨价、化工涨价、医药mRNA等）
- 每条格式：**故事线名称 + 起始日 + 当前状态（每日只更新增量，≤2句）+ 未来验证点 + 对A股映射**
- 当日无新进展的故事线标注「无新增」，**禁止重复全量**——这样每天报告是"增量更新"而非"复述"
- 持续性故事线集中在章8.7（或独立模块），其他章节只引用不展开
- 故事线话题库与「热点追踪池」共用（见「热点追踪池与内容补充」）：池中话题有当日增量时展开，无增量时标注「无新增」

**周度视角纪律（3-5日维度）：**
- 章一内嵌「周度视角」子块：本周（近5日）主线变化、风格切换、量能趋势、板块轮动节奏
- 用"本周 vs 上周"对比呈现，不重复当日数据
- 例：本周主线从"医药单极"→"黄金有色+算力"的切换节奏、本周量能趋势（2.38万亿→1.88万亿的递减）

### 动态折叠机制（Dynamic Folding · 硬性必守）

> 16章是"最大模板"，不是"每日必填"。单日信息量有限时硬填16章必然注水+重复。解法：**按当日信息量自动启用/折叠章节**——信息多全展开，信息少收缩到核心骨架，条件模块有增量才展开。

**章节分级：**

| 层级 | 章节 | 规则 |
|------|------|------|
| **核心骨架（永远存在）** | 零 底色 / 一 全景+周度 / 三 主线资金 / 十五 结论 / 8.7 持续性故事线 / 十六 预测台账 | 无论信息多少都必须有；信息少时缩短篇幅，不缩章节 |
| **条件模块（有增量才展开）** | 二 宏观 / 四 暗线 / 五 成因（含护盘资金参与度子块） / 六 叙事映射 / 七 多空辩论 / 八 信息+外媒 / 8.5 重磅深度 / 8.6 价格波动链 / 九 状态更新 / 十 前瞻 / 十一 标的 / 十二 反弹定性 / 十三 外资与海外 / 十四 仓位 | 当日无增量则折叠为一行"今日无重大X，见章Y"或直接省略 |

**信息量分级（决定折叠程度）：**

| 信息量级 | 判定（成交额+主线+事件数） | 折叠策略 |
|---------|---------------------------|----------|
| 高 | 成交>2.2万亿 + 多主线 + ≥3个重大事件 | 全展开（16章+） |
| 中 | 成交1.7~2.2万亿 + 单主线 + 1-2个事件 | 核心骨架 + 有增量的条件模块（约10-12章） |
| 低 | 成交<1.7万亿 + 无主线 + 盘面无聊 | 核心骨架 + 热点追踪池/非零资讯补充（约8-10章） |

**折叠纪律：**
- 折叠不是删除：被折叠章节的核心结论并入其他章节一句话带过（如"今日无重大护盘信号"并入章五盘面成因）
- 条件模块的"增量"判定：当日有新增数据/事件/边际变化才展开，无则折叠
- 信息量少时禁止硬凑：宁可章节少而精，不可多而水——用热点追踪池/产业深度补内容，不用重复盘面凑篇幅

### 热点追踪池与内容补充（Hot Topic Pool · 硬性必守）

> 当日信息量少、盘面无聊时，从「热点追踪池」选取有当日增量的高热度话题展开，或补充非当日但相关的产业深度内容。目的：信息量少时用"时间纵深+产业纵深"替代"当日空间堆砌"，避免硬凑当日盘面。

**热点追踪池（持续维护 · 台账见 `A股/hot_topic_pool.md`）：**
- 池内话题：AI算力投入、存储涨价周期、实验猴价格、美伊以地缘/霍尔木兹、化工价格、黄金牛市、医药mRNA、机器人、低空经济、创新药出海、半导体国产化、猪周期、碳酸锂/光伏价格等
- 每条话题记录：话题名 + 起始日 + 核心逻辑 + 关键数据/验证点 + 对A股映射
- 当日信息量少时，从池中选取**有当日增量**的1-2个话题展开（增量=当日有新的价格/订单/政策/海外映射数据）
- 与章8.7持续性故事线的关系：故事线是"被动等增量"，追踪池是"主动维护+信息少时选取展开"，两者共用同一话题库

**非零资讯/产业深度补充（当日信息量少时启用）：**
- 加入与股市相关但非当日发生的产业深度内容：某行业景气度深度、某公司中报/基本面深度、产业链上下游传导逻辑、宏观背景知识
- 要求：必须与当前市场主线/持仓相关、有信息增量、可验证，禁止无关话题填充
- 例：当日盘面无聊时，可展开"存储涨价对A股存储板块的传导路径"产业深度，而非硬讲当日盘面

**加大当日信息收集（配合动态折叠）：**
- 当日信息量少时扩大搜索范围：更多板块、更多海外映射（美股/港股/韩股）、更多研报（外资/内资）、更多价格数据（商品/化工/存储/实验猴）
- 注意：收集是为了"当日信息全"，不是"越多越好"——收集结果仍按动态折叠机制组织，信息少时优先用热点追踪池/产业深度补充，而非硬塞当日信息

### 预测-回归-学习闭环（Forecast-Regression-Learning Loop · 硬性必守）

> 复盘不只描述过去，还要预测未来并自我进化。闭环：**每日记录可验证预测 → 3-5天后回归验证 → 统计命中率 → 识别系统性偏差 → 校准分析框架**。

**每日预测记录（复盘报告新增「预测台账与回归」章节）：**
- 记录3-5条核心预测：方向 + 价格 + 时间节点 + 可验证指标 + 置信度
- 预测必须可验证（具体价格点/量能阈值/时间节点），禁止模糊表述
- 例：「贵金属/有色主线延续：明日（8/24）湖南白银/盛达资源不炸板且板块资金净流入，置信度中」

**回归验证（3-5天后）：**
- 每天回归验证3-5天前的预测，打分：**命中 / 部分命中 / 未命中**
- 记录实际结果与偏差归因（为什么偏了：样本不足/外部冲击/框架缺陷）

**学习进化（持续）：**
- 统计滚动命中率（方向/区间/主线/时间节点/情景概率）
- 识别系统性偏差（如"总是高估情绪退潮速度"、"低估缩量幅度"），写入台账
- 校准分析框架权重（如"量能预测偏差大→加大历史样本基准"），记录校准依据
- 维护「预测-回归-学习台账」（扩展 `A股/predictions_ledger.md`，复盘预测与盘前预测共用同一台账）

## 核心逻辑底层拆解（所有路径默认必含）

> **硬性规则**：路径一～四的复盘报告中，**必须包含**本节内容。这是复盘的灵魂——不只告诉用户"涨了什么"，更要讲清"为什么涨、能不能持续、背后的产业/资金/情绪逻辑是什么"。

### 定位与原则

- **位置**：放在"板块表现"之后、"技术面分析"之前（或在"核心驱动"章节中展开）
- **数量**：每次拆解 1-3 个当日最核心的驱动/主线方向，不要贪多
- **深度**：每个方向按"事实→传导→映射→持续性判断"四层展开
- **风格**：像给朋友讲明白一样，不用黑话，用大白话讲清产业逻辑

### 四层拆解框架（默认模板）

针对当日最强的 1-3 个主线方向，每个方向按以下四层展开：

| 层级 | 内容 | 要回答的问题 |
|------|------|-------------|
| **第一层：事实** | 发生了什么具体事件/数据 | 到底是什么触发了行情？ |
| **第二层：传导** | 这个事件/数据如何传导到对应板块 | 为什么利好/利空这个板块？产业逻辑是什么？ |
| **第三层：映射** | 对应到 A 股是哪些公司/细分方向受益 | 具体买什么？龙头是谁？弹性最大的是谁？ |
| **第四层：持续性** | 这波行情能走多久？是一日游还是趋势 | 明天/下周还能涨吗？需要什么条件验证？ |

### 常见拆解方向与方法论

根据当日行情特征，选择最核心的 1-3 个方向深入拆解：

**方向 A：海外传导（美股/港股 → A股）**
- 适用场景：隔夜美股大涨/大跌、美股科技股财报、美联储利率决议、地缘事件
- 拆解要点：
  - 美股涨/跌的具体原因是什么？（财报？政策？宏观？）
  - 传导链条是什么？（美股科技股 → A股半导体？美股消费 → A股消费？）
  - 历史上类似情景 A 股的表现如何？
  - 这次有没有不一样的地方？（量级、持续性、催化剂强度）

**方向 B：政策催化（国内政策 → 对应板块）**
- 适用场景：国务院/部委政策、产业规划、监管动态、地方政策
- 拆解要点：
  - 政策的核心内容是什么？（不要只看标题，看具体措施）
  - 直接受益的环节和公司是哪些？
  - 政策力度有多大？（真金白银还是口号？）
  - 是短期刺激还是长期趋势？

**方向 C：产业趋势（技术突破/产品迭代 → 产业链）**
- 适用场景：AI 大模型发布、新产品发布、技术突破、涨价/降价
- 拆解要点：
  - 技术/产品突破在哪里？（是质变还是量变？）
  - 产业链哪个环节最受益？（上游材料？中游制造？下游应用？）
  - 业绩兑现周期有多长？（本季度？明年？还是更远？）
  - 市场预期打满了吗？（估值贵不贵？）

**方向 D：资金行为（机构/北向/游资 → 风格切换）**
- 适用场景：风格极端分化、北向大额流入流出、机构调仓、量化策略变化
- 拆解要点：
  - 谁在买？谁在卖？（北向？机构？游资？散户？）
  - 为什么买/卖？（调仓？避险？追涨？抄底？）
  - 这种资金行为的历史持续性如何？
  - 有没有背离信号？（资金流入但股价不涨/跌）

**方向 E：情绪周期（极端情绪 → 反转/延续）**
- 适用场景：冰点/高潮日、极端涨跌比、连续大涨/大跌后
- 拆解要点：
  - 当前情绪在什么位置？（冰点？修复？高潮？退潮？）
  - 历史上类似情绪位置后市场怎么走？
  - 有没有情绪反转的信号？（跌停数骤降/涨停数骤增？）
  - 情绪修复的强度够不够？（量能？广度？持续性？）
**方向 F：反弹定性分析（鹏华早评框架）**
- 适用场景：市场经历连续下跌后出现反弹，需要判断反弹的性质
- 拆解要点：
  - 反弹的性质是什么？（超跌技术修复 / 政策驱动反弹 / 趋势反转？）
  - 反弹的力度如何？（量能配合程度、领涨板块的持续性）
  - 反弹的空间有多大？（上方阻力位、套牢盘密集区、均线压制）
  - 重势 vs 重消息：趋势驱动型反弹（重势，关注均线修复和量能持续）vs 消息驱动型反弹（重消息，关注催化剂的持续性和新消息跟进）
  - 反弹的失效条件是什么？（缩量、龙头熄火、关键阻力位遇阻）
  - 操作策略：反弹初期可参与，但需设好止损位；反弹中后期逐步减仓，不追高

**方向 G：板块热点密度与Token经济学分析（热点追踪框架）**
- 适用场景：市场热点分散、板块轮动加快、需要量化评估热点强度
- 拆解要点：
  - 按板块分类的新闻密度：统计各板块近3日相关新闻/公告的数量，量化热点热度
  - Token经济学分析：将板块视为"经济体"，分析其"Token消耗效率"（资金使用效率）、"Margin定价权"（板块利润空间）、"流通速度"（资金轮动速度）
  - 供应链映射：将事件/政策/涨价映射到产业链各环节，判断最受益的环节和公司
  - 热点持续性评估：板块热度是否在扩散（跟风股增多）还是收敛（龙头独涨、跟风乏力）
  - 板块资金效率：板块成交额占比 / 板块市值占比，衡量资金过度集中还是分散
### 写作要求

1. **结论先行**：每段拆解开头先给一句话核心结论，再展开讲逻辑
2. **用数据说话**：有具体数字支撑（涨跌幅、成交额、增速、估值等），不要空泛
3. **诚实表达不确定性**：拿不准的就说"需要观察""有待验证"，不要硬编
4. **正反两面（Bull/Bear双面呈现）**：既讲利好逻辑，也讲风险点和可能的证伪条件。**并增加说明**：模仿TradingAgents的多智能体辩论机制，每个判断必须有正反两面，让多头和空头各自陈述，先展示熊市观点（风险优先）再展示牛市观点。
5. **不超过 3 个方向**：宁少勿滥，把最核心的讲透比讲一堆浅的好
6. **语言通俗**：避免堆砌专业术语，用类比和大白话讲清
7. **连续阅读原则**：关键分析段落（章零、一、二、三、十六）使用**连续自然段**写作，一个完整逻辑链写成一个段落，避免一句话一个段落。辅助数据可用卡片/表格，但核心分析不能碎片化。核心段落的写作节奏应为：结论句 → 数据支撑句 → 推导过程句 → 与前后文的关联句 → 限制条件/反证条件句
8. **状态优先原则**：先诊断市场状态（State），再分析触发器（Trigger），最后看资金响应（Flow）。禁止将行情简单归因于当天的新闻，必须先判断市场原有的仓位状态和信念底色
9. **叙事竞争原则**：每次分析必须区分"局部定价权（板块层面）"和"全局定价权（指数层面）"，并量化叙事权重。必须回答：哪条叙事赢得了局部定价权？哪条赢得了全局定价权？为什么？
10. **四步法原则**：每个核心判断必须经过"观察事实→排除其他解释→给出最可能解释→附反证条件"四步，缺一不可。关键结论必须标注"证据等级"（高/中/低）
11. **科技/AI优先原则**：标的筛选和主线判断以科技/AI/AI泛科技为主线，其他板块（消费/周期/金融等）仅作背景分析。科技/AI板块的叙事权重天然高于其他板块，在叙事竞争分析中优先考虑
12. **小资金适配原则**：所有操作建议和交易策略以$2000-3000资金规模为基准，考虑可买股数、分散度限制（单只标的仓位不宜超过50%）、交易成本影响。避免推荐高价股（每股>300元），优先考虑ETF和低价高弹性标的
13. **10%止盈纪律**：目标收益10%左右，达到后减仓至轻仓甚至空仓，情愿不亏。所有交易建议必须包含止盈触发条件和止损执行纪律

## TradingAgents 多智能体辩论式分析框架（新增·核心）

> 参考 TradingAgents（GitHub 80K+ Stars，Tauric Research 开发）的多智能体协作框架，在 A 股复盘报告中引入结构化辩论机制，弥补原有分析中「只讲一面、缺乏多空对抗」的短板。

### 为什么 TradingAgents 对 A 股复盘同样重要？

A 股市场比美股更加情绪化、博弈属性更强——涨停板制度、T+1 交易、散户占比高、政策驱动频繁。这意味着 A 股复盘不能只做「数据罗列」或「单向叙事」，而必须：

- **多空双方各自陈述理由**：让"看多的人"和"看空的人"在报告中正面交锋
- **量化风险与机会的胜率**：不只是说"有机会"或"有风险"，而是给出具体概率判断
- **区分不同角色的分析视角**：基本面分析师的业绩判断 ≠ 情绪分析师的恐慌/贪婪判断 ≠ 技术分析师的支撑/阻力判断
- **给出可执行的交易决策**：综合所有角色的判断后，由"交易员"角色做出最终操作建议

### 核心借鉴：TradingAgents 8 角色 → A 股复盘映射

| TradingAgents 角色 | A 股复盘中的对应分析维度 | 输出内容 |
|-------------------|------------------------|---------|
| 基本面分析师 | 财报/估值/行业景气度/产业周期 | 标的业绩趋势、估值合理性、行业周期位置 |
| 情绪分析师 | 涨停跌停比/炸板率/连板高度/成交额变化 | 市场恐慌/贪婪程度、情绪周期定位 |
| 新闻分析师 | 政策解读/产业催化/消息面/龙虎榜席位 | 关键驱动事件及影响评估、政策力度判断 |
| 技术分析师 | K线形态/均线系统/MACD/KDJ/成交量/支撑阻力 | 技术形态、关键价位、趋势方向判断 |
| 牛市研究员（Bull） | 看多逻辑汇总 | 买入理由、催化因素、上涨空间、目标价位 |
| 熊市研究员（Bear） | 看空逻辑汇总 | 风险警示、下跌风险、证伪条件、止损位 |
| 风险管理师 | 仓位管理/回撤控制/市场环境评估 | 当前建议仓位、最大亏损额度、止盈止损纪律 |
| 交易员 | 综合决策输出 | 最终操作建议（方向/标的/仓位/时机/条件单） |

### 报告中的辩论式呈现格式

在复盘报告中，针对关键方向（指数、主线板块、核心标的），采用以下结构化辩论格式：

```
### 多空辩论：{方向/板块/标的}

- 论据1：{数据/逻辑支撑}
- 论据2：{数据/逻辑支撑}
- 论据3：{数据/逻辑支撑}
- 目标空间：{预期涨幅/上行空间}

**🐻 空头观点（熊市研究员）**
- 论据1：{数据/逻辑支撑}
- 论据2：{数据/逻辑支撑}
- 论据3：{数据/逻辑支撑}
- 风险程度：{预期跌幅/下行风险}

**⚖️ 综合判断（交易员）**
- 胜率倾向：{多头/空头/中性}
- 胜率评估：{60%/70%/50% 等具体概率}
- 关键验证条件：{什么情况下多头胜/空头胜}
- 触发条件：{需要看到什么信号才行动}
- 当前建议：{操作方向 + 具体策略}
```

### 在复盘报告中的使用场景

| 场景 | 辩论对象 | 典型问题 |
|------|---------|---------|
| 指数方向 | 上证指数/创业板指 | 4000点能否突破？回调还是反转？ |
| 主线板块 | 当前最强板块（如医药、有色） | 板块行情是一日游还是趋势？ |
| 核心标的 | 龙头股/持仓股 | 追高还是等待回调？止盈还是持有？ |
| 市场整体 | 全市场状态 | 进攻还是防守？加仓还是减仓？ |
| 资金方向 | 北向资金/主力资金 | 外资是真看好还是短期博弈？ |

### 执行原则

1. **每个方向至少 2 条论据**：Bull 和 Bear 各至少 2 条有数据支撑的论据，避免空洞的"看好/看空"
2. **胜率必须量化**：综合判断中给出具体胜率（如 60%/70%），而非模糊的"大概率"
3. **验证条件必须可观测**：多空胜负的条件必须是次日/次周可验证的具体信号（如"成交量>2.8万亿"、"突破4000点"等），而非模糊的"如果市场好转"
4. **风险优先**：先展示熊市观点（风险警示），再展示牛市观点，最后给出综合判断
5. **与现有框架互补**：不替代核心逻辑拆解和板块分析，而是在这些分析的基础上增加多空辩论维度

### 反弹定性分析模块（鹏华早评框架）

当市场出现反弹行情时触发。本模块包含三个子框架：

**框架A：反弹性质判断**
| 反弹类型 | 特征 | 操作策略 | 失效条件 |
|---------|------|---------|---------|
| 超跌技术修复 | 缩量止跌、无量反弹、无主线、无催化 | 不参与或轻仓博弈 | 遇阻回落、二次探底 |
| 政策驱动反弹 | 政策利好明确、板块有响应、量能温和放大 | 可参与龙头方向，设好止损 | 政策落地后无后续、资金不跟进 |
| 趋势反转 | 放量突破关键阻力位、主线清晰、情绪持续回暖 | 积极参与，逐步加仓 | 假突破、缩量回踩破位 |
| 事件驱动反弹 | 突发事件催化、板块热度集中、持续性存疑 | 快进快出，不恋战 | 事件消化后回落 |

**框架B：重势 vs 重消息对冲逻辑**
- **重势（趋势驱动）**：均线系统修复、量能持续温和放大、板块轮动有序 → 重趋势，轻消息，关注技术面信号
- **重消息（消息驱动）**：突发政策/事件催化、板块热度集中、龙头连续涨停 → 重消息，轻趋势，关注催化剂的持续性和新消息跟进
- **对冲逻辑**：当趋势和消息方向一致时 → 最强共振，可积极参与；当趋势和消息方向背离时 → 谨慎操作，以趋势为主，消息为辅

**框架C：操作策略建议**
- 反弹初期（指数在支撑位附近、缩量止跌、底分型出现）：左侧试探仓位，严格止损
- 反弹确认（放量突破5日线、MACD拐头、龙头出现）：加仓到正常仓位
- 反弹延续（持续放量、主线清晰、板块轮动有序）：持有为主，逐步减仓
- 反弹末期（缩量滞涨、龙头松动、跟风乏力）：减仓防守

- 多空胜负条件：{具体可观测信号}
- 触发条件：{什么情况下入场/离场}
- 建议：{操作方向+仓位+纪律}
```

**应用场景**：
- 指数方向辩论（如"上证指数能否突破4000点"）
- 主线板块辩论（如"医药板块行情持续性"）
- 持仓标的辩论（如"亨通光电冲高回落后的操作"）
- 市场状态辩论（如"当前是反弹还是反转"）

**注意事项**：
- 每个辩论方向须有至少2条有数据支撑的论据
- 胜率须给出具体数值（60%/70%等），而非模糊表述
- 验证条件须是可观测的具体信号
- 综合判断须包含操作建议和仓位建议

## 自媒体文案总结模块（新增 · 可选附加）

> 在完整复盘的基础上，额外生成一份**适合公众号/小红书/朋友圈等社交平台传播的短文案总结**。
> 用户明确要求"整合成几段话""公众号文案""小红书文案"时触发。可附加在任何分析路径之后。

### 适用场景

| 场景 | 触发关键词 | 输出格式 |
|------|-----------|---------|
| 公众号推文 | "公众号文案""整合成几段话""总结成文案" | 纯文本 Markdown，4-5段，每段120-200字 |
| 小红书/朋友圈 | "小红书文案""朋友圈文案""短文案" | 纯文本，3-4段，每段80-150字，轻量化 |
| 盘前简报 | "早盘文案""开盘前文案" | 纯文本 Markdown，3段，侧重当日关注点 |
| 复盘摘要 | 不指定平台时 | 默认公众号风格，4段 |

### 文案结构模板（公众号风格）

参考鹏华早评、热点追踪等机构自媒体文案风格，采用以下四段式结构：

```
【第1段：宏观锚点与市场情绪】

一句话定性今日市场状态（进攻/修复/分歧/退潮）→ 核心指数表现（上证/深证/创业板/科创50）→ 量能变化（成交额增减）→ 涨跌家数/涨跌停比 → 市场情绪温度 → 海外宏观影响（美股/汇率/美债/地缘）→ 国内宏观数据（CPI/PPI/政策）

【第2段：上涨驱动与核心催化】

今日/本周上涨的核心驱动力是什么 → 哪条产业/政策逻辑在兑现 → 上周/昨日发生了什么关键事件 → 这个催化剂是一日游还是趋势性 → 机构的普遍看法 → 外资/北向资金的态度

【第3段：板块轮动与资金博弈】

当前领涨方向（TOP 3-5板块，含涨幅和驱动）→ 领跌方向（及原因）→ 资金高低切换特征 → 连板梯队/龙头表现 → 资金流向（主力净流入/流出TOP）→ 北向资金动态 → 板块轮动是"一日游"还是"趋势切换"

【第4段：操作策略与关注清单】

当前市场状态定性（反弹/反转/震荡/退潮）→ 仓位建议（几成仓）→ 次日关注重点（核心事件/数据/技术位）→ 风险提示（什么情况下需要减仓/离场）→ 一句话总结

———

※ 以上分析基于公开数据，不构成投资建议
```

### 写作指南

#### 语言风格
- **Insider 口吻**：适度使用"其实也早有判断""我们看""都有收获了"等暗示信息优势的表达
- **预判式表达**："如果…还是机会""不好说""可能"——保留余地但给出倾向
- **市场黑话适度**：可嵌入"鬼故事""打了样""水温""小碎步""反包""高低切"等行话，筛选读者
- **多空平衡术**：每段含"一方面…另一方面…"或转折，避免绝对判断
- **结论后置弱化**：核心观点埋于段末，非标题式强调

#### 信息密度
- 每段120-200字，信息密度高，语言精炼
- 数据精确到小数点后两位数（如"+0.67%"、"2.54万亿"）
- 关键数据使用**加粗**强调
- 避免大段引用，用"据悉""市场反馈""产业催化"等中性表述

#### 结构要点
- 编号体系用阿拉伯数字1-4，平行并列结构
- 每段150-200字，属于"中高密度段落"
- 逗号密集、句号节制，单句偏长（典型书面口语混合体）
- 括号用于补充说明，非正文信息

#### 合规要求
- 文末必须加风险提示：「以上分析基于公开数据，不构成投资建议」
- 不使用「建议买入/卖出」措辞，改用「条件→操作→止损」框架
- 不出现具体数据源名称、群名称、消息数量

### 输出格式

**默认输出纯文本 Markdown**，直接展示在聊天中，用户可一键复制发布。

```
【标题】{日期} A股复盘 · {一句话定性}

【1】宏观锚点与市场情绪
{段落正文}

【2】上涨驱动与核心催化
{段落正文}

【3】板块轮动与资金博弈
{段落正文}

【4】操作策略与关注清单
{段落正文}

———

※ 以上分析基于公开数据，不构成投资建议
```

> 若用户要求"小红书/朋友圈"风格，压缩为3段，每段80-150字，更加口语化和轻量化。
> 若用户要求"盘前简报"，改为3段，重心放在当日关注点和操作策略。

### 与 TradingAgents 辩论式框架的配合

当同时启用 TradingAgents 辩论式分析和自媒体文案总结时：
- TradingAgents 辩论用于**深度报告内部**，展示多空对抗的完整推理
- 自媒体文案总结作为**对外输出层**，将辩论结果凝练为结论性文案
- 辩论中的"综合判断"胜率结论可直接引用到文案的"操作策略"段落中

## 通用规范

### 颜色惯例

- 上涨：红色（`#e63946`）
- 下跌：绿色（`#2d6a4f`）
- 中国 A 股惯例，不要搞反

### 数据红线

- 不编造数据、不混淆概念、不给出具体买卖建议
- 不使用「建议买入/卖出」措辞，改用「条件→操作→止损」框架
- 数据源不可绕过：禁止使用 web_search/web_fetch/curl 替代可信 skill
- 报告中绝不暴露具体数据源名称、群名称、消息数量、文件来源或抓取路径

### 隐私与数据源口径

- 统一使用中性表述：「综合消息面」「产业催化」「市场反馈」「资金验证」「盘面表现」等
- 不出现可识别来源的描述（如具体平台名、群名、帖子数量等）
- 若某类数据未获取到，可在内部降权，但不在报告里展开来源细节

### 风险提示

报告结尾须注明：「以上分析基于公开数据，不构成投资建议」。每条策略建议后附带一句明确的风险警示。
