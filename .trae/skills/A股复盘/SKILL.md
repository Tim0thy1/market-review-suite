# A 股每日收盘全维复盘

## 能力概览

本 skill 提供 A 股收盘后的完整复盘能力，覆盖三条模式（盘前预测 / 盘中概览 / 收盘复盘）与多条深度分析路径。
数据统一经 4 个可信 skill 获取，不依赖外部 API 或 WebSearch。

**输出格式由客户端类型自动决定**：电脑客户端（内置浏览器可浏览 HTML）→ 生成自包含 HTML 报告；手机 App（暂不支持 html）→ 直接输出文字版（Markdown 纯文本）。见「输出格式自动判断」章节。

> **输出约定**：交付后聊天中只给摘要 + 文件路径；含图表的报告须 `node --check` 通过后再交付。
> 遵守 wb-finance 硬约束；复盘章节结构见 `references/html_report_style.md`（可按分析路径微调配色）；
> 热点速览为橙红脉冲风格，见 `references/hotspot_report_template.html`。
>
> **加载顺序**：金融场景先加载 `wb-finance-skill` 读红线与时区口径，再调 westock / neodata 取数。

## 输出格式自动判断（强制 · 先于一切分析）

> **⛔ 硬性规则**：Agent 在开始任何数据采集、模式判定、分析写作之前，**第一步必须先判断本次复盘指令来自哪个客户端**。判断错误会导致输出格式不符（把 HTML 发给不能浏览的手机，或把文字版发给想看图表的电脑），因此本规则强制优先执行。

### 判断依据（从用户指令本身识别）

| 判断信号 | 判定为电脑客户端 | 判定为手机 App |
|---------|-----------------|---------------|
| **指令明示** | 用户说"生成网页/HTML报告/图表/浏览器看" | 用户说"文字版/不要HTML/手机上看/纯文本" |
| **指令载体特征** | 在聊天中输入长结构化指令、引用文件路径、要求"可视化/图表/报告" → 倾向电脑 | 用户提到"手机上/App/打开不方便/看不到网页" → 倾向手机 |
| **历史行为** | 用户过往对 HTML 报告有正向反馈、要求生成报告文件 | 用户过往要求"直接输出文字/太长了/手机看" |
| **上下文痕迹** | 会话中涉及 `computer://` 链接、报告文件目录、浏览器预览 | 会话要求"精简/压缩/手机友好" |

**核心判断原则**：
1. **用户指令明确时，以用户明示为准**（用户说"文字版"就输出文字，说"HTML"就输出HTML）
2. **用户未明示时**：若无任何手机线索，默认按**电脑客户端**处理（输出 HTML 报告，附带 `computer://` 文件链接）；若指令中出现手机相关线索（"手机""App""打开不方便""看不到网页"），则按手机处理，**直接输出文字版 Markdown，不生成 HTML 文件**
3. 当从对话上下文中能判断出用户设备时，跟随上下文的稳定推断

### 两种输出模式的分工

| 模式 | 适用客户端 | 交付物 | 特点 |
|------|-----------|--------|------|
| **HTML 模式** | 电脑客户端（内置浏览器） | 自包含 `.html` 文件（ECharts 图表） | 可视化、图表丰富，交付 `computer://` 链接 + 聊天摘要 |
| **文字版模式** | 手机 App（暂不支持 HTML） | 纯文本 Markdown（直接展示在聊天中） | 信息密度高、可一键复制，图表用文字/表格代替 |

### 文字版模式的写作要求

当判定为手机 App（文字版）时，**必须完整保留 16 章分析框架的全部维度**，只是以纯 Markdown 文字方式呈现而非 HTML：

- **16 章结构一个不能少**：从章零到章十六，每一章的核心分析维度都必须覆盖。文字版与 HTML 版的区别仅在呈现形式，不在分析深度
- **图表转表格**：HTML 中的 ECharts 折线图/柱状图/雷达图，在文字版中改为 Markdown 表格呈现（指数数据用表格、涨跌幅排序用表格、多空辩论用结构化文字）
- **HTML 卡片转 Markdown 段落**：HTML 中的数据卡片、结论卡片，在文字版中改为 `###` 标题 + 加粗关键数据 + 连续自然段
- **核心分析章节（章零、一、二、三、五、七、十六）使用连续自然段**：一个完整逻辑链写成一个段落，避免一句话一个段落的碎片化
- **每个事实/结论只讲一次**：不同章节之间不重复同一数据点，章一讲过的数据章五引用时一句话带过
- **因果传导链保留**：每条关键新闻的归因仍须讲清四层（改变什么预期→谁受益为何→资金先手还是跟风→逻辑能否持续），用连贯自然段呈现
- **盘前预测模式同样适用**：6 段结构完整保留，每段内容不缩减，只是以 Markdown 文字呈现

## 交易日检查

开始任何数据采集前，先判断目标日期是否为 A 股交易日。周末或中国法定节假日（A 股休市）时，告知用户「今日休市，无交易数据」，停止后续流程。

### 国家队护盘信号监控（宽基ETF + 券商银行）

> 国家队（汇金/证金等）护盘通常通过宽基ETF大额申购和拉升券商/银行板块实现。以下命令采集关键信号数据。

```bash

# 券商板块 + 银行板块行情（申万行业）
westock-data search 券商 --type sector

# 拿到板块代码后：
# westock-data sector info <券商板块代码>
# westock-data sector info <银行板块代码>
# westock-data fund flow <券商板块代码>
# westock-data fund flow <银行板块代码>

# 宽基ETF近期K线（判断是否有持续放量申购痕迹）
westock-data kline sh510300 --period day --limit 10
westock-data kline sh510050 --period day --limit 10
```

**国家队护盘识别逻辑**：

| 信号 | 判定条件 | 强度 |
|------|---------|------|
| 宽基ETF异常放量 | 单只宽基ETF成交额 > 近5日均值2倍 | 中 |
| 宽基ETF持续净流入 | 连续3日主力净流入且日均 > 1亿 | 中 |
| 多只宽基ETF同步流入 | >=3只宽基ETF同日主力净流入 | 强 |
| 沪深300ETF + 上证50ETF双流入 | 510300和510050同日净流入 | 强（汇金经典操作） |
| 券商板块异动拉升 | 券商板块涨幅 > 1%且资金净流入 | 中 |
| 银行板块逆势走强 | 大盘下跌但银行板块上涨 | 中 |
| 券商+银行双拉升 | 两板块同日涨幅 > 0.5%且资金净流入 | 强 |
| 尾盘集中放量（盘中模式） | 14:30后宽基ETF成交额突然放大 | 强（尾盘护盘信号） |

> 当 >=2个「强」信号或 >=3个「中」信号同时出现时，可判定为「国家队护盘信号明显」，在报告中单列提示。

## 盘前预测模式（核心新增 · 时间因果与消息泄露度）

> **⛔ 本模式是全新升级，核心是「时间因果」+「消息泄露度」双判断。** 旧版把「盘后才发布的新闻 / 隔夜美股」一律排除在当日归因之外，这过于绝对——实际上**部分消息在发布前就可能被"聪明钱"抢跑**（提前泄露），资金确实会提前埋伏。正确做法不是一刀切禁用，而是**分级判断每条消息的可泄露性**，再决定能否用它解释当日盘面。

### 时间因果铁律（基线）

| 你要回答的问题 | 只能使用哪个时间窗的信息 | 说明 |
|--------------|------------------------|---------|
| 昨日（T-1）为何上涨/下跌 | T-2 盘后 → T-1 开盘前已公开的信息 | 这是当日资金决策的确定依据 |
| 今日（T）开盘预测 | T-1 收盘后 → T 开盘前（隔夜美股、盘后政策、早间消息） | 今日预测的确定Trigger |
| 今日（T）全天推演 | T-1 状态(State) + 隔夜触发(Trigger) → 推演 T 资金响应(Flow) | 预测主线 |

### 消息泄露度分级（在本铁律之上·智能豁免）

**核心逻辑**：若某条"盘后才正式发布"的消息，其**核心内容在盘前已可被提前获知**（存在泄露渠道），则它**可以**用来解释当日盘中的提前反应；反之，若消息真正无法提前预知，则禁止用它倒推当日盘面。

| 消息类型 | 可泄露性 | 能否解释当日盘面 | 判断依据 |
|---------|---------|----------------|---------|
| **政策文件/会议纪要**（如央行货币政策报告、国常会通稿） | 高（起草/审阅/吹风阶段易泄露，卖方会提前路演） | **可以**，需标注"存在提前泄露可能" | 观察盘前是否有资金提前潜伏相关板块、板块是否在消息发布前已异动 |
| **产业订单/大客户/扩产**（如SK海力士扩产、阿里云超节点） | 中高（产业链公司/调研纪要/卖方覆盖会提前知情） | **可以**，需标注"存在抢跑可能" | 看相关个股是否在消息前已有资金布局、是否逆势走强 |
| **宏观数据**（CPI/PMI，官方定时发布） | 低（有严格保密，但市场有预测共识） | 有限（只能解释"预期差"导致的波动） | 看实际值 vs 市场一致预期的偏离 |
| **美股隔夜收盘/美联储决议** | 极低（A股无法提前知道，只能盘前反应） | **禁止**用于解释T-1盘中，只能用于T开盘预测 | 时间上T-1盘中时美股尚未收盘 |
| **突发地缘/黑天鹅**（如突发冲突、单交易日爆雷） | 极低（无法预知） | **禁止**倒推，只能做事后归因 | 无法提前埋伏 |

**操作原则**：
1. 基线是"昨日走势看昨晨已公开信息、今日预测看隔夜信息"
2. **内部评估、外部呈现**："可泄露性""抢跑"是分析者在**内部推理**时评估资金有无可能提前知情用的，**不要把"可泄露性""泄露度""有抢跑可能"等词写进报告**。报告只呈现判断结果和证据
3. **呈现方式**：当判断资金在某消息发布前已先手买入时，直接写"资金在消息公开前已提前潜伏/布局，从某板块某时点逆势走强可见"，并给出证据；不用解释评估过程
4. **不豁免**：美股隔夜收盘、突发黑天鹅等真正无法提前预知的，归入"今日预测Trigger"，不倒推昨日盘中
5. 判断标准是**消息发布前资金有无可能提前知情**，而非消息发布时间本身

- 用户使用「盘前分析 / 盘前预测 / 今日预测 / 早盘预判 / 开盘预测」等词
- 或当前时间为交易时段之前（09:00 前）且用户要求 A 股分析，默认走本模式

### 报告结构（盘前预测，6 段）

1. **昨日复盘速览（State 起点）**：昨日指数、量能、涨停/跌停、主线、情绪。只陈述事实，不做过度的"归因深挖"（归因要归到昨日开盘前信息，简略即可，重点放在今日预测）
2. **隔夜关键信息（Trigger）**：T-1 收盘后到今天开盘前发生了什么，按"宏观/政策/产业/海外/地缘"分类。
   - **每条信息必须讲清因果传导链，禁止简单关联**。不要写"央行宽松→利好→涨"这种废话。必须回答四层：
     - **这条消息改变了什么预期**（资金原本怎么想，消息如何改变）
     - **谁最受益、为什么是它**（传导到哪条产业链/哪个环节/哪个公司，机制是什么）
     - **资金是先手还是跟风**（内部判断资金是否在消息公开前已先手买入；若是，写明从板块何时点逆势走强可见）
     - **此逻辑能否持续**（是预期博弈还是有实质兑现，明天/下周还能不能讲）
   - **证据等级**：标注高/中/低
3. **今日三大预测（核心）**：
   - **开盘预测**：高开/低开/平开，幅度区间（如"高开 0.3%~0.6%"），依据是什么
   - **分时节奏推演**：上午看什么（如科技能否放量）、午后看什么（如权重是否护盘）、尾盘看什么
   - **主线承接预判**：昨日主线今日会延续/扩散/退潮？哪些新方向可能接力？给出证据等级
4. **量能与情绪预判**：预测今日成交额区间（放量/缩量）、涨停家数区间、情绪温度，给出"什么信号代表预测成立/失败"
5. **情景推演（概率加权）**：乐观/中性/悲观三情景，各给概率 + 关键触发条件 + 对应操作
6. **操作策略与风险提示**：仓位建议、今日关键观察点、风险警示

### 写作要求

- **预测必须具体可验证**：不要"可能反弹"，要"若高开0.5%+量能充足，则有望冲上 X 点；反之若低开，则回踩 Y 支撑"。给出点位、量能阈值、时间点
- **概率明确**：每个情景给具体概率（如 40%/40%/20%），并说明是什么信号会改变概率
- **证据等级**：每个预测标注证据等级（高/中/低），说明依据
- **不凑字数**：信息密度优先，一件事只讲一次，把篇幅用在"今日预测"而非重复昨日数据

## 盘中概览模式（盘中分析报告）

> 当用户使用「盘中概览 / 盘中分析 / 盘中复盘 / 实时盘面 / 盘中速览 / 盘中报告」等词触发时进入本模式。
> 与本技能「收盘复盘」的差别：数据取**当前实时快照**，分析聚焦「现在发生了什么、谁在领涨、本时段看什么」，不做次日推演。
> 底层数据源（westock-data / westock-tool / neodata）本就返回实时快照，无需改动取数命令，只需把查询口径从「收盘+日期」改为「当前/实时」。

### 交易时段判定（先于任何采集 · 强制执行）

> **⛔ 硬性规则**：Agent 在进入任何数据采集或模式判定之前，**必须**通过系统命令（如 `Get-Date` / `date`）获取当前北京时间，**不得凭经验或上下文猜测时间**。A 股收盘时间为 15:00，当前时间 < 15:00 且为交易日时，一律视为**盘中模式**；当前时间 >= 15:00 时方可进入**收盘复盘模式**。违反此规则会导致使用错误的数据口径和分析框架。

A 股交易时段（北京时间 GMT+8，遵循 wb-finance-skill 时区口径）：

- 盘前：09:00–09:30（集合竞价 09:15–09:25）
- 早盘：09:30–11:30
- 午间休市：11:30–13:00
- 午盘：13:00–14:30
- 尾盘：14:30–15:00（尾盘竞价 14:57–15:00）
- 盘后：15:00–16:00（龙虎榜、盘后公告陆续披露）
- 其他时段（含周末 / 法定节假日）= 非交易时段

**执行步骤**（严格遵守）：

1. 调用系统命令获取当前北京时间（如 PowerShell `Get-Date -Format "yyyy-MM-dd HH:mm:ss zzz"`）
2. 判定是否为交易日（周末/法定节假日休市 -> 非交易时段）
3. 若为交易日，根据当前时间匹配上表时段
4. **当前时间 < 15:00 -> 盘中模式**（即使仅差几分钟收盘，也按盘中处理，数据取实时快照）
5. **当前时间 >= 15:00 -> 收盘复盘模式**（可叠加龙虎榜、盘后公告）
6. 在报告中标注「**数据时点 + 所属时段**」，再决定采集与解读口径：盘前看昨收与竞价信号、盘中看实时快照、盘后叠加龙虎榜与公告、非交易时段退化为「最近一个交易日快照」并明确标注，不编造实时数据

## 核心分析框架（所有路径强制适用）

> 以下分析框架应用于所有分析路径（路径一～五），是复盘报告的方法论基础。**禁止将行情简单归因于当天的新闻**，必须先判断市场原有的仓位状态和信念底色。

### 市场 = 状态（State） + 触发器（Trigger） + 资金响应（Flow）

A 股市场同样适用 State-Trigger-Flow 框架，且在涨跌停制度和 T+1 交易规则下，状态判断比美股更为关键——因为一旦方向判断错误，T+1 无法当日纠错，代价远高于美股。

| 维度 | 定义 | A 股特有含义 |
|------|------|-------------|
| **状态（State）** | 市场进入今天的"底色"——仓位结构、信念共识、情绪温度 | 涨停连板高度、炸板率、量能趋势、主线板块的拥挤度（是否已经过于一致） |
| **触发器（Trigger）** | 打破状态平衡的事件——宏观数据、政策、产业催化、突发新闻 | 政策文件、产业规划、涨价函、龙虎榜席位变化、北向资金异动 |
| **资金响应（Flow）** | 触发器引发资金如何流动——板块轮动方向、资金攻击方向、撤退方向 | 涨停封单量、主力净流入/流出、北向资金净买入、ETF资金流向、连板梯队封板强度 |

**禁止行为**：先看收盘K线再找理由。必须还原"今天开盘时市场是什么状态 → 过程中发生了什么 → 资金如何响应 → 最终K线怎么走出来"的时间顺序。

### 分析方法论（强制四步法）

每个核心判断必须经过以下四步，缺一不可：

1. **观察事实** — 盘面发生了什么，数据是什么（先写盘面事实，再写推导，再写结论）
2. **排除其他解释** — 为什么不是其他常见解释（排除法，避免"拿着结果找原因"）
3. **给出最可能解释** — 基于排除后的剩余选项，给出最合理的因果链，明确标注"证据等级"（高/中/低）
4. **附反证条件** — "如果这个判断是错的，盘面应该出现什么信号"（让读者可以自行验证判断的有效性）

### 叙事竞争分析框架

每次分析必须区分两个层面：

- **局部定价权** — 某条叙事在板块层面赢了（如"数据要素"叙事推动计算机板块领涨，但大盘指数下跌）
- **全局定价权** — 某条叙事在指数层面赢了（如"稳增长政策"叙事推动上证指数收涨，但AI板块反而下跌）

必须回答：哪条叙事赢得了局部定价权？哪条赢得了全局定价权？为什么？

### 多时间维度分析原则（强制）

所有分析结论必须注明是哪个时间窗口的判断，禁止用单日数据下中期结论：

| 时间窗口 | 关注重点 | 解决的问题 |
|---------|---------|-----------|
| **当日（1D）** | 涨跌幅、成交量、资金流向、新闻驱动 | 今天发生了什么 |
| **近5日（5D）** | 趋势方向、板块轮动持续性、量能变化趋势 | 当前的短期趋势是什么 |
| **近20日（20D）** | 中期趋势、均线系统、支撑/阻力位、累计资金流向 | 中期方向如何，是否值得参与 |

**写作基调**：基于数据推演，结论有依据。关键句式：「当前阶段的判断是……」「等信号确认而非提前押注」「宁可错过机会也不做无把握的决策」

### 路径二：情绪周期分析

**匹配场景**：用户关注市场情绪、短线氛围、赚钱效应与亏钱效应。

**分析维度**：五维情绪评估。

**分析清单**：

| 维度 | 核心问题 | 结论输出 |
|------|---------|---------|
| 量温度 | 涨停数、跌停数、连板数、炸板率、红盘占比 | 温度决定仓位上限 |
| 识主线 | 领涨板块与龙头、跟风是否批量跟随 | 龙头+跟风齐涨 = 情绪健康；龙头独涨 = 不健康 |
| 测亏钱效应 | 昨日追高者今日盈亏、高位股是否补跌、炸板股次日开盘表现 | 亏钱效应扩散时机会减少、陷阱增多 |
| 判持筹心态 | 持仓者卖出意愿、抛压轻重、场外资金入场意愿 | 核心是判断市场心理，不是看价格 |
| 空仓检验 | 假设空仓，选哪只标的、胜算多少、预期涨幅 vs 下跌空间 | 赢面不足 60% 则不操作 |

**输出格式**：自包含 HTML，包含大盘概览、赚钱效应、亏钱效应、情绪周期（情绪温度计 + 周期定位）、板块轮动、连板梯队（含龙头质量评级 S/A/B/C）、龙虎榜博弈、风险评估、明日策略九个板块。样式遵循 `references/html_report_style.md`。保存建议：`./daily-review/情绪周期_YYYYMMDD.html`。

**写作基调**：短句为主、结论先行。每个板块先给结论再列数据支撑。

## 核心逻辑底层拆解（所有路径默认必含）

> **硬性规则**：路径一～四的复盘报告中，**必须包含**本节内容。这是复盘的灵魂——不只告诉用户"涨了什么"，更要讲清"为什么涨、能不能持续、背后的产业/资金/情绪逻辑是什么"。

### 定位与原则

- **位置**：放在"板块表现"之后、"技术面分析"之前（或在"核心驱动"章节中展开）
- **数量**：每次拆解 1-3 个当日最核心的驱动/主线方向，不要贪多
- **深度**：每个方向按"事实→传导→映射→持续性判断"四层展开
- **风格**：像给朋友讲明白一样，不用黑话，用大白话讲清产业逻辑

### 四层拆解框架（默认模板）

针对当日最强的 1-3 个主线方向，每个方向按以下四层展开：

| 层级 | 内容 | 要回答的问题 |
|------|------|-------------|
| **第一层：事实** | 发生了什么具体事件/数据 | 到底是什么触发了行情？ |
| **第二层：传导** | 这个事件/数据如何传导到对应板块 | 为什么利好/利空这个板块？产业逻辑是什么？ |
| **第三层：映射** | 对应到 A 股是哪些公司/细分方向受益 | 具体买什么？龙头是谁？弹性最大的是谁？ |
| **第四层：持续性** | 这波行情能走多久？是一日游还是趋势 | 明天/下周还能涨吗？需要什么条件验证？ |

### 常见拆解方向与方法论

根据当日行情特征，选择最核心的 1-3 个方向深入拆解：

**方向 A：海外传导（美股/港股 → A股）**
- 适用场景：隔夜美股大涨/大跌、美股科技股财报、美联储利率决议、地缘事件
- 拆解要点：
  - 美股涨/跌的具体原因是什么？（财报？政策？宏观？）
  - 传导链条是什么？（美股科技股 → A股半导体？美股消费 → A股消费？）
  - 历史上类似情景 A 股的表现如何？
  - 这次有没有不一样的地方？（量级、持续性、催化剂强度）

**方向 B：政策催化（国内政策 → 对应板块）**
- 适用场景：国务院/部委政策、产业规划、监管动态、地方政策
- 拆解要点：
  - 政策的核心内容是什么？（不要只看标题，看具体措施）
  - 直接受益的环节和公司是哪些？
  - 政策力度有多大？（真金白银还是口号？）
  - 是短期刺激还是长期趋势？

**方向 C：产业趋势（技术突破/产品迭代 → 产业链）**
- 适用场景：AI 大模型发布、新产品发布、技术突破、涨价/降价
- 拆解要点：
  - 技术/产品突破在哪里？（是质变还是量变？）
  - 产业链哪个环节最受益？（上游材料？中游制造？下游应用？）
  - 业绩兑现周期有多长？（本季度？明年？还是更远？）
  - 市场预期打满了吗？（估值贵不贵？）

**方向 D：资金行为（机构/北向/游资 → 风格切换）**
- 适用场景：风格极端分化、北向大额流入流出、机构调仓、量化策略变化
- 拆解要点：
  - 谁在买？谁在卖？（北向？机构？游资？散户？）
  - 为什么买/卖？（调仓？避险？追涨？抄底？）
  - 这种资金行为的历史持续性如何？
  - 有没有背离信号？（资金流入但股价不涨/跌）

**方向 E：情绪周期（极端情绪 → 反转/延续）**
- 适用场景：冰点/高潮日、极端涨跌比、连续大涨/大跌后
- 拆解要点：
  - 当前情绪在什么位置？（冰点？修复？高潮？退潮？）
  - 历史上类似情绪位置后市场怎么走？
  - 有没有情绪反转的信号？（跌停数骤降/涨停数骤增？）
  - 情绪修复的强度够不够？（量能？广度？持续性？）
**方向 F：反弹定性分析（鹏华早评框架）**
- 适用场景：市场经历连续下跌后出现反弹，需要判断反弹的性质
- 拆解要点：
  - 反弹的性质是什么？（超跌技术修复 / 政策驱动反弹 / 趋势反转？）
  - 反弹的力度如何？（量能配合程度、领涨板块的持续性）
  - 反弹的空间有多大？（上方阻力位、套牢盘密集区、均线压制）
  - 重势 vs 重消息：趋势驱动型反弹（重势，关注均线修复和量能持续）vs 消息驱动型反弹（重消息，关注催化剂的持续性和新消息跟进）
  - 反弹的失效条件是什么？（缩量、龙头熄火、关键阻力位遇阻）
  - 操作策略：反弹初期可参与，但需设好止损位；反弹中后期逐步减仓，不追高

**方向 G：板块热点密度与Token经济学分析（热点追踪框架）**
- 适用场景：市场热点分散、板块轮动加快、需要量化评估热点强度
- 拆解要点：
  - 按板块分类的新闻密度：统计各板块近3日相关新闻/公告的数量，量化热点热度
  - Token经济学分析：将板块视为"经济体"，分析其"Token消耗效率"（资金使用效率）、"Margin定价权"（板块利润空间）、"流通速度"（资金轮动速度）
  - 供应链映射：将事件/政策/涨价映射到产业链各环节，判断最受益的环节和公司
  - 热点持续性评估：板块热度是否在扩散（跟风股增多）还是收敛（龙头独涨、跟风乏力）
  - 板块资金效率：板块成交额占比 / 板块市值占比，衡量资金过度集中还是分散
### 写作要求

1. **结论先行**：每段拆解开头先给一句话核心结论，再展开讲逻辑
2. **用数据说话**：有具体数字支撑（涨跌幅、成交额、增速、估值等），不要空泛
3. **诚实表达不确定性**：拿不准的就说"需要观察""有待验证"，不要硬编
4. **正反两面（Bull/Bear双面呈现）**：既讲利好逻辑，也讲风险点和可能的证伪条件。**并增加说明**：模仿TradingAgents的多智能体辩论机制，每个判断必须有正反两面，让多头和空头各自陈述，先展示熊市观点（风险优先）再展示牛市观点。
5. **不超过 3 个方向**：宁少勿滥，把最核心的讲透比讲一堆浅的好
6. **语言通俗**：避免堆砌专业术语，用类比和大白话讲清
7. **连续阅读原则**：关键分析段落（章零、一、二、三、十六）使用**连续自然段**写作，一个完整逻辑链写成一个段落，避免一句话一个段落。辅助数据可用卡片/表格，但核心分析不能碎片化。核心段落的写作节奏应为：结论句 → 数据支撑句 → 推导过程句 → 与前后文的关联句 → 限制条件/反证条件句
8. **状态优先原则**：先诊断市场状态（State），再分析触发器（Trigger），最后看资金响应（Flow）。禁止将行情简单归因于当天的新闻，必须先判断市场原有的仓位状态和信念底色
9. **叙事竞争原则**：每次分析必须区分"局部定价权（板块层面）"和"全局定价权（指数层面）"，并量化叙事权重。必须回答：哪条叙事赢得了局部定价权？哪条赢得了全局定价权？为什么？
10. **四步法原则**：每个核心判断必须经过"观察事实→排除其他解释→给出最可能解释→附反证条件"四步，缺一不可。关键结论必须标注"证据等级"（高/中/低）

## TradingAgents 多智能体辩论式分析框架（新增·核心）

> 参考 TradingAgents（GitHub 80K+ Stars，Tauric Research 开发）的多智能体协作框架，在 A 股复盘报告中引入结构化辩论机制，弥补原有分析中「只讲一面、缺乏多空对抗」的短板。

### 为什么 TradingAgents 对 A 股复盘同样重要？

A 股市场比美股更加情绪化、博弈属性更强——涨停板制度、T+1 交易、散户占比高、政策驱动频繁。这意味着 A 股复盘不能只做「数据罗列」或「单向叙事」，而必须：

- **多空双方各自陈述理由**：让"看多的人"和"看空的人"在报告中正面交锋
- **量化风险与机会的胜率**：不只是说"有机会"或"有风险"，而是给出具体概率判断
- **区分不同角色的分析视角**：基本面分析师的业绩判断 ≠ 情绪分析师的恐慌/贪婪判断 ≠ 技术分析师的支撑/阻力判断
- **给出可执行的交易决策**：综合所有角色的判断后，由"交易员"角色做出最终操作建议

### 核心借鉴：TradingAgents 8 角色 → A 股复盘映射

| TradingAgents 角色 | A 股复盘中的对应分析维度 | 输出内容 |
|-------------------|------------------------|---------|
| 基本面分析师 | 财报/估值/行业景气度/产业周期 | 标的业绩趋势、估值合理性、行业周期位置 |
| 情绪分析师 | 涨停跌停比/炸板率/连板高度/成交额变化 | 市场恐慌/贪婪程度、情绪周期定位 |
| 新闻分析师 | 政策解读/产业催化/消息面/龙虎榜席位 | 关键驱动事件及影响评估、政策力度判断 |
| 技术分析师 | K线形态/均线系统/MACD/KDJ/成交量/支撑阻力 | 技术形态、关键价位、趋势方向判断 |
| 牛市研究员（Bull） | 看多逻辑汇总 | 买入理由、催化因素、上涨空间、目标价位 |
| 熊市研究员（Bear） | 看空逻辑汇总 | 风险警示、下跌风险、证伪条件、止损位 |
| 风险管理师 | 仓位管理/回撤控制/市场环境评估 | 当前建议仓位、最大亏损额度、止盈止损纪律 |
| 交易员 | 综合决策输出 | 最终操作建议（方向/标的/仓位/时机/条件单） |

### 报告中的辩论式呈现格式

在复盘报告中，针对关键方向（指数、主线板块、核心标的），采用以下结构化辩论格式：

```
### 多空辩论：{方向/板块/标的}

**🐂 多头观点（牛市研究员）**
- 论据1：{数据/逻辑支撑}
- 论据2：{数据/逻辑支撑}
- 论据3：{数据/逻辑支撑}
- 目标空间：{预期涨幅/上行空间}

**🐻 空头观点（熊市研究员）**
- 论据1：{数据/逻辑支撑}
- 论据2：{数据/逻辑支撑}
- 论据3：{数据/逻辑支撑}
- 风险程度：{预期跌幅/下行风险}

**⚖️ 综合判断（交易员）**
- 胜率倾向：{多头/空头/中性}
- 胜率评估：{60%/70%/50% 等具体概率}
- 关键验证条件：{什么情况下多头胜/空头胜}
- 触发条件：{需要看到什么信号才行动}

```

### 在复盘报告中的使用场景

| 场景 | 辩论对象 | 典型问题 |
|------|---------|---------|
| 指数方向 | 上证指数/创业板指 | 4000点能否突破？回调还是反转？ |
| 主线板块 | 当前最强板块（如医药、有色） | 板块行情是一日游还是趋势？ |
| 核心标的 | 龙头股/持仓股 | 追高还是等待回调？止盈还是持有？ |
| 市场整体 | 全市场状态 | 进攻还是防守？加仓还是减仓？ |
| 资金方向 | 北向资金/主力资金 | 外资是真看好还是短期博弈？ |

### 执行原则

1. **每个方向至少 2 条论据**：Bull 和 Bear 各至少 2 条有数据支撑的论据，避免空洞的"看好/看空"
2. **胜率必须量化**：综合判断中给出具体胜率（如 60%/70%），而非模糊的"大概率"
3. **验证条件必须可观测**：多空胜负的条件必须是次日/次周可验证的具体信号（如"成交量>2.8万亿"、"突破4000点"等），而非模糊的"如果市场好转"
4. **风险优先**：先展示熊市观点（风险警示），再展示牛市观点，最后给出综合判断
5. **与现有框架互补**：不替代核心逻辑拆解和板块分析，而是在这些分析的基础上增加多空辩论维度

### 反弹定性分析模块（鹏华早评框架）

当市场出现反弹行情时触发。本模块包含三个子框架：

**框架A：反弹性质判断**
| 反弹类型 | 特征 | 操作策略 | 失效条件 |
|---------|------|---------|---------|
| 超跌技术修复 | 缩量止跌、无量反弹、无主线、无催化 | 不参与或轻仓博弈 | 遇阻回落、二次探底 |
| 政策驱动反弹 | 政策利好明确、板块有响应、量能温和放大 | 可参与龙头方向，设好止损 | 政策落地后无后续、资金不跟进 |
| 趋势反转 | 放量突破关键阻力位、主线清晰、情绪持续回暖 | 积极参与，逐步加仓 | 假突破、缩量回踩破位 |
| 事件驱动反弹 | 突发事件催化、板块热度集中、持续性存疑 | 快进快出，不恋战 | 事件消化后回落 |

**框架B：重势 vs 重消息对冲逻辑**
- **重势（趋势驱动）**：均线系统修复、量能持续温和放大、板块轮动有序 → 重趋势，轻消息，关注技术面信号
- **重消息（消息驱动）**：突发政策/事件催化、板块热度集中、龙头连续涨停 → 重消息，轻趋势，关注催化剂的持续性和新消息跟进
- **对冲逻辑**：当趋势和消息方向一致时 → 最强共振，可积极参与；当趋势和消息方向背离时 → 谨慎操作，以趋势为主，消息为辅

**框架C：操作策略建议**
- 反弹初期（指数在支撑位附近、缩量止跌、底分型出现）：左侧试探仓位，严格止损
- 反弹确认（放量突破5日线、MACD拐头、龙头出现）：加仓到正常仓位
- 反弹延续（持续放量、主线清晰、板块轮动有序）：持有为主，逐步减仓
- 反弹末期（缩量滞涨、龙头松动、跟风乏力）：减仓防守

```
- 人民币汇率走势对北向资金的影响
- 中美关系/地缘政治对资金流的潜在影响
- 全球流动性环境变化
```

**数据采集**：通过联网搜索获取，执行命令参考"外资机构观点采集"小节。

### 多空辩论模块（TradingAgents）

当用户要求"多空分析""辩论式复盘""Bull/Bear""多空力量对比"或用户提供具体标的时触发。

**触发条件**：用户明确要求多空辩论分析，或复盘报告中的关键方向存在明显分歧。

**数据采集**：在已有数据基础上，针对辩论对象额外采集：
- 技术面数据（支撑/阻力位、均线位置、成交量变化）
- 消息面数据（最新公告、行业新闻、政策动态）
- 资金面数据（主力资金流向、北向资金、龙虎榜）

**输出结构**：

```
### 多空辩论：{辩论对象}

**🐂 多头逻辑链**
1. {核心逻辑}：{数据支撑}
2. {核心逻辑}：{数据支撑}
3. {核心逻辑}：{数据支撑}
→ 目标空间：{上行目标}

**🐻 空头逻辑链**
1. {核心风险}：{数据支撑}
2. {核心风险}：{数据支撑}
3. {核心风险}：{数据支撑}
→ 风险程度：{下行风险}

**⚖️ 综合判断**
- 胜率：{具体概率}
- 多空胜负条件：{具体可观测信号}
- 触发条件：{什么情况下入场/离场}
- 建议：{操作方向+仓位+纪律}
```

**应用场景**：
- 指数方向辩论（如"上证指数能否突破4000点"）
- 主线板块辩论（如"医药板块行情持续性"）
- 持仓标的辩论（如"亨通光电冲高回落后的操作"）
- 市场状态辩论（如"当前是反弹还是反转"）

**注意事项**：
- 每个辩论方向须有至少2条有数据支撑的论据
- 胜率须给出具体数值（60%/70%等），而非模糊表述
- 验证条件须是可观测的具体信号
- 综合判断须包含操作建议和仓位建议

## 自媒体文案总结模块（新增 · 可选附加）

> 在完整复盘的基础上，额外生成一份**适合公众号/小红书/朋友圈等社交平台传播的短文案总结**。
> 用户明确要求"整合成几段话""公众号文案""小红书文案"时触发。可附加在任何分析路径之后。

### 适用场景

| 场景 | 触发关键词 | 输出格式 |
|------|-----------|---------|
| 公众号推文 | "公众号文案""整合成几段话""总结成文案" | 纯文本 Markdown，4-5段，每段120-200字 |
| 小红书/朋友圈 | "小红书文案""朋友圈文案""短文案" | 纯文本，3-4段，每段80-150字，轻量化 |
| 盘前简报 | "早盘文案""开盘前文案" | 纯文本 Markdown，3段，侧重当日关注点 |
| 复盘摘要 | 不指定平台时 | 默认公众号风格，4段 |

### 文案结构模板（公众号风格）

参考鹏华早评、热点追踪等机构自媒体文案风格，采用以下四段式结构：

```
【第1段：宏观锚点与市场情绪】

一句话定性今日市场状态（进攻/修复/分歧/退潮）→ 核心指数表现（上证/深证/创业板/科创50）→ 量能变化（成交额增减）→ 涨跌家数/涨跌停比 → 市场情绪温度 → 海外宏观影响（美股/汇率/美债/地缘）→ 国内宏观数据（CPI/PPI/政策）

【第2段：上涨驱动与核心催化】

今日/本周上涨的核心驱动力是什么 → 哪条产业/政策逻辑在兑现 → 上周/昨日发生了什么关键事件 → 这个催化剂是一日游还是趋势性 → 机构的普遍看法 → 外资/北向资金的态度

【第3段：板块轮动与资金博弈】

当前领涨方向（TOP 3-5板块，含涨幅和驱动）→ 领跌方向（及原因）→ 资金高低切换特征 → 连板梯队/龙头表现 → 资金流向（主力净流入/流出TOP）→ 北向资金动态 → 板块轮动是"一日游"还是"趋势切换"

【第4段：操作策略与关注清单】

当前市场状态定性（反弹/反转/震荡/退潮）→ 仓位建议（几成仓）→ 次日关注重点（核心事件/数据/技术位）→ 风险提示（什么情况下需要减仓/离场）→ 一句话总结

———

※ 以上分析基于公开数据，不构成投资建议
```

### 写作指南

#### 语言风格
- **Insider 口吻**：适度使用"其实也早有判断""我们看""都有收获了"等暗示信息优势的表达
- **预判式表达**："如果…还是机会""不好说""可能"——保留余地但给出倾向
- **市场黑话适度**：可嵌入"鬼故事""打了样""水温""小碎步""反包""高低切"等行话，筛选读者
- **多空平衡术**：每段含"一方面…另一方面…"或转折，避免绝对判断
- **结论后置弱化**：核心观点埋于段末，非标题式强调

#### 信息密度
- 每段120-200字，信息密度高，语言精炼
- 数据精确到小数点后两位数（如"+0.67%"、"2.54万亿"）
- 关键数据使用**加粗**强调
- 避免大段引用，用"据悉""市场反馈""产业催化"等中性表述

#### 结构要点
- 编号体系用阿拉伯数字1-4，平行并列结构
- 每段150-200字，属于"中高密度段落"
- 逗号密集、句号节制，单句偏长（典型书面口语混合体）
- 括号用于补充说明，非正文信息

#### 合规要求
- 文末必须加风险提示：「以上分析基于公开数据，不构成投资建议」
- 不使用「建议买入/卖出」措辞，改用「条件→操作→止损」框架
- 不出现具体数据源名称、群名称、消息数量

### 输出格式

**默认输出纯文本 Markdown**，直接展示在聊天中，用户可一键复制发布。

```
【标题】{日期} A股复盘 · {一句话定性}

【1】宏观锚点与市场情绪
{段落正文}

【2】上涨驱动与核心催化
{段落正文}

【3】板块轮动与资金博弈
{段落正文}

【4】操作策略与关注清单
{段落正文}

———

※ 以上分析基于公开数据，不构成投资建议
```

> 若用户要求"小红书/朋友圈"风格，压缩为3段，每段80-150字，更加口语化和轻量化。
> 若用户要求"盘前简报"，改为3段，重心放在当日关注点和操作策略。

### 与 TradingAgents 辩论式框架的配合

当同时启用 TradingAgents 辩论式分析和自媒体文案总结时：
- TradingAgents 辩论用于**深度报告内部**，展示多空对抗的完整推理
- 自媒体文案总结作为**对外输出层**，将辩论结果凝练为结论性文案
- 辩论中的"综合判断"胜率结论可直接引用到文案的"操作策略"段落中

## 通用规范

### 颜色惯例

- 上涨：红色（`#e63946`）
- 下跌：绿色（`#2d6a4f`）
- 中国 A 股惯例，不要搞反

### 数据红线

- 不编造数据、不混淆概念、不给出具体买卖建议
- 不使用「建议买入/卖出」措辞，改用「条件→操作→止损」框架
- 数据源不可绕过：禁止使用 web_search/web_fetch/curl 替代可信 skill
- 报告中绝不暴露具体数据源名称、群名称、消息数量、文件来源或抓取路径

### 隐私与数据源口径

- 统一使用中性表述：「综合消息面」「产业催化」「市场反馈」「资金验证」「盘面表现」等
- 不出现可识别来源的描述（如具体平台名、群名、帖子数量等）
- 若某类数据未获取到，可在内部降权，但不在报告里展开来源细节

### 风险提示

报告结尾须注明：「以上分析基于公开数据，不构成投资建议」。每条策略建议后附带一句明确的风险警示。
