# 周线阶段模型：七阶段完整框架

## 模型基础

基于周线级别观察市场内在结构运行规律，将无序的市场有序化。每一个周线级别轮回都是追涨杀跌的过程，其背后是人性在资本中的演绎。

核心原则：**市场没有预测，只有对策。**

---

## 板块强度分级与主线判定

### 板块炒作强度定义

| 级别 | 定义 | 赚钱效应 | 市场带动能力 |
|------|------|---------|-------------|
| **主线** | 拥有强大赚钱效应且能带动整个市场上行 | 极强 | 能带动大盘 |
| **强支线** | 赚钱效应强，维持炒作人气 | 较强 | 不能带动大盘 |
| **暗线** | 力度偏弱，关注者少 | 弱 | 无 |
| **一日游** | 两个交易日内结束 | 无持续性 | 无 |

### 主线成立的四个条件

1. **板块容量足够大** — 容纳游资 + 机构资金，所有人都能参与
2. **炒作周期长** — 以周为计，一般两个月以上
3. **市场认可度高** — 成交额前 100 中成分股数量 40–50 只，金额占比约 50%（主线顶部）
4. **赚钱效应足够强** — 龙头翻倍以上涨幅

### 主线与强支线的核心区别

**是否能带动整个市场上涨？** 强支线虽具备赚钱效应，但不能带动整个市场。

### 板块强度升级路径

一日游 → 暗线 → 支线 → 主线。其背后是资金从怀疑到确定的过程，赚钱效应不断加强。

## 七阶段详细特征

### 阶段一：下跌到企稳

**本质**：市场合力从一致到分歧，再到均衡点的过程。

**盘面特征**：
- 不断有资金尝试抄底，一日游板块拉升频率增加
- 跌停个股减少，跌幅 > 5% 个股不断减少
- 指数小级别不断反抽做中枢
- **最重要**：主跌板块是否开始企稳，主跌板块风险必须得到释放

**关键信号**：
- 必消品等防御性板块补跌 → 离底部不远（历史规律：最后一波杀白马）
- 若市场仍有支线炒作但指数仍跌 → 徒劳无功，未到企稳

**量化参考（震荡市）**：
- 下跌期：涨停 ≤ 20 只，涨幅 > 5% ≤ 40 只，跌停 40–100 只，跌幅 > 5% 100–400 只

---

### 阶段二：超跌反弹

**本质**：分力达到均衡点后，资金找到短期一致方向——超跌反弹。

**从阶段一到二的转折判断（小转大）**：
1. 涨速榜紫色（涨幅 1.5% 以上）越多越好，一般 30 多只为主
2. 板块效应强 — 涨速榜同板块扎堆
3. 龙头封板，龙二龙三跟随封死
4. 成交量明显放大

**满足以上条件**：至少是 1F 级别转 60F 级别的反抽。

**盘面特征**：
- 指数日线底分型，短期企稳
- 超跌龙头连板，激进资金大量进场
- 主跌板块企稳，跌停数量持续减少
- 绩优股企稳反弹，仙股游离
- **潜在主线板块（暗线）可能提前企稳**

**超跌龙头空间**：
- 股灾/系统性风险：基本一倍空间
- 正常周线轮回：30%–50%

---

### 阶段三：超跌结束到主线出现的真空期

**盘面特征**：
- 超跌股回落，资金重入分歧
- 板块轮动切换：支线 + 暗线 + 一日游 + 前主线反抽
- 无短线板块维持时，其余个股回落
- 绩优股/潜在主线个股相对抗跌，仙股继续新低

**指数**：回落做中枢，不排除新低。重点不是是否新低，而是是否再次出现向下合力。

**两种分叉**：
1. 板块轮动后主线冒头 → 进入阶段四
2. 人气不足，无法出现新主线，再次出现下跌主力板块 → 回到阶段一（缠论「背了又背」）

**阶段三与阶段六同类**：都以支线炒作为主的中枢震荡。
- 支线强 → 中枢上沿震荡
- 无支线只有暗线/一日游 → 中枢下沿震荡
- 连暗线和一日游都没有 → 考虑转阶段一

---

### 阶段四：主线初期

**本质**：90% 的主线是市场资金不断尝试后由市场选择的结果。阶段四是尝试阶段/怀疑阶段。

**盘面特征**：
- 市场氛围逐渐好转
- 涨停、涨幅 > 5% 数量开始上升
- 绩优股逐渐走强，支线/暗线走强，普通股反弹，垃圾股企稳
- **板块轮动速度放慢**
- **昨日涨停今日平均涨幅持续 > 2%**
- 赚钱效应开始提高
- 最终在资金不断尝试后主线板块浮出水面
- 龙头股持续高涨，板块效应强

**最早判断主线**：更多凭经验，暂无完美量化方法。关注板块容量 + 龙头持续性 + 二线跟随 + 成交占比。

---

### 阶段五：主线中期

**本质**：做多热情爆发，赚钱效应最强的一段，几乎所有个股都涨。

**盘面特征**：
- 主线龙头翻倍以上涨幅，板块联动性强
- 主线持续时间：至少两个月
- 绩优股走趋势，垃圾股小幅反弹

**量化参考（震荡市）**：
- 涨停：40–60 只
- 涨幅 > 5%：70–130 只
- 跌停：≤ 10 只，跌幅 > 5% ≤ 40 只
- 昨涨停今均：每天 > 2%，强时 4%–5%
- 指数进入周线级别主升

**主线终点预警**：
- 成交额前 100 中主线成分数量达 40–50 只
- 成交额前 100 中主线成交额占比**达约 50%** → 超过此量级，资金从其他个股抽离，风险出现
- 典型案例：某日金融占比 45%，持续到数日后达 49%，自选股池一片全绿

**关键规则**：
- 除主线外，其他分力至少达到均衡点，主线才能带动市场
- 若其余形成向下合力并打出亏钱效应，主线也将倒头杀跌

---

### 阶段六：主线末期

**进入标志**：**主线核心龙头带崩整个高位股集体性跌停。**

**盘面特征**：
- 龙头回落，低位股接力但力度逐渐衰弱
- 绩优股势头不减或稍有回调
- 普通股票日线级别中枢震荡，垃圾股回落较多
- 砸下来后主线仍反复活跃，支线只剩龙头活跃
- 小热点、一日游板块轮动频繁出现
- **指数进入 60F 级别中枢震荡**
- 昨涨停今均：0%–1%，甚至 0% 以下，波动大

**博弈特征**：节奏踩不好会被反反复复打脸。机构票/绩优股相对出色。

**人气龙头回调极限**：28%–33%（最高收盘价到最低收盘价）。

**阶段六后半段两种分叉**：
1. 板块轮动后市场找到新主线，氛围配合 → 回到阶段四循环
2. 加速轮动后无新主线 → 进入阶段七下跌

**震荡市中每轮周线轮回有 2–3 波主线接力。**

---

### 阶段七：进入下跌

**触发条件**：主线结束后板块不断轮动到加速轮动，最终仍无法找到新方向 → 资金卖出退出。

**标志规律**：
- 板块轮动到「高速公路」就轮不下去 → 历史经验信号
- **每次中期趋势扭转都是「板块轮动结束 + 不起眼板块下跌」组合**
  - 不起眼板块如：解禁股、质押、闪崩股、新低股

**恶化过程**：
- 跌停板异常个股从 1 只变 2–3 只 → 高度警惕
- 形成板块性下跌 → 悲观氛围放大
- 大量仙股创新低，恐慌放大
- 极端：百股跌停甚至千股跌停

**高位即将短期回调量化信号**：
- 指数 1F 级别向下拐头，跌速榜紫色股（跌速 > 1.5%）25 只甚至以上
- 连续 2–3 天出现 → 即将面临 60F 级别调整
- 历史案例可参考过往周线轮回中的关键节点

---

## 策略总纲速查（仓位为情景取向，非买卖指令）

> 交付报告时改写为「条件→观察→风险」框架，禁止「必须满仓/清仓/买入/卖出」口吻。

| 阶段 | 仓位取向 | 策略核心 |
|------|----------|---------|
| 阶段一 | 轻仓观察 | 等主跌企稳，关注补跌的防御板块 |
| 阶段二 | 偏低（约 3–5 成示意） | 超跌反弹参与，快进快出 |
| 阶段三 | 中低（约 3–5 成示意） | 关注绩优/潜在主线，等方向 |
| 阶段四 | 中高（约 5–7 成示意） | 主线确认后逐步提高敞口，重点观察 |
| 阶段五 | 偏高（约 7–9 成示意） | 主线持有主升；设失效条件，非「拿住不动」 |
| 阶段六 | 中低（约 3–5 成示意） | 降低高位主线敞口，转绩优防御 |
| 阶段七 | 极低（约 0–2 成示意） | 防守为主，等阶段一再评估入场 |

## 历史周期参考：完整周线轮回示例

```
外部冲击暴跌 → 阶段一/二
震荡筑底 → 阶段三
科技主线浮现 → 阶段四（第一波）
主升浪高潮 → 阶段五
龙头分歧 → 阶段六
防御板块轮动 → 阶段六/三过渡
新兴主线 → 阶段四（第二波）
资源板块 → 支线切换
电力板块 → 支线切换
主线退潮 → 阶段六
前期主线回归 → 阶段四（第三波）
全产业链 → 阶段五→六
```

完整路线：政策底 → 科技牛 → 新兴方向 → 资源 → 电力 → 前期主线回归，三次阶段四起点，体现 2–3 波主线接力的规律。
