# 群体行为金融：核心框架与 A 股适配参考

## 基础理论模块

### 前景理论 (Prospect Theory — Kahneman & Tversky, 1979)

- **核心机制**：盈利区间风险规避（落袋为安），亏损区间风险偏好（死扛等反弹）
- **A 股映射**：牛市中轻仓（赚一点就跑）、熊市中满仓（被套就不动）
- **观测价值**：市场从下跌转上涨初期，散户普遍「不敢买」属正常心理，对应怀疑阶段——此时反而应关注

### 心理账户 (Mental Accounting — Thaler, 1985)

- **核心机制**：人们将资金按用途分类（安稳钱、赌博钱、教育金等），不同类别容忍度不同
- **A 股映射**：散户把「赚来的钱」归为赌博钱，操作更激进；把「本金」归为安稳钱，操作更保守
- **观测价值**：散户开始使用融资/配资（赌博钱仓位扩大）→ 狂热阶段信号

### 自我归因偏差 (Self-Attribution Bias)

- **核心机制**：盈利归功于自己英明，亏损归咎于市场/庄家/政策
- **A 股映射**：牛市中人人自称「股神」；熊市中抱怨「A 股不适合价值投资」
- **观测价值**：社交平台上「股神」帖子数量可作为情绪反向指标

### 沉没成本谬误 (Sunk Cost Fallacy)

- **核心机制**：已投入大量时间/金钱/精力，即使前景不好也继续坚持
- **A 股映射**：「都跌了这么多了，现在卖不是白亏了吗」——典型沉没成本思维
- **观测价值**：市场下跌中成交量反而缩小（散户惜售），可配合沉没成本分析

### 代表性启发 (Representativeness Heuristic)

- **核心机制**：用过去某段代表性经历判断当前，忽略基础概率
- **A 股映射**：「上次 XX 事件后大涨了，这次也一样」或「已经连涨 3 天了，肯定要跌」
- **观测价值**：检测市场是否存在「刻舟求剑」式的类比推理

## 群体行为理论模块

### 勒庞群体心理 (1895 — 至今适用)

- 群体智力低于个体平均智力
- 群体情绪具有传染性和放大效应
- 群体易受简单口号和极端主张影响
- **A 股映射**：投资社群/股票论坛中「牛市来了」「这次不一样」等口号传播

### 明斯基金融不稳定假说 (Minsky, 1986)

- 演化路径：稳定期 → 冒险增加 → 杠杆上升 → 脆弱性积累 → 突然崩溃
- 五阶段划分：替代 → 繁荣 → 狂热 → 危机 → 恐慌
- **A 股映射**：历史上多轮杠杆牛行情完美诠释此模型

### 索罗斯反身性理论 (Reflexivity)

- 核心逻辑：市场参与者认知可改变市场基本面，基本面反过来又改变认知
- 正反馈循环：价格上涨 → 更多人买入 → 价格继续上涨 → 更多人相信会继续涨
- **A 股映射**：当龙头股行情进入「股价涨 → 机构增持 → 更多人看好 → 股价继续涨」的循环
- **关键识别信号**：故事开始「自我实现」时，反身性已进入最后阶段

## A 股特色心理特征

### 政策驱动型情绪

- A 股受政策影响显著，政策信号对大众心理的冲击力远超基本面
- **散户心理链**：政策传闻 → 集体焦虑 → 媒体放大 → 情绪共振 → 过度反应
- 特征：情绪在「极度悲观」和「极度乐观」之间切换速度快、幅度大
- 例：某次印花税调降——消息一出全市场狂欢，数日后回归理性

### 散户主导的指标特征

- 换手率天然高于发达市场
- 融资余额与上证走势高度同步（散户加杠杆是趋势的加速器）
- 「龙虎榜」上榜标的情绪分析：游资手法为 A 股特有的群体行为模式
- **季节性情绪规律**：春季躁动 → 年中决断 → 暑期清淡 → 节前行情 → 年末排名

### 信息传播与情绪放大链

```
传统媒体 → 财经门户 → 社交平台大V → 投资社群 → 朋友圈
(严肃报道)                                          (情绪化转发)
```

- 信息从源头到传播终端的情绪失真程度逐级放大
- **判断要点**：当信息传到投资社群已是第 3–4 手，情绪已被极度放大
- **实战意义**：社群大量讨论某只股票时，该股票通常已接近行情末端

## 极端情绪量化指标

### 恐惧与贪婪指数 (A 股适配版)

构成因素：
1. 股价动量（近 5 日涨跌幅 vs 近 120 日均值）
2. 市场宽度（涨跌家数比）
3. 避险偏好（高股息 vs 成长股表现差异）
4. 新开户数增速
5. 融资余额变化率
6. 基金发行热度

### 极端读数与市场拐点统计

| 情绪状态 | 读数区间 | 历史统计（A 股回测） |
|:---|:---|:---|
| 极度恐慌 | ≤15 | 未来 1 个月正收益概率 > 70% |
| 恐慌 | 16–35 | 可评估分批建仓 |
| 中性 | 36–65 | 情绪非主导因素 |
| 贪婪 | 66–85 | 注意风险，评估是否降低敞口 |
| 极度贪婪 | ≥86 | 未来 1 个月负收益概率 > 65%（历史统计，非预测） |

> 以上为统计概率，**不构成交易建议**。极端情绪仅作辅助观察，须与价格结构、估值、资金流向交叉验证，**不可单独作为交易依据**。

### 拥挤度（前 5% 成交占比）观察阈值

| 读数 | 含义 | 报告写法 |
|------|------|----------|
| < 35% | 偏冷清 | 标注「拥挤度偏低」 |
| 35%–45% | 中性区间 | 常规跟踪 |
| > 45% | 过度集中预警 | 标「狂热/拥挤预警」；**禁止写「自动清仓」**；须交叉验证后再给防守取向 |

> 拥挤度 > 45% 是行为金融意义上的「狂热阶段」量化提示，不是交易指令。
