# 中线右侧交易信号清单（详细规则）

> 适配规则：持仓 10~20 个交易日，止盈 8%~11%，单笔严控最大亏损 ≤ -6%，本金复利目标，只做共振右侧，缺一项暂缓开仓。

## 一、大趋势过滤（优先核查，不达标直接淘汰）

### 检查项

| 检查项 | 判定规则 | 数据来源 |
|--------|---------|---------|
| 60日均线走平/向上 | MA60斜率 = (MA60今日 - MA60的5日前) / 5 / MA60今日，斜率 > 0.001 = 向上，< -0.001 = 向下，之间 = 走平 | K线收盘价计算 |
| 股价站稳60日均线上方 | 最近5日收盘价均 > MA60 × 0.98 | K线收盘价 |
| 低点逐步抬高 | 近20日内局部最低点序列非递减 | K线最低价 |
| 非下降趋势股 | MA60方向非向下 AND (MA5 > MA20 OR MA60斜率 ≥ 0) | K线收盘价 |

### 淘汰规则
- 任意一条不满足 → 直接淘汰，不进入后续检查

## 二、右侧确认形态（二选一满足）

### 方案A：箱体突破

| 检查项 | 判定规则 | 阈值 |
|--------|---------|------|
| 横盘震荡周期 | 从最近往前扫描，波动率 ≤ 8% 的连续天数 | ≥ 15根日线 |
| 收盘价站稳箱体上沿 | 最后收盘价 ≥ 箱体最高价 × 0.98 | 拒绝仅盘中突破 |
| 突破当日成交量 | 当日成交量 / 20日均量 | ≥ 1.3倍 |
| 震荡阶段持续缩量 | 后半段均量 < 前半段均量 × 0.9 | 筹码沉淀 |

**箱体识别算法**：
1. 从最近一个交易日往前扫描
2. 计算扫描区间的 (最高价 - 最低价) / 最低价 = 波动率
3. 波动率 ≤ 8% → 识别为箱体
4. 记录箱体上沿（区间最高价）和下沿（区间最低价）

### 方案B：多头回踩启动

| 检查项 | 判定规则 |
|--------|---------|
| 20日均线向上 | MA60今日 > MA60的5日前 |
| 回调未跌破20日线 | 近10日最低价 ≥ MA20 × 0.97 |
| 重新放量收阳线 | 最后一根K线收盘 > 前收 AND 量比 > 1.2 |

### 淘汰规则
- 方案A和方案B均不满足 → 淘汰

## 三、量能硬性标准

| 检查项 | 判定规则 |
|--------|---------|
| 启动阳线放量 | 最后一根K线为阳线（收盘 > 前收）AND 量比 ≥ 1.3 |
| 无无量虚拉 | 近3日平均成交量 ≥ 近20日平均成交量 × 0.7 |

### 淘汰规则
- 任意一条不满足 → 淘汰

## 四、板块 & 市场环境共振

| 检查项 | 判定规则 | 数据来源 |
|--------|---------|---------|
| 所属板块强于大盘 | 板块近3-5日涨幅 > 同期大盘涨幅 | sector ranking |
| 优先主线板块 | 板块在当日涨幅TOP10或资金流入TOP5 | sector ranking |
| 避开高位退潮 | 板块近5日涨幅 < 15%（非高位） | sector ranking |
| 无系统性大跌 | 大盘当日跌幅 < -2% 时暂缓 | market-overview |

### 评分规则
- 不满足 → 降分（不直接淘汰，但影响综合打分）
- Agent 需根据板块排行数据覆盖 screener.py 的默认判断

## 五、基本面 & 流动性避雷（满足任意一条直接放弃）

| 检查项 | 判定规则 | 数据来源 |
|--------|---------|---------|
| 大额解禁 | 近30日内有解禁事件且解禁市值 > 流通市值5% | risk --types unlock |
| 大股东减持预告 | 存在高管减持预告 | risk --types executive |
| 业绩暴雷 | 近期负面公告 | notice list |
| ST个股 | 名称含ST或*ST | profile / risk |
| 流动性不足 | 20日平均成交额 < 1.5亿 | K线amount |
| 短期涨幅过大 | 10日或20日涨幅 > 30% | K线收盘价 |

### 淘汰规则
- 任意一条满足 → 直接淘汰（exclusion = true）

## 六、风控提前规划

| 检查项 | 判定规则 |
|--------|---------|
| 明确防守支撑位 | 支撑位 = max(近20日最低价, MA20 × 0.97) |
| 最大亏损控制 | (支撑位 / 当前价 - 1) × 100 ≥ -6% |
| 盈亏比 | 止盈幅度 / 止损幅度 ≥ 1.5（优选 ≥ 2） |

### 淘汰规则
- 最大亏损超过-6% → 淘汰
- 盈亏比 < 1.5 → 降分

## 七、持仓时间约束

| 约束项 | 规则 |
|--------|------|
| 预期持有周期 | 10~20个交易日 |
| 止盈目标 | 8%~11% |
| 超时离场 | 满20个交易日未达止盈目标，无条件离场 |
| 止损线 | 达到-6%立即止损 |

## 八、最终综合打分

### 评分公式
```
基础分 = Σ(通过维度的权重) / Σ(所有维度权重) × 100
盈亏比加分: ≥3 → +5分, ≥2 → +3分, ≥1.5 → +1分
最终分 = min(100, 基础分 + 盈亏比加分)
```

### 默认权重

| 维度 | 权重 | 核心维度 |
|------|------|---------|
| 趋势过滤 | 1.5 | ✅ 核心 |
| 右侧确认 | 2.0 | ✅ 核心 |
| 量能确认 | 1.2 | |
| 板块共振 | 1.3 | |
| 基本面避雷 | 1.5 | ✅ 核心 |
| 风控规划 | 1.0 | ✅ 核心 |
| 持仓周期 | 0.5 | |
| 综合打分 | 1.0 | |

### 通过条件
- 核心维度（趋势/右侧/基本面/风控）全部通过
- 最终分 ≥ 60
- 核心维度通过数 ≥ 3

### 共振度评级
- 强共振：4个核心维度全部通过
- 中共振：3个核心维度通过
- 弱共振：少于3个核心维度通过（不推荐）
