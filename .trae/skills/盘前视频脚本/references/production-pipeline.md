# 视频制作管线（两条路径）

脚本交付后，按以下路径制作视频。两条路径可先后启用：先用剪映跑通流程、验证内容效果，再迁移到GPU全自动。

---

## 路径A · 剪映数字人半自动（冷启动，约10分钟/天）

### 一次性设置（约30分钟）

1. **安装**：剪映专业版 ≥ 4.6（数字人功能入口要求）
2. **数字人定制**（二选一）：
   - **方案1 · 克隆专属形象**：录制 1 分钟真人正面视频（纯色背景、光线均匀、正常语速说话、头部微动），上传至剪映「数字人 → 克隆数字人」，约1分钟生成数字分身；可同步克隆声音（录制阅读文本样本）
   - **方案2 · 内置主播**：直接选用剪映预设的正式风格主播（写实风），零成本启动
3. **背景模板**：素材库搜索"演播室/新闻背景"，选固定一张存为常用素材；后期用「画中画」置于数字人轨道下方（注意层级：背景轨必须在数字人轨之下，否则数字人被覆盖）
4. **图表窗模板**：预做一个右侧图表占位框（16:9 布局：主播居左2/3，图表窗居右1/3），每日替换截图

### 每日流程（约10分钟）

1. 打开昨日工程副本 → 删除旧文本轨
2. 「文本」→ 粘贴当日 `口播稿.md` 全文
3. 选中文本 → 右上角「数字人」→ 选择定制的数字人 → 等待云端渲染（期间预览静止属正常，勿中断）
4. 渲染完成 → 删除原始文本轨（只留数字人视频轨）
5. 「智能字幕 → 识别字幕」→ 调整字幕样式（白色+描边，应用到全部）
6. 替换图表窗内截图（来自复盘报告的图表截图）
7. 加片头关键词卡（大字3-5字，2秒）与片尾免责字幕条（3秒）
8. 导出 1080P → 抖音发布（用 `发布文案.md` 的标题+标签）

### 已知坑

- 免费版导出水印：开会员或用网页版去水印方案
- AI匹配素材跑偏：数字人路线无此问题（口播为主），图表窗素材手动放
- 云端渲染排队：早高峰（8-9点）可能慢，建议 7:30 前提交渲染

## 路径B · GPU服务器全自动（进阶）

适合验证内容效果后，追求无人值守日更。架构：**脚本（Agent）→ TTS → 口型驱动 → 合成 → 发布**。

### B1 · TTS 语音合成

| 方案 | 说明 | 成本 |
|------|------|------|
| MiniMax speech-02（API） | 声音克隆+情绪控制，中文自然度第一梯队 | 按字符计费，一条4分钟视频约几元 |
| 本地 CosyVoice / GPT-SoVITS | 开源，克隆音色，GPU推理 | 免费（电费） |

建议：先用 MiniMax API（省心），量稳定后迁移本地。

### B2 · 口型驱动（核心环节）

| 方案 | 说明 | 适用 |
|------|------|------|
| **MuseTalk**（推荐） | 开源，30fps 实时级推理，输入=主播模板视频+音频，输出对口型视频；单卡GPU可跑 | 4分钟视频约几分钟渲染 |
| SadTalker | 单张照片驱动，质量好但偏慢 | 备选 |
| EchoMimicV2 | 照片+音频，支持半身动作 | 备选 |
| Wav2Lip | 老牌方案，速度快但清晰度一般 | 兜底 |
| MiniMax S2V-01 / Hailuo H3（API） | 主体一致性视频生成，**单段上限约15秒** | 只做片头片尾特效段，不适合全片 |

主播模板：录制一段 4-6 分钟正面口播底版视频（循环眨眼/微动作自然），作为 MuseTalk 的固定输入，保证每天形象一致。

### B3 · FFmpeg 合成

```
输入：口型视频.mp4 + 演播室背景图/循环视频 + 图表截图序列 + 字幕.srt + 片头片尾.mp4
步骤：
1. 口型视频缩放置于画面左2/3，抠掉原背景（纯色背景用chromakey滤镜）
2. 背景轨铺底，右侧1/3开窗叠加图表截图（按分镜时间点切换）
3. 烧录字幕（subtitles滤镜，样式与SRT内联）
4. 片头关键词卡2秒 + 片尾免责条3秒拼接
5. 输出 1080P / 30fps MP4
```

### B4 · 发布

| 方案 | 说明 |
|------|------|
| 抖音开放平台 `video.create` API | 需企业资质+应用审核，全自动 |
| 巨量引擎/第三方上传工具 | 半自动 |
| 手动上传（推荐初期） | 每天一次拖拽，成本可忽略 |

### 成本与产能估算（路径B）

| 项目 | 单条成本 | 备注 |
|------|---------|------|
| TTS（MiniMax API） | ≈ 2-5元 | 4分钟约1200字 |
| MuseTalk 本地渲染 | 电费级 | 单卡GPU几分钟 |
| Hailuo H3 片头（可选） | ≈ $0.14/秒 × 10秒 ≈ 10元 | 非必需 |
| 合计 | **约3-15元/条** | 全自动后人工0分钟 |

## 里程碑建议

1. **第1周**：路径A跑通，验证内容与完播率（抖音后台看3秒跳出率、平均播放时长）
2. **第2-4周**：迭代脚本（哪段跳出高砍哪段），固定人设口头禅
3. **第2个月起**：搭建路径B（先TTS API+MuseTalk，后全自动发布），人工介入降为审片5分钟
